# 角色资产产线（三步逐级传递出图）

> 本模块从"角色出图产线"技能中提炼，适配保险视频场景。提供S1验脸→S2面部四视图→S3全身四视图的逐级传递出图流程，解决保险视频多角色跨镜头换脸问题。

## 核心理念

三张图按固定顺序逐级传递，**每一张出完都停下来等确认**。每一张的身份依据是上一张的成图，不是最开始的原图。身份只会越走越稳。

| 产物 | 画幅 | 职责 | 保险场景用途 |
|------|------|------|------------|
| **S1 单张大头** | 竖构图2K | 验脸闸门，像才往下走 | 确认妈妈/爸爸/孩子/销售员形象 |
| **S2 面部四视图** | 3:4 | 锁脸型轮廓、五官形状、发型发际线 | 跨镜头面部一致性 |
| **S3 全身四视图** | 9:16 | 锁身高比例与服装 | 跨镜头服装/体态一致性 |

## 四条铁律

1. **每一步出完必须停** — 把成图推给用户、等确认后才走下一步
2. **身份依据是上一张成图** — S2用S1的成图做身份参考，S3用S2的成图
3. **不重复生成用户已有素材** — 用户上传了图就用那张，不要重出
4. **用户给了提示词就逐字用** — 不加风格词、不加服装清单、不加写实规格

## 入口判定

| 入口 | 判定 | 动作 |
|------|------|------|
| **A 用户上传图** | 对话里带了图 | 直接以该图为身份依据进S1 |
| **B 画布已有图** | 用户说"用画布上那张" | 确认是哪张后走和入口A一样的流程 |
| **C 纯文生人物** | 没有可用图 | 先补齐人物设定（身份/五官/服装/气质/画风），再出S1 |

### 入口C的问诊清单（一轮问齐）
- 身份/性别与年龄段
- 脸型与五官关键形状（脸型轮廓、眼型与眼距、鼻型、唇型、发型发色）
- 服装（款式、颜色、材质、领型）——越具体越好，S3全靠它
- 气质与职业/身份背景
- 画风（写实真人/3D动画/二维插画等）

## 第一步：S1 单张大头（验脸闸门）

### 为什么必须先做
四视图一旦出完才发现不像，整轮白做。先用一张单张确认脸，是最便宜的止损。

### 参数
- 画幅：竖构图，2K
- 模型：建议锁脸能力强的模型
- 提示词：只取"正面免冠证件照视角"，不带四宫格措辞

### 标准提示词
```text
出单张正面大头照。
正面免冠证件照视角，
头部占画面主导，
背景写实摄影棚纯白背景定妆照
```
附加：比例竖构图2K、模型名、身份依据句。

### 出图后必须做两件事

1. **拼一张并排对照图**（原图 | 生成图），没有拼图能力时改为逐目视核对
2. **逐项核这六项**：

| 核对项 | 看什么 |
|--------|--------|
| 脸型轮廓 | 鹅蛋/方圆/长窄——形状对了没 |
| 眼睛 | 大小、眼距宽窄、眼皮形态 |
| 鼻子 | 鼻梁高低、鼻头钝尖 |
| 唇 | 厚薄、唇峰明显否 |
| 发型 | 轮廓、刘海形态、发际线、发色 |
| 配饰 | 原图可见的帽子/眼镜/耳饰是否在 |

- **通过** → 推图给用户，等确认后进S2
- **不通过** → 改提示词重出单张，绝不带着不像的脸往下走
- **拿不准** → 如实说"这一项我拿不准"

### 入口C特例
纯文生时，S1同时是基准图和验脸图，用户确认"这就是我要的人"即可。

## 第二步：S2 面部四视图（3:4）

### 参数
- 画幅：3:4（2K约1536x2048）
- 模型：建议锁脸能力强的模型
- 身份依据：**S1的成图**（已验过脸的那张），不是最初的原图

### 标准提示词
```text
出2x2四视图。
左上正面免冠证件照视角，
右上严格左侧面轮廓，
左下四分之三右侧面，
右下低角度仰视面部特写。
头部占画面绝对主导，
背景写实摄影棚纯白背景定妆照
```
附加：比例3:4、模型名、身份依据句（依据=S1成图）。

### 四格内容
- 左上：正面免冠证件照视角
- 右上：严格左侧面轮廓
- 左下：四分之三右侧面
- 右下：低角度仰视面部特写

### 出图后自检
- 四格必须是同一个人：脸型、五官、发型跨格不能漂
- 出图后停下来等用户确认，通过后才进S3

## 第三步：S3 全身四视图（9:16）

### 参数
- 画幅：9:16（2K约1440x2560）
- 模型：建议人体比例/服装结构能力强的模型
- 身份依据：**S2的成图**，不是原图也不是S1的大头

### 标准提示词
```text
出2x2四视图。
上小下大：
左上正脸特写，
右上侧脸特写，
左下脖子以下全身不含头，
右下背面全身。
背景写实摄影棚纯白背景定妆照
```
附加：比例9:16、模型名、身份依据句（依据=S2成图）。

### 四格版面
- 左上：正脸特写
- 右上：侧脸特写
- 左下：脖子以下全身不含头
- 右下：背面全身

### 最容易翻车的一格："左下 脖子以下全身不含头"
模型要在没有头部参考的情况下重建整个身体，两类问题高发：
1. **服装被改款** — 单排扣画成双排扣、长款画成短款
2. **比例与气质漂移** — 这一格比其余三格显老或显壮

**对策**：出图后逐格核对服装款式（扣型、长度、敞开方式、领型），不能只看"同一套颜色"就算过。在推给用户之前主动说明这一格的风险。

## 服装字段：只能抄不能补

1. **可见的照抄** — 领型是V领就写V领，颜色是灰绿就写灰绿，一个字都不"优化"
2. **不可见的绝不补全** — 画面外的下装、鞋、背面花纹，原图没给就不能编
3. **需要补全时先问** — 给三个选项：裁到可见范围/用户指定/按原风格拟一版
4. **同一人物服装字段全程复用同一个值** — 不要S2写一套、S3又写一套

## 出图自检清单（每张图出完都过一遍）

### 一、像不像（最重要）
拼原图 | 生成图的并排对照，逐项核六项五官与配饰。入口C时改为核对"是否符合用户问诊设定"。

### 二、画幅与白底
用实际像素验：
- 比例必须正好对上：3:4 = 0.75，9:16 = 0.5625
- 四角像素应接近纯白（244-253可接受）

### 三、四格版面与一致性
- 版面是不是要求的版式
- 四格顺序对不对
- 四格是不是同一个人
- 四格服装是不是同一套
- 光线方向是否一致

### 四、服装与原图逐项对
领型、颜色、材质、配饰。这一步不能省。

### 五、模型确实生效了吗
看返回文件名前缀验证模型是否按预期生效。

## 与现有角色锁定协议的关系

- **character_lock_protocol.md** 定义角色参考图的格式规范（四视图+锁定卡+多角色引用），本文件定义**出图流程**（三步逐级传递+验脸闸门+自检）
- 两文件互补：先用本文件流程出图，再用character_lock_protocol的格式规范登记和管理
- 用户已上传角色照片时，跳过三步出图，直接按character_lock_protocol的"用户已上传角色照片时例外"处理
- 本文件的S2/S3产出可直接作为character_lock_protocol中的"四视图角色设定稿"使用

## 保险场景特化建议

### 多角色场景的出图顺序
保险视频通常有2-4个角色（妈妈、爸爸、孩子、销售员），建议：
1. 先出主角（通常是妈妈或爸爸）的S1→S2→S3
2. 主角确认后再出第二角色的S1→S2→S3
3. 孩子角色如果只是出镜不说话，可以只做到S2（面部四视图），省去S3
4. 销售员/医生等配角用群像类型参考图即可，不需要走三步

### 保险场景常见角色设定参考

| 角色类型 | 典型设定 | 服装要点 |
|---------|---------|---------|
| 妈妈（30-40岁） | 温柔、疲惫但坚强 | 居家休闲装/超市购物装/医院陪伴装 |
| 爸爸（35-45岁） | 沉默、务实 | 衬衫西裤/老头衫/夹克 |
| 孩子（5-12岁） | 天真、懂事 | 校服/卡通T恤/睡衣 |
| 销售/医生 | 专业、可信 | 职业装/白大褂 |

## 资产状态衍生体系（v4.4新增）

> 从全球顶牛创意广告导演的状态资产树和单一衍生源公理中提炼，升级为"基准+状态衍生"的全生命周期资产管理体系。

### 单一衍生源公理

所有状态资产（受伤/换装/妆造/老年/湿/战损等）必须**无条件以最初锁定的基准资产为唯一底图**一次性修改生成。

**绝对禁止链式修改**：
- 正确：基准态 → 受伤态（以基准态为底图）
- 正确：基准态 → 化妆态（以基准态为底图）
- 错误：基准态 → 受伤态 → 化妆态（以受伤态为底图）← 面部骨相会漂移

### 状态资产树

每个角色在基准态之外，根据剧情需要派生状态资产：

```
@CHAR_MOM（基准态）
├── @CHAR_MOM_焦虑态（泪痕/黑眼圈/凌乱头发）
├── @CHAR_MOM_释然态（微笑/放松/整理过头发）
├── @CHAR_MOM_换装态（从居家服换成外出装）
└── @CHAR_MOM_回忆态（年轻5-10岁）
```

### 保险场景常用状态资产

| 角色 | 基准态 | 常用衍生状态 | 触发场景 |
|------|--------|-------------|---------|
| 妈妈 | 居家日常 | 焦虑态(泪痕/黑眼圈) | 确诊/催款 |
| 妈妈 | 居家日常 | 释然态(微笑/放松) | 理赔到账 |
| 爸爸 | 工作装 | 疲惫态(衬衫褶皱/胡茬) | 筹钱/加班 |
| 孩子 | 校服 | 病服态(穿病号服/苍白) | 住院段 |
| 场景 | 家庭客厅 | 凌乱态(药瓶散落/窗帘半拉) | 困境段 |
| 场景 | 医院走廊 | 夜间态(灯光减半/空旷) | 深夜急诊 |

### @命名字典

每个项目必须建立@命名字典，资产名=提示词@名=界面参考名，一字不差：

```
@CHAR_MOM = assets/insurance_project/character_mom_base.png
@CHAR_MOM_焦虑态 = assets/insurance_project/character_mom_anxious.png
@CHAR_MOM_释然态 = assets/insurance_project/character_mom_relieved.png
@SCN_HOME = assets/insurance_project/scene_home.png
@SCN_HOSPITAL = assets/insurance_project/scene_hospital.png
@PROP_POLICY = assets/insurance_project/prop_policy.png
```

### 分镜-资产匹配清单

每个分镜必须标注引用哪些精确状态资产：

| 分镜 | 角色 | 场景 | 道具 |
|------|------|------|------|
| SH01 | @CHAR_MOM | @SCN_HOME | @PROP_SAVINGS_JAR |
| SH02 | @CHAR_MOM_焦虑态 | @SCN_HOSPITAL | @PROP_PHONE |
| SH03 | @CHAR_MOM_释然态 | @SCN_HOSPITAL | @PROP_POLICY |

### 参考槽纪律

- 参考图槽只放资产级定妆图（基准态或精确状态资产）
- 叙事帧（生成过的视频截图）永远不进参考槽
- 跨镜一致性靠资产级参考图保证，不靠"和上一镜一样"的隐式引用

### 资产生命周期

```
创建 → 登记@名 → 分镜匹配 → 生成验证 → 锁定 → 复用
                                              ↓
                                         如需新状态
                                              ↓
                                         从基准态衍生 → 登记 → 锁定
```

一旦锁定，基准态不可修改。如需修改角色设定，重新走三步出图流程，旧资产标记为废弃。
