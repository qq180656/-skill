# 医院场景空镜 Skill

## 适用范围

当视频Prompt涉及医院场景的空镜画面时，加载本Skill。覆盖医院6大可拍区域、合规红线（不可拍什么）、安全替代方案、各叙事阶段的空镜组合模板。

本Skill与「空镜穿插通则」「旁白型视频画面分镜规则」配合使用。通则里的因果关联4类、时长控制仍然适用；本Skill解决"医院里能拍什么、怎么拍才合规"。

---

## 一、合规红线：医院空镜绝对不可出现的元素

| 禁止类别 | 具体禁止项 | 原因 |
|---|---|---|
| 医护形象 | 医生（白大褂/听诊器/手术帽）、护士（护士帽/护士服）、任何穿医护服装的人物 | AI生成无法获得真人肖像授权，且涉及执业资格暗示 |
| 医疗仪器特写 | 心电监护仪读数、输液架+输液瓶+滴管、呼吸机面板、手术灯、血压计读数、CT/MRI设备操作面 | 仪器读数涉及诊断暗示，AI生成的数值必然错误，误导观众 |
| 药品/处方 | 药品名称、药盒品牌、处方笺上的文字、药房药架上的药名标签 | 涉及处方药监管和品牌侵权 |
| 患者隐私 | 病历卡文字、挂号单姓名、检查报告上的数据、病房门上的患者信息卡 | HIPAA/个人隐私法规 |

## 三、安全替代方案（想拍X → 改拍Y）

| 想拍的内容 | ❌ 不可拍 | ✅ 安全替代 |
|---|---|---|
| 医生在诊室看病 | 医护形象+诊断暗示 | 诊室门口标识（"内科诊室"）+家属在外面等待的近景表情 |
| 心电监护仪显示病情 | 医疗仪器读数 | 病房窗外空镜（色调随病情加重变冷/转好变暖），或家属握着患者手的近景 |
| 输液/打点滴 | 输液架+输液瓶 | 患者手背搁在被子上的近景（不拍针头和输液管），或走廊窗边家属等待的中景 |
| 护士在护士站忙碌 | 医护形象 | 空护士站远景（电脑屏幕模糊发光、桌上有文件但不拍内容），或走廊灯光变化暗示值班节奏 |
| 药房取药 | 药名标签 | 取药窗口远景，患者拎着白色袋子离开的背影，不拍柜台上的药盒 |
| 手术室场景 | 手术灯+操作画面 | 手术室外走廊中景，家属坐在椅子上双手紧握，走廊尽头手术指示灯亮着红光 |
| 病历/检查报告 | 文字内容 | 病历封面合上的近景（不打开），或医生桌面远景（文件翻开着但不拍文字） |

## 四、各叙事阶段的医院空镜组合模板

### 4.1 生病/发现症状阶段

情绪：不安、意外

推荐空镜组合（2-3秒/条，穿插在人物表演间）：
1. 家庭场景窗边空镜（阴天/雨天=不安）
2. 桌上翻开到一半的日历（标记了去医院的日子）
3. 路上——车窗外街景滑过（去医院的路上）

### 4.2 就医/挂号/检查阶段

情绪：焦虑、等待

推荐空镜组合：
1. 医院外观定场（2-3秒）
2. 候诊区椅子+电子叫号屏（2秒）
3. 走廊纵深（家属在走廊走动/等待）
4. 缴费窗口（递出银行卡的手特写）

### 4.3 诊断/告知阶段

情绪：沉重、震惊

推荐空镜组合：
1. 诊室门口标识近景（"XX科"）
2. 走廊窗边光线从暖变冷（暗示坏消息）
3. 家属坐在走廊椅子上低头的中景

⚠️ 此阶段最容易想写"医生告知病情"，但**医护形象不可出现**。替代写法：
```
近景，女儿坐在诊室门口外的走廊椅子上，
嘴唇紧闭，眉头紧锁，右手无意识地攥着手里的病历本封面（封面合着，不打开）。
画外声：{检查结果出来了，需要住院治疗}
<走廊安静环境声>
```

### 4.4 住院/陪护阶段

情绪：牵挂、温情

推荐空镜组合：
1. 病房窗边阳光+绿萝（2秒，温暖调）
2. 床头柜上的水杯和鲜花特写（2秒）
3. 女儿握着老人手的近景（3秒）
4. 走廊窗边午后光影（2秒，余韵）

### 4.5 康复/出院阶段

情绪：希望、释然

推荐空镜组合：
1. 病房窗户阳光变得更明亮（色调从冷转暖）
2. 医院门口家属搀扶老人走出（中景，背影）
3. 院区小花园绿植+石板路（2秒，生机感）
4. 车窗外医院建筑渐渐远去（远景，回望）

## 五、医院空镜的光线与色调控制

| 阶段 | 推荐色调 | 光线写法 | 情绪 |
|---|---|---|---|
| 发现症状 | 偏冷灰调 | "阴天灰白天空，室内光线偏暗偏冷" | 不安 |
| 就医检查 | 冷白日光灯调 | "走廊顶灯冷白光，地砖反射冷调光" | 疏离/焦虑 |
| 诊断告知 | 冷调加重 | "走廊自然光被乌云遮住，光线变暗变冷" | 沉重 |
| 住院陪护 | 暖冷交替 | "窗外暖阳照进病房/走廊冷白灯" | 冷暖交替=牵挂与希望并存 |
| 康复出院 | 暖调回升 | "午后暖阳照亮病房/医院门口金色夕阳" | 希望/释然 |

铁律：光线和色调的变化本身就是在讲故事——同一扇病房窗，前半段冷白光=病情，后半段暖金光=转好。写Prompt时必须写明光线色调，不能只写"医院走廊"。

## 六、医院空镜的音效规范

| 空镜区域 | 推荐音效 | 写法 |
|---|---|---|
| 走廊 | 远处脚步声/低频环境声 | <远处轻微脚步声> / <走廊安静环境声> |
| 候诊区 | 叫号声/低语声 | <远处电子叫号声，低> |
| 缴费窗口 | 键盘声/打印机声 | <键盘敲击声+打印机出纸声> |
| 病房 | 极安静/呼吸声/窗外声 | <极轻呼吸声> / <窗外鸟鸣> |
| 门口/停车场 | 车声/门声/脚步声 | <自动门开合声> / <远处车辆声> |

铁律：医院空镜的音效必须写"低"或"远处"，制造安静氛围——医院不是菜市场，不能写嘈杂人群声。

## 七、完整Prompt骨架示例

### 示例：保险口播——医院陪护段（10秒单段）

```
第一层：素材绑定 + 音色绑定
  参考@图片1的形象作为口播者，场景参考@图片2（医院病房走廊）。
  @VOX_口播者 = 33岁女性，温和坚定女中音；语速每秒4字；标准普通话；心疼但克制；句前轻吸气；医院近场短混响

第二层：一句话概述
  医院走廊/病房内，口播者讲述陪护经历，穿插病房窗边空镜和手部近景

第三层：画面阶段
  第0-3秒：中景，口播者面朝镜头坐在走廊椅子上，背后是病房走廊纵深，
  浅色地砖反射顶灯白光，走廊尽头安全出口绿灯亮着。
  @VOX_口播者 嘴唇随台词清晰张合，说：{那段时间我每天都在医院}
  第3-5秒：镜头缓缓摇向走廊窗户，切入空镜——
  走廊落地窗，午后阳光斜照进来，在浅色地砖上投下长方形暖光斑，
  窗台上一盆绿萝叶子在光线中微微透亮。
  旁白：{从早到晚，不敢离开半步}（画外声，不写口型）
  <走廊安静环境声>
  第5-8秒：回切至近景，口播者低头看着自己手中攥着的病历本封面（封面合着不打开），
  手指微微发抖，嘴唇紧闭。
  @VOX_口播者 嘴唇随台词清晰张合，说：{我才真正理解什么是重疾险}
  第8-10秒：镜头从口播者缓缓摇向病房门——
  病房门半开，里面可见白色床单和窗台上一束鲜花，
  暖光从门缝中洒出。
  <窗外鸟鸣声，低>

  Environmental SFX only. No music. No BGM.

第四层：约束
  禁止画面中出现医生（白大褂/听诊器）、护士、医护角色、药品名称/药盒品牌/处方药等医疗敏感元素，同时禁止出现医疗仪器特写（心电监护仪读数、输液架输液瓶、手术灯），可用病床、床头柜、窗帘、窗台绿植等非敏感元素替代病房氛围。五官清晰不变形、人体结构正常、服装发型一致，4K超高清、画面稳定无模糊、电影质感，不要生成水印，不要生成logo，保持无字幕
  时长：10秒，比例：16:9
```
