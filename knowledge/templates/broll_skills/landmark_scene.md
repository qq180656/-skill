# 地标与世界景观场景 Skill

## 适用范围

当视频Prompt涉及可辨识的地标建筑、世界景观、城市天际线、自然奇观等场景时，加载本Skill。覆盖地标定场空镜、角色实地互动、FPV穿越、环绕换装、航拍揭示、延时定场、倒影、跨城串联等创意玩法。

---

## 一、地标描写铁律

### 1.1 必须写可辨识特征，不能只写地标名字

模型不认识"东方明珠"这个名词的含义。必须把地标的视觉特征翻译成画面描述：

| 写法 | 判定 | 修正 |
|---|---|---|
| "背景是东方明珠" | ❌ 模型不知道东方明珠长什么样 | "背景是一座高耸的电视塔，顶部有数个大小不一的紫色球体串联，尖刺直指天空" |
| "巴黎铁塔" | ❌ | "一座铁艺镂空高塔，四条弧形铁腿向上收拢汇合成尖顶，棕色金属骨架" |
| "外滩万国建筑群" | ❌ | "沿江一排欧式古典建筑，花岗岩外墙、罗马柱廊、穹顶钟楼，风格各异却整齐排列" |

### 1.2 地标特征清单写法

格式：[整体轮廓] + [材质/颜色] + [标志性结构] + [灯光状态（如有）]

示例：
> 一座高耸电视塔，混凝土主体配紫色球体串联，顶部尖刺天线直指天空，夜间球体亮起粉紫色灯光，塔身投光灯从底部向上照亮

### 1.3 常见地标特征速查（写Prompt时替换为这些描述）

| 地标 | 可辨识视觉特征 |
|---|---|
| 东方明珠 | 高耸电视塔，数个大小不一的紫色球体沿塔身串联，顶部尖刺天线 |
| 上海中心大厦 | 螺旋扭转的玻璃幕墙超高层，顶部呈圆角三角形 |
| 外滩万国建筑群 | 沿江排列的欧式古典建筑群，花岗岩外墙、罗马柱、穹顶钟楼 |
| 武康大楼 | 三角形地块的弧形公寓楼，红砖外墙、法国文艺复兴风格檐口 |
| 埃菲尔铁塔 | 铁艺镂空四腿锥形高塔，棕色金属骨架，顶部尖顶 |
| 自由女神像 | 绿色铜质 statue，右手高举火炬，头戴尖刺王冠，站在基座上 |
| 大本钟/伊丽莎白塔 | 哥特式石砌钟塔，金色钟面镶嵌在四面，尖顶带有繁复雕饰 |
| 东京塔 | 红白相间的钢架电波塔，顶部天线，下部四腿支撑 |
| 广州塔（小蛮腰） | 扭转的腰身，银灰色钢架结构外裹，夜间彩虹灯网 |
| 悉尼歌剧院 | 白色帆形壳体屋顶层层叠叠，坐落于海港半岛 |

### 1.4 审核注意

部分国外地标有版权/商标限制（如埃菲尔塔夜间灯光秀、迪士尼城堡等）。若生成被审核拦截，改用通用描写（"铁艺镂空高塔"替代"埃菲尔铁塔"），不重试原名称。

## 二、地标引用两种模式

### 模式A：定场空镜（地标不与角色互动）

用途：视频开场或转场时快速建立地点信息，告诉观众"这是哪里"。

写法要点：
- 地标占据画面主体（≥60%画面面积），角色不出场
- 景别用远景/全景
- 必须写明时间段（晨/午/黄昏/夜间）和天气状态
- 运镜推荐：航拍揭示、延时摄影、FPV穿越
- 时长建议：2-4秒（定场空镜不宜过长）

```
示例：航拍揭示定场
运镜：航拍揭示，高空俯拍黄浦江蜿蜒S形穿过城市，镜头缓缓下移，
露出一座高耸电视塔（数个紫色球体串联、尖刺天线）和周边螺旋扭转的玻璃幕墙高楼群。
黄昏时分，暖金色夕阳照亮建筑群西面，江面泛着橙金波光，天空橙蓝渐变。
<城市低频环境声>
```

### 模式B：角色实地互动（角色与地标同框）

用途：Vlog、旅拍、剧情中角色出现在地标前/旁/远处。

写法要点：
- 必须写角色与地标的**空间关系**（角色在画面前景/中景/远景，地标在角色身后哪个方向）
- 景别选择：
  - 角色中景+地标远景 = "景大人小"，突出环境
  - 角色近景+地标虚化背景 = 突出角色，地标做氛围
  - 全景人物占1/4+地标占主体 = 定位感强
- 地标必须写可辨识特征（见§1.1），不能只写名字
- 角色朝向用绝对朝向（面朝镜头/背对镜头/侧身朝左）

```
示例：角色在地标前Vlog
运镜：手持拍摄，镜头带轻微自然晃动。
中景，口播者面朝镜头站在江边栏杆旁，背后远处是一座高耸电视塔
（数个紫色球体串联、尖刺天线、夜间亮粉紫色灯光）和沿江欧式建筑群。
口播者边走边说，背景随走动自然变化。
@VOX_口播者 嘴唇随每个字清晰地一开一合，说：{台词}
<江风声，低>
```

## 三、创意玩法

### 3.1 FPV穿越地标

适用场景：巷道、楼缝、桥洞、江面低空、城市天际线穿行

```
运镜：穿越机运镜，镜头以第一视角高速穿行[空间]，
贴近[场景边界]灵活飞行，带明显速度感与滚转俯仰变化。
```

铁律：
- 必须写完整飞行路径和穿过的物体，不能只写"高速穿越"
- FPV穿越中地标以动态视角呈现：擦过→掠过→豁然开朗
- 配合音效：<风声呼啸> 或 <引擎声+气流声>

```
示例：FPV穿越上海陆家嘴
运镜：穿越机运镜，第一视角从外滩江面低空贴水飞越，
擦过外白渡桥钢架，急转侧飞掠过沿江欧式建筑群（花岗岩外墙、罗马柱、穹顶钟楼），
穿过桥洞后拉升，豁然开朗——一座高耸电视塔（紫色球体串联、尖刺天线）
和螺旋扭转的玻璃幕墙高楼群矗立前方，夜间霓虹璀璨。
<风声呼啸+引擎声>
```

### 3.2 环绕轨道换装（地标背景无缝切换）

适用场景：旅行Vlog、时尚穿搭、多城市串联

核心手法：镜头不停环绕角色，每次转到角色背后时切换城市地标+换装，利用角色身体遮挡实现无缝转场。

```
运镜：环绕拍摄，镜头以角色为圆心持续匀速旋转，不停顿。
镜头每次转到角色背后（角色身体遮挡画面）时，背景地标和角色服装同步切换。
切换发生在角色肩背遮挡画面的1-2帧内，观众看不到硬切。
```

分段写法：
```
第0-3秒：镜头环绕至角色正面，背景是一座铁艺镂空四腿锥形高塔（棕色金属骨架），
角色穿法式优雅连衣裙，微微转向镜头。
第3-6秒：镜头继续环绕，经过角色背后时背景切换为霓虹灯牌和广告幕墙密集的十字路口，
角色服装切换为现代街头时尚，角色自信地向前迈步。
第6-9秒：镜头继续环绕，经过角色背后时背景切换为传统东方宫殿院落（飞檐斗拱、石阶灯笼），
角色服装切换为融合传统纹样的现代服饰，角色随镜头旋转裙摆飘动。
```

铁律：
- 镜头旋转方向全片一致（始终顺时针或始终逆时针），不能中途反转
- 每段地标必须写可辨识特征，不能只写城市名
- 换装与背景切换必须在同一帧完成，不能先换装再换背景

### 3.3 地标延时定场

适用场景：开场定场、时间跨度叙事、城市脉动呈现

```
运镜：固定机位，延时摄影，[被压缩的时间过程]在数秒内快速呈现。
```

示例：
```
运镜：固定机位，延时摄影，3秒内呈现黄昏到入夜的光线变化——
天空从橙蓝渐变转为深蓝，沿江一排欧式古典建筑（花岗岩外墙、罗马柱、穹顶钟楼）
的灯光渐次亮起，一座高耸电视塔（紫色球体串联）的球体从底部向上依次亮起粉紫色灯光，
江面车灯光轨汇聚成流线，游船灯光在水面划出彩色尾迹。
<快节奏城市环境声压缩>
```

铁律：
- 延时期间必须写明"被压缩的时间过程"具体是什么变化
- 延时画面中禁止出现不可逆变化的方向性错误（如日落写成了日出）
- 地标灯光亮起顺序要符合真实（从下往上、从远到近等）

### 3.4 航拍揭示

适用场景：城市全貌展示、地理体量呈现、地标首次亮相

三种变体：

| 变体 | 写法 | 适用 |
|---|---|---|
| 高空俯拍揭示 | 运镜：高空俯拍→镜头下移→露具体地标 | 城市天际线、地标群 |
| 低空推进揭示 | 运镜：低空贴地/水面推进→缓慢拉升→展开全景 | 江边/海边/广场地标 |
| 螺旋上升揭示 | 运镜：环绕拍摄+同时上升，从近景旋升高空全景 | 单一地标立体展示 |

```
示例：低空推进揭示
运镜：镜头贴江面低空前推，水面波光在前景滑过，
缓慢拉升抬升视角，远处一座高耸电视塔（紫色球体串联、尖刺天线）
和螺旋扭转的玻璃幕墙高楼群从江面雾气中逐渐浮现，
最终展开为全景城市天际线，黄昏暖光镀金建筑群。
<江水声+城市远场环境声>
```

### 3.5 地标+角色Vlog互动运镜

适用场景：旅拍、探店、城市行走Vlog

| 运镜手法 | 写法 | 效果 |
|---|---|---|
| 框架构图 | "角色穿过门洞/桥洞，地标在框架内呈现" | 画中画层次感，一眼识地点 |
| 景大人小 | "全景，角色占画面1/5，地标占主体" | 突出环境壮阔感 |
| 反向跟踪 | "镜头与角色反向移动，角色始终锁定画面中心" | 视觉冲击，地标从角色身后滑过 |
| 走路转场 | "角色朝同一方向走，背景地标切换" | 无缝跨城转场 |
| 回眸跟拍 | "镜头跟随角色行走，角色不经意回眸看向镜头" | 自然情绪+地标背景 |

```
示例：框架构图+走路转场
运镜：跟随拍摄，镜头跟随口播者沿江边步道自然步态前行。
口播者穿过一座石拱桥的桥洞，桥洞框架内远处可见一座高耸电视塔
（紫色球体串联、尖刺天线）和沿江建筑群。
口播者继续前行走出桥洞，回眸看向镜头微笑。
@VOX_口播者 嘴唇随台词清晰张合，说：{台词}
<江风声+脚步声>
```

### 3.6 地标倒影

适用场景：文艺情绪、水面/玻璃幕墙反射、虚实对比

```
运镜：固定机位，镜头对准[水面/玻璃幕墙]中的地标倒影，
倒影微微晃动（水波纹/光斑闪烁），3秒后镜头缓缓上移，
露出真实地标的完整轮廓，倒影与实体形成上下对称构图。
```

铁律：
- 倒影写成模糊/晃动的虚影，禁止倒影中出现可清晰辨识五官的人脸
- 水面倒影需写水面状态（平静如镜/微波粼粼/波光闪烁）
- 玻璃幕墙倒影需写幕墙材质带来的变形（拉伸/扭曲/色彩偏移）

### 3.7 微距+蒙太奇（地标细节纹理与全景交替）

适用场景：城市宣传片、产品广告中的城市背景、节奏感强的快剪

```
镜头序列（每个镜头2-3秒，全景与微距交替）：
1. 全景：地标完整轮廓远景
2. 微距：地标建筑表面材质特写（花岗岩纹理/玻璃幕墙反光/钢架锈迹）
3. 全景：另一角度地标全景或周边建筑群
4. 微距：地标局部结构特写（球体连接处/塔尖天线/雕花柱头）
5. 全景：地标与城市天际线融合大远景
```

铁律：
- 全景与微距交替节奏要均匀，不能连续两个全景或两个微距
- 微距特写必须承载建筑信息（材质证明/结构细节），不是纯装饰
- 交替剪辑的动势要对齐（全景的运动方向与微距的视觉引导线一致）

### 3.8 赛博朋克夜景地标

适用场景：未来感城市、科技感开场、夜间都市

```
风格：赛博朋克与海派摩登融合，电影级青橙调色。
夜间，地标建筑灯光全开（[具体灯光颜色和分布]），
周边建筑群玻璃幕墙流光溢彩，霓虹灯牌在建筑表面投影彩色光斑，
江面/水面倒映斑斓灯光，低空雾气营造赛博氛围。
<低频电子环境声>
```

铁律：
- 必须写明青橙调色的具体表现（暗部偏青、高光偏橙暖）
- 霓虹灯颜色要具体（粉紫/电蓝/暖橙），不能只写"霓虹闪烁"
- 地标灯光状态与白天不同，需单独描述

### 3.9 希区柯克变焦拍地标

适用场景：角色面对地标时的心理冲击、认知崩塌、敬畏感

```
运镜：希区柯克式变焦，机位移动与反向变焦同时发生，
地标在画面中大小基本保持稳定，但背景透视发生明显变化——
周边建筑群向后退散或向前压迫，空间感急剧扭曲。
```

铁律：同一视频中使用不超过1次，多用则失效。

### 3.10 跨城串联（多城市地标一镜到底）

适用场景：旅行集锦、城市对比、国家形象片

```
运镜：穿越机运镜/一镜到底，镜头高速穿行于多个城市地标之间，
通过以下方式实现跨城无缝连接：
- 飞越遮挡物（穿过桥洞/云层/建筑缝隙）→ 切换到下一个城市
- 匹配剪辑（前一个城市的建筑轮廓与后一个城市的建筑轮廓对齐）
- 速度模糊（加速到画面模糊→减速时已在新城市）
```

分段写法：
```
第0-4秒：FPV穿越城市A地标群，贴建筑表面高速掠过
第4-5秒：加速冲入云层/桥洞，画面速度模糊
第5-9秒：减速穿出，已到城市B地标群，豁然开朗
第9-10秒：再次加速冲向下一个遮挡物
第10-14秒：穿出后到城市C地标群，全景收束
```

铁律：
- 每个城市的地标必须写可辨识特征，不能只写城市名
- 跨城过渡必须写明过渡方式（遮挡/匹配/模糊），不能硬切
- 最后一个城市用全景航拍收束，给观众落地感

## 四、地标与光线组合

| 时间段 | 光线特征 | 写法要点 | 适用 |
|---|---|---|---|
| 日出 | 低角度暖光从地平线射来，建筑东侧镀金 | "日出时分，低角度金色阳光照亮建筑东面，西面投下长阴影" | 温暖定场、新一天开始 |
| 正午 | 顶光，建筑受光均匀，阴影短促 | "正午强光直射，建筑表面明亮均匀，下方阴影短促" | 清晰展示建筑细节 |
| 黄昏 | 暖金色侧逆光，建筑轮廓镀金边 | "黄昏暖金色逆光，建筑西面轮廓镀金边，东面沉入阴影" | 最常用、最有质感 |
| 蓝调时刻 | 天空深蓝、建筑灯光已亮但天未全黑 | "蓝调时刻，天空深蓝渐变，建筑灯光亮起，天际线清晰可辨" | 城市夜景过渡 |
| 夜间 | 建筑灯光为主光源，天空深黑 | "夜间，建筑灯光全开，[具体灯光颜色]，天空漆黑，水面倒映灯光" | 赛博朋克、都市夜景 |

铁律：地标在不同时间段的可辨识特征不同（白天看轮廓材质，夜间看灯光分布），必须按所选时间段写对应的特征。

## 五、地标作为空镜穿插时的因果关联

地标空镜归入「空镜穿插通则」的关联类型判定：

| 关联类型 | 地标空镜示例 |
|---|---|
| 因果关联 | 台词"在上海的那些年"→空镜：外滩建筑群黄昏全景 |
| 空间关联 | 当前场景在黄浦江边→空镜：对岸陆家嘴天际线 |
