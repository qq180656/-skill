# 空镜场景 Skill

## 适用范围

当视频Prompt涉及空镜（B-roll）画面的类型选择、创意玩法、写法规范时，加载本Skill。覆盖空镜6大类型、12种创意玩法、各体裁空镜配比、空镜与台词/旁白/音效的组合规范。

本Skill是「空镜穿插通则」的扩展，通则里的因果关联4类、切入回切规则、时长控制仍然适用，本Skill补充"空镜可以拍什么"和"怎么拍"。

---

## 一、空镜6大类型（按叙事功能分）

| 类型 | 功能 | 拍什么 | 时长建议 | 体裁偏好 |
|---|---|---|---|---|
| **定场空镜** | 建立地点/时间/氛围 | 城市/建筑/街景/室内全景 | 2-4秒 | 全体裁（开场必用） |
| **细节空镜** | 放大关键信息、材质证明 | 物件特写/手部动作/纹理质感 | 1-3秒 | 口播/产品/美食/科普 |
| **过程空镜** | 展示"怎么做"的步骤 | 做饭步骤/操作流程/行走路线 | 2-4秒/步 | 教程/产品/烹饪 |
| **反应空镜** | 捕听者/旁观者的情绪反应 | 表情微变化/手部动作/姿态 | 1-2秒 | 采访/对话/纪录 |
| **氛围空镜** | 营造情绪调性 | 光影变化/天气/烟雾/水面 | 2-3秒 | 剧情/文艺/Vlog |
| **留白空镜** | 情绪停顿、让观众消化 | 静物/空椅/窗外/远景 | 1-2秒 | 剧情/文艺 |

铁律：每一条空镜必须能回答"它为观众提供了什么信息"——如果是"只是好看"，归入氛围空镜但必须满足因果关联四类之一；如果连氛围关联都不满足，删除。

## 二、12种空镜创意玩法

### 2.1 慢动作细节空镜（升格微距）

适用场景：食物冒热气、水滴飞溅、手部精细动作、材质纹理

写法：
```
特写，[物体/动作]慢动作呈现，[细节1]和[细节2]清晰可见。
例：特写，热汤从勺子缓缓倒入碗中，汤汁在空中拉出金色弧线，
碗面蒸汽在慢动作中缓缓升腾。<汤汁声>
```

铁律：
- 慢动作必须写明"什么在慢动作中可见"，不能只写"慢动作"
- 适合1-3秒的短插入，不适合超过5秒的持续慢动作（节奏拖沓）
- 慢动作期间音效写低频环境声，不写台词

### 2.2 延时定场空镜

适用场景：时间跨度、城市脉动、天气变化

写法：
```
运镜：固定机位，延时摄影，[被压缩的时间过程]在数秒内快速呈现。
例：延时摄影，固定机位，窗外天空从深蓝渐变为暖橙，
对面楼的灯光依次亮起，3秒内呈现入夜过程。<快节奏环境声压缩>
```

铁律：
- 必须写明被压缩的具体变化过程，不能只写"延时摄影"
- 延时期间画面是纯空镜，台词以画外声持续

### 2.3 手部过程空镜

适用场景：做饭、手工、翻书、打字、操作设备、签字

写法：
```
特写，双手[具体动作]，[手部与物件的交互细节]。
例：特写，双手翻开病历本，手指停在某一页上，
指尖微微发抖，纸页边缘有折痕。<纸张翻动声>
```

铁律：
- 手部空镜必须承载叙事信息（翻病历=看病，签字=决定，打字=工作）
- 纯装饰性的手部特写（只是"好看的手"）禁止使用
- 手部空镜期间旁白可画外持续

### 2.4 桌面物件空镜

适用场景：口播/科普/产品讲解中的信息补充

写法：
```
特写/中景，桌面上[物件]的静物画面，[物件状态细节]。
例：特写，桌上摊开的保险合同，旁边放着一支笔和一副老花镜，
合同页面在暖光灯下微微泛黄。<纸张沙沙声，低>
```

铁律：
- 物件必须与当前台词/旁白内容有因果关联（说保险→拍合同，说看病→拍病历）
- 桌面物件不超过3件，避免杂乱
- 物件摆放有构图逻辑（三角构图/对角线/居中），不能随意堆放

### 2.5 天气/季节空镜

适用场景：情绪渲染、时间标记、场景过渡

写法：
```
中景/远景，[天气现象]笼罩[场景]，[光影/氛围细节]。
例：远景，细雨笼罩城市街道，路灯在雨幕中晕开暖黄光圈，
行人撑伞匆匆走过，地面水洼倒映霓虹。<雨声淅沥>
```

铁律：
- 天气空镜必须与台词情绪同频（说"困难时期"→雨天/阴天，说"转机"→雨后放光）
- 天气状态必须写具体（细雨/暴雨/薄雾/积雪/烈日），不能只写"天气不好"
- 天气空镜的色调要写明（冷调=阴郁，暖调=治愈，高饱和=活力）

### 2.6 光影氛围空镜

适用场景：情绪转折、内心独白、时间流逝暗示

写法：
```
中景，[光影变化描述]，[被光线照到的表面细节]。
例：中景，阳光透过百叶窗在墙壁上投下水平条纹光影，
光影缓缓移动，暗示时间流逝，灰尘在光束中飘浮。<安静环境声>
```

铁律：
- 必须写光源方向和类型（侧窗自然光/顶灯/台灯/霓虹），不能只写"光影"
- 光影变化必须有叙事含义（移动=时间，闪烁=不安，渐暗=结束）
- 纯装饰光影（只是"好看的光"）必须满足因果关联四类之一

### 2.7 窗外/门外空镜（空间延伸）

适用场景：角色在室内时，窗外画面提供空间/时间/情绪信息

写法：
```
镜头从[室内角色]缓缓摇向[窗户/门口]，切入窗外画面：
[窗外场景描述]，[与室内的氛围对比]。
例：镜头从病床旁的女儿缓缓摇向窗外，切入窗外空镜：
病房窗外城市天际线，黄昏暖光镀金对岸楼群，
与室内的冷白灯光形成冷暖对比。<远处城市声，低>
```

铁律：
- 窗外空镜必须与室内场景形成关联（对比/延伸/时间标记）
- 摇窗切入比硬切更自然（见空镜穿插通则"运镜引导切入"）
- 窗外画面中不出现与台词无关的随机内容

### 2.8 食物/饮品空镜

适用场景：美食Vlog、烹饪教程、生活日常

写法：
```
特写，[食物状态描述]，[热气/质感/色彩细节]。
例：特写，砂锅揭盖的瞬间，白色蒸汽升腾，
红烧肉在浓油中微微颤动，表面挂着琥珀色糖色光泽。<揭盖声+滋滋声>
```

铁律：
- 食物空镜必须写3个以上感官细节（颜色/质感/热气/声音/光泽）
- 食物状态要具体（"微沸""刚揭盖""筷子提起的瞬间"），不能只写"食物特写"
- 食物空镜与台词关联：说"最爱妈妈做的菜"→拍那道菜，不是随便一道菜

### 2.9 反应空镜（听者/旁观者）

适用场景：对话中的反应插入、采访中的听者表情、纪录片中的旁观者

写法：
```
近景，[听者名]嘴唇紧闭，[微表情细节]，[身体姿态]。
说话方声音转为画外声继续。
例：近景，女儿嘴唇紧闭，眉头微微皱起，眼眶泛红，
握着父亲的手微微收紧。父亲的声音转为画外声继续说话。<轻微呼吸声>
```

铁律：
- 反应空镜必须写具体微表情（不能只写"表情沉重"）
- 说话方转为画外声，不能静音
- 反应空镜1-2秒即切回，不宜超过3秒

### 2.10 倒影/镜面空镜

适用场景：暗示双面性、内心世界、虚实对比

写法：
```
中景，[反射面]中倒映着[场景/角色]，[倒影状态（模糊/晃动/变形）]。
例：中景，雨后水洼倒映着对面咖啡店的暖黄灯光，
倒影被涟漪打碎又重组，路人脚步踩过水洼，倒影碎裂。<雨后脚步声>
```

铁律：
- 倒影写成模糊/晃动的虚影，禁止倒影中出现可清晰辨识五官的人脸
- 必须写反射面状态（平静水面/涟漪/玻璃变形/镜面清晰）
- 倒影空镜与台词关联：说"两种人生"→倒影暗示双面性

### 2.11 脚步/行走空镜

适用场景：角色移动、时间推进、空间切换

写法：
```
低角度特写，[角色名]的[鞋/脚]踩在[地面材质]上，[步态节奏]。
例：低角度特写，女儿的平底鞋踩在医院走廊的浅色地砖上，
步伐从急促逐渐放慢，地砖反射走廊顶灯的白光。<脚步声由急到缓>
```

铁律：
- 脚步空镜必须写步态节奏（急促/缓慢/犹豫/坚定），步态=情绪
- 地面材质必须写（医院地砖/水泥路/沙地/草地），暗示环境
- 脚步空镜可做转场（走路场景A→走路场景B=空间切换）

### 2.12 道具转场空镜

适用场景：跨场景过渡、情绪切换

写法：
```
[前一场景末尾]，角色[触碰/拿起/放下某道具]；
[后一场景开头]，同一道具在不同场景中出现。
例1：角色翻开钱包看了一眼→硬切→同一钱包放在医院缴费窗口柜台上
例2：角色端起咖啡杯→硬切→同一咖啡杯放在办公桌上
```

铁律：
- 转场道具必须在前后场景中都出现，且状态有变化（钱包=从看→缴费，咖啡=从喝→放着）
- 道具必须与叙事关联（不是随手抓个杯子做转场）
- 前后两镜的道具位置/角度尽量对齐，便于匹配剪辑

## 三、各体裁空镜配比与节奏

| 体裁 | 空镜总占比 | 空镜类型偏好 | 节奏建议 |
|---|---|---|---|
| 口播/科普 | 20-30% | 细节空镜+桌面物件+手部过程 | 每4-5秒插一条空镜，防止口播画面单调 |
| 采访/对话 | 10-15% | 反应空镜+定场空镜 | 听者反应每8-10秒插入1次；定场仅开头用 |
| 剧情/短剧 | 15-20% | 氛围空镜+窗外空镜+倒影 | 空镜集中在情绪转折点，不在对话密集处 |
| Vlog/旅拍 | 30-40% | 定场空镜+食物空镜+脚步+天气 | 空镜与人像交替，节奏公式：人→空→人→空 |
| 产品/营销 | 25-35% | 慢动作细节+桌面物件+过程空镜 | 产品段空镜密集，前段人物表演为主 |
| 纪录片 | 20-30% | 过程空镜+反应空镜+延时定场 | 空镜与旁白节奏对齐，旁白停顿处留空镜 |

## 四、空镜与声音的组合规范

### 4.1 空镜期间必须有声音

空镜不是静默画面，声音类型优先级：

1. **台词/旁白画外声**（最高优先级）：台词持续播放，空镜做视觉注脚
2. **环境音效**（必保底线）：即使没有台词，也必须有 <环境音> 维持空间感
3. **静默**（仅限留白空镜）：纯静默≤2秒，必须为情绪留白服务

### 4.2 空镜音效写法

| 空镜类型 | 推荐音效 | 写法示例 |
|---|---|---|
| 定场空镜 | 城市环境声/自然声 | <远处城市低频环境声> |
| 细节空镜 | 与物件相关的材质声 | <纸张翻动声> / <键盘敲击声> |
| 过程空镜 | 动作过程音 | <切菜声+油锅滋滋声> |
| 反应空镜 | 极轻呼吸/环境 | <轻微呼吸声> |
| 氛围空镜 | 自然/天气声 | <雨声淅沥> / <风声低吟> |
| 留白空镜 | 极低频或静默 | <极轻远场环境声> 或 静默（≤2秒） |

### 4.3 空镜与台词的时间对齐

- 台词开始时空镜已经在画面中（不能台词先出再切空镜）
- 空镜期间台词以画外声形式持续，写法：旁白：{台词}（画外声，不写口型）
- 台词结束→空镜再留1秒情绪余韵→回切人物

## 五、空镜的常见错误 vs 正确写法

| ❌ 错误 | ✅ 正确 | 原因 |
|---|---|---|
| "医院走廊空镜" | "医院走廊中景，自然光从左侧窗户洒入，地砖反射白光，走廊尽头有绿色安全出口指示灯" | "空镜"不是描写，必须写画面内容 |
| "切一个天空空镜" | "远景，灰蓝色天空云层低垂，远处有薄雾笼罩的楼群轮廓" | 天空必须写状态和情绪色彩 |
| "食物特写" | "特写，砂锅揭盖瞬间白色蒸汽升腾，红烧肉表面琥珀色糖色光泽微微颤动" | 3个以上感官细节 |
| "手部动作" | "特写，右手食指和中指夹着笔尖在合同某行下方画了一条线，笔尖微微发抖" | 手部必须承载叙事+写微动作 |
| "反应镜头" | "近景，女儿嘴唇紧闭眉头微皱，握着父亲的手微微收紧" | 反应必须写微表情，不能写抽象情绪 |

## 六、空镜与Prompt分层结构的配合

空镜在Prompt第三层（画面阶段）中与台词/音效同步写，不单独分层：

```
第三层：画面阶段
  第0-3秒：中景，口播者面朝镜头说话
  @VOX_口播者 嘴唇随台词清晰张合，说：{那个社区医院就在我家楼下}
  第3-5秒：镜头从口播者缓缓摇向窗外，切入空镜——
  社区医院外观，三层白色小楼，门口有红色十字标识，
  几位老人坐在门口长椅上聊天，午后阳光照亮外墙。
  旁白：{那时候觉得生病变远}（画外声，不写口型）
  <远处街道声，低>
  第5-7秒：回切至口播者中景，口播者表情若有所思
```

注意：
- 空镜切入和回切都在画面阶段的时间轴中标注
- 空镜期间台词写"画外声，不写口型"
- 空镜必须有环境音效 <音效>

## 七、完整Prompt骨架示例

### 示例：口播+空镜穿插（10秒单段）

```
第一层：素材绑定 + 音色绑定
  参考@图片1的形象作为口播者，场景参考@图片2（书房内景）。
  @VOX_口播者 = 35岁男性，温和沉稳男中音；语速每秒4字；标准普通话；理性克制带温度；句中平稳换气；书房近场短混响

第二层：一句话概述
  书房内，口播者坐在桌前讲解保险产品，穿插桌面合同物件空镜和窗外氛围空镜

第三层：画面阶段
  第0-4秒：中景，口播者坐在书桌后面朝镜头，桌上摊着文件，暖色台灯光从左侧照亮面部
  @VOX_口播者 嘴唇随台词清晰张合，说：{很多人觉得保险太复杂，其实核心就三件事}
  第4-6秒：镜头缓缓下摇至桌面特写——
  桌上摊开的保险合同，旁边放着一支钢笔和一副老花镜，
  合同某一行被黄色荧光笔标注，暖色台灯光在纸面上形成柔和光斑。
  旁白：{保障、保费、理赔}（画外声，不写口型）
  <纸张沙沙声，低>
  第6-8秒：回切至口播者中景，口播者微微点头
  @VOX_口播者 嘴唇随台词清晰张合，说：{今天我们一个一个说清楚}
  第8-10秒：镜头从口播者缓缓摇向窗外，切入窗外空镜——
  书房窗外傍晚城市天际线，暖金色夕阳照亮对面的住宅楼群，
  几扇窗户亮起灯光。情绪余韵。
  <远处城市声，极低>

  Environmental SFX only. No music. No BGM.

第四层：约束
  五官清晰不变形、人体结构正常、服装发型一致，4K超高清、画面稳定无模糊、电影质感，不要生成水印，不要生成logo，保持无字幕
  时长：10秒，比例：16:9
```
