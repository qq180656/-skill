# 家属日常空镜 Skill

## 适用范围

当视频Prompt需要展现"家人身体不好"时，加载本Skill。覆盖身体衰退的微动作信号、日常空镜3大叙事层级、各身体状态的空镜清单、家庭场景光线与道具规范。

核心原则：**不拍"生病"，拍"做日常时力不从心"**。观众不需要看到病床才能理解身体不好——一双揉膝盖的手、一把扶着桌角才站起来的椅子、一锅忘了放盐的汤，比任何医院画面都更真实。

本Skill与「医院场景空镜Skill」互补：医院空镜拍"场所感"（这是医院），本Skill拍"人情感"（这个人正在承受什么）。两条线穿插，叙事完整度远超单用医院空镜。

## 一、身体衰退的微动作信号清单

### 1.1 上肢与手部信号

| 微动作 | 写法 | 暗示 |
|---|---|---|
| 揉膝盖/揉肩膀/揉腰 | "右手无意识地揉着右膝盖，手指在膝盖骨上缓缓画圈" | 关节痛/腰腿不适 |
| 手发抖 | "端碗的手微微发抖，碗里的汤洒出一点在桌面上" | 神经/体力衰退 |
| 放下东西很重 | "把菜刀搁在砧板上时动作明显变重，刀身在板上弹了一下" | 手部力量减退 |
| 抓东西抓不稳 | "伸手去拿桌上的杯子，手指试了两次才握住杯柄" | 精细动作能力下降 |
| 扶着东西才稳 | "右手扶着灶台才站稳，左手翻锅铲的动作明显比以前慢" | 平衡/体力不足 |

### 1.2 起坐与行走信号

| 微动作 | 写法 | 暗示 |
|---|---|---|
| 扶着桌角站起来 | "双手撑在桌面边缘，缓缓把身体推起来，起身后停了一秒才迈步" | 腰腿/膝关节退化 |
| 坐下时身体一沉 | "坐到沙发上时身体明显一沉，嘴里轻轻吸了一口气" | 腰/髋关节疼痛 |
| 上下楼梯停顿 | "上楼梯时右手扶着扶手，每上两级台阶停一下，左脚跟上来时微微拖步" | 膝/心肺功能 |
| 步伐变小变慢 | "从客厅到厨房的步子比以前小了半步，脚掌几乎贴着地面拖行" | 体力/平衡衰退 |
| 走到一半扶墙/扶家具 | "端着菜从厨房走到餐厅途中，左手扶了一下门框才继续走" | 体力不支/头晕 |

### 1.3 日常家务"力不从心"信号

| 微动作 | 写法 | 暗示 |
|---|---|---|
| 做饭动作变慢 | "切菜的速度比以前慢了，每切两三刀停一下，手指按菜的手微微打滑" | 体力/手部灵活性下降 |
| 忘了步骤/放了两次盐 | "往锅里加盐后犹豫了一下，又拿起来加了一次" | 记忆力减退 |
| 做到一半要坐下歇 | "炒到一半放下锅铲，扶着灶台走到旁边的椅子坐下喘口气" | 体力不支 |
| 东西做到一半放着 | "灶台上锅正开着火，老人却坐在旁边椅子上闭着眼，锅里的水快要溢出" | 精力/注意力下降 |
| 衣服没叠好就放着 | "叠到第三件衣服时手停了下来，衣服一半叠好一半摊在腿上，目光看向窗外" | 体力/精神倦怠 |

### 1.4 休息状态信号

| 微动作 | 写法 | 暗示 |
|---|---|---|
| 靠在沙发上睡着了 | "电视还开着，头微微歪向一侧，手里的遥控器滑到沙发缝里，呼吸声比平时重" | 持续疲惫/夜间睡眠差 |
| 吃完饭趴在桌上 | "碗还摆在面前，额头靠在叠起的手臂上，肩膀微微起伏" | 饭后困倦/体力差 |
| 坐着发呆 | "坐在窗边，手里的杯子已经凉了，目光停在一个方向很久没动" | 精神状态/抑郁倾向 |
| 阳台站一会儿就回来 | "在阳台上站了不到一分钟，扶着门框走回客厅坐下" | 站立体力/腿脚 |

铁律：每一条微动作空镜必须让观众"读出"身体出了问题，但不能写"痛苦""难受"这类抽象情绪。用可见的动作和细节让观众自己判断。

## 二、日常空镜3大叙事层级

### 层级A：环境先行（先拍空间，暗示人）

用空间和物件状态暗示人的状态，不拍人。

| 空镜类型 | 写法 | 暗示 |
|---|---|---|
| 厨房做到一半 | "中景，灶台上锅盖半开，蒸汽从缝隙里冒出，旁边的砧板上菜切了一半，刀搁在上面" | 做饭做到一半停下了 |
| 桌上饭菜没动 | "近景，餐桌上三菜一汤摆得整齐，碗筷已经摆好，但米饭一口没动，筷子横在碗沿上" | 人没来吃/没有食欲 |
| 沙发上的毯子 | "中景，沙发上叠着一条薄毯，旁边茶几上放着药盒（不拍药名）和一杯凉了的水" | 经常在沙发上休息 |
| 阳台晾了一半的衣服 | "中景，阳台晾衣杆上只挂了两件衣服，洗衣篮里还有没晾完的，洗衣机的门开着" | 晾到一半歇了 |
| 门口的拖鞋 | "近景，门口两双拖鞋，一双整齐放好，另一双东倒西歪地甩在一边" | 走路不稳/匆忙 |

### 层级B：局部入画（只拍手/脚/背影，不露脸）

拍人的局部，比拍全景更有代入感。

| 空镜类型 | 写法 | 暗示 |
|---|---|---|
| 手揉膝盖 | "特写，一双老人的手按在右膝盖上，手指缓缓揉着膝盖骨，指节因用力微微发白" | 关节痛 |
| 手扶桌角 | "特写，右手紧紧握住餐桌边缘，指节微微发白，手臂在微微用力撑起身体" | 起身困难 |
| 手端碗发抖 | "特写，双手捧着碗，碗里的汤微微晃动，手指在碗壁上微微颤抖" | 手部力量衰退 |
| 脚步拖行 | "低角度特写，一双布鞋的鞋底贴着地砖缓缓拖行，鞋尖在地砖上蹭出轻微摩擦痕迹" | 步态改变 |
| 背影扶墙 | "中景，背影，左手扶着走廊墙壁，身体微微前倾，步伐很小" | 行走困难 |

### 层级C：完整人物入画（拍全身/半身动作，有表情）

最直接的叙事层级，但最容易写成"表演过度"。

| 空镜类型 | 写法 | 暗示 |
|---|---|---|
| 切菜时停顿 | "中景，老人站在灶台前切菜，切到一半停了下来，手撑在砧板边上，低头缓缓呼了口气，然后又继续切" | 做饭变慢/体力下降 |
| 站起来停顿 | "中景，老人坐在沙发上，双手撑着沙发扶手缓缓站起，站起后停了两秒才迈步" | 起坐困难 |
| 看着窗外出神 | "近景，老人坐在窗边椅子上，手里拿着杯子但没喝，目光停在窗外，嘴角微微下垂" | 精神倦怠 |
| 上楼歇脚 | "中景，老人站在楼梯拐角处，右手扶着扶手，左手按着腰，微微低头喘气" | 体力衰退 |

铁律：A→B→C三个层级可以混合使用，但单条视频中至少使用2个层级。全程只拍C（完整人物）会像监控画面，全程只拍A（空环境）会太冷没有情感。

## 三、不同身体状态的空镜组合

### 3.1 关节/腰腿不好

推荐空镜序列（按叙事节奏排列）：

1. **A层级**：门口一双东倒西歪的拖鞋（近景）
2. **B层级**：手揉膝盖，指节发白（特写）
3. **C层级**：上楼时停在拐角扶腰喘气（中景）
4. **B层级**：脚贴着地砖拖行（低角度特写）
5. **A层级**：沙发上的毯子和茶几上的水杯（中景）

### 3.2 心血管/体力差

推荐空镜序列：

1. **A层级**：灶台上锅开着火，人不在（中景）
2. **C层级**：做饭到一半扶灶台歇气（中景）
3. **B层级**：手端碗微微发抖（特写）
4. **C层级**：靠在沙发上睡着了，电视还开着（中景）
5. **A层级**：阳台上空椅子（中景，暗示站了一会就回来了）

### 3.3 记忆力减退

推荐空镜序列：

1. **A层级**：灶台上锅烧着，旁边放着已经放过的调料（暗示放了两次）
2. **C层级**：老人站在厨房中间，手按着额头，像在想什么（近景）
3. **A层级**：桌上翻开的相册，一张老照片被反复翻看（近景）
4. **C层级**：老人对着电话发呆，拨了号又挂掉（中景）
5. **A层级**：冰箱上贴着密密麻麻的备忘便签（近景）

### 3.4 精神状态/情绪低落

推荐空镜序列：

1. **C层级**：坐在窗边发呆，杯子凉了没喝（近景）
2. **A层级**：餐桌上饭菜没动（近景）
3. **C层级**：阳台站了一分钟就回来了（中景）
4. **B层级**：手搁在膝盖上，一动不动（特写）
5. **A层级**：客厅只有一盏小灯亮着，其余暗着（中景，暗示不怎么活动了）

## 四、家庭场景光线与色调规范

| 家人状态 | 推荐色调 | 光线写法 | 情绪 |
|---|---|---|---|
| 还能自理但明显变慢 | 暖光但偏暗 | "午后阳光从窗户照进来但只照亮了一小块，客厅大部分在阴影中" | 温暖但有隐忧 |
| 间歇性不适 | 暖冷交替 | "厨房暖光灯下切菜→走到客厅时光线变暗偏冷" | 反复/不稳定 |
| 持续不好转 | 偏冷偏暗 | "阴天灰白光线透过薄窗帘照进来，室内光线灰暗平淡" | 压抑/无力 |
| 好转/有人照顾 | 暖光回归 | "夕阳暖光从窗户照进来，照亮了桌上的热汤和两个人影" | 温暖/希望 |

铁律：家庭空镜的光线就是无声的叙事。同一扇窗户，前半段阴天灰光=身体不好，后半段暖光=转好或有人陪。必须写光线状态，不能只写"客厅"。

## 五、家庭空镜的道具规范

### 5.1 安全道具（可拍）

| 道具 | 写法 | 暗示 |
|---|---|---|
| 保温杯 | "茶几上一个白色保温杯，盖子没拧紧" | 经常喝热水/需要保暖 |
| 拐杖 | "门后靠着一根木拐杖，把手磨得发亮" | 行走需要辅助 |
| 便签/备忘 | "冰箱上贴着四五张黄色便签，字迹有些潦草" | 记忆力减退 |
| 老花镜 | "老花镜搁在摊开的报纸上，一条镜腿微微翘起" | 年龄/日常 |
| 薄毯 | "沙发上叠着一条米色薄毯，边角有洗过多次的毛边" | 经常在沙发上休息 |
| 药盒（不拍药名） | "床头柜上一个白色分格药盒，几格是空的，几格还有药片（不拍药名标签）" | 在吃药/用药管理 |

### 5.2 禁止道具

| 禁止项 | 原因 |
|---|---|
| 药品包装上的药名/品牌 | 品牌侵权+处方药暗示 |
| 血压计读数 | AI生成的数值不可信 |
| 血糖仪读数 | 同上 |
| 医院检查报告上的文字 | 隐私+AI生成文字必然乱码 |

## 六、家庭空镜与医院空镜的穿插节奏

| 视频阶段 | 先拍什么 | 再拍什么 | 逻辑 |
|---|---|---|---|
| 发现问题 | 家庭日常空镜（微动作信号） | — | 先建立"人"的连接，观众先认识这个人 |
| 去医院 | 家庭空镜（出门前一刻） | 医院空镜（建筑外观定场） | 从家→医院的地理过渡 |
| 检查/诊断 | 医院空镜（候诊/走廊/缴费） | — | 医院段纯医院空镜 |
| 住院陪护 | 医院空镜（病房窗边/手握着手） | — | 医院段纯医院空镜 |
| 出院回家 | 医院空镜（门口走出） | 家庭空镜（进门一刻/坐到沙发上） | 从医院→家的地理过渡 |
| 后续日常 | 家庭日常空镜（好转/未好转的对比） | — | 回到家后的对比叙事 |

节奏铁律：
- **先家后院**：先拍家庭日常空镜让观众认识这个人，再拍医院空镜才有情感重量
- **过渡有桥**：家→医院和医院→家的转换必须各有一条过渡空镜，不能硬切
- **医院段不插家庭空镜**：医院段落里只拍医院空镜，不切回家拍（会打断紧迫感）
- **回家后才有对比**：出院回家的家庭空镜和发现症状时的家庭空镜形成对比（同一个厨房，同一个沙发，光线/动作/情绪不同）

## 七、完整Prompt骨架示例

### 示例：保险口播——妈妈身体不好日常段（10秒单段）

```
第一层：素材绑定 + 音色绑定
  参考@图片1的形象作为口播者，场景参考@图片2（家庭厨房/客厅）。
  @VOX_口播者 = 33岁女性，温和坚定女中音；语速每秒7字（保险批次；非保险项目约4字/秒）；标准普通话；心疼但克制；句前轻吸气；家庭近场短混响

第二层：一句话概述
  家庭厨房，口播者讲述妈妈身体变差的日常，穿插妈妈做饭时力不从心的空镜

第三层：画面阶段
  第0-3秒：中景，口播者坐在客厅沙发上，背后是厨房方向，
  厨房暖光灯亮着但只照亮了一小块区域，客厅大部分在午后阴影中。
  @VOX_口播者 嘴唇随台词清晰张合，说：{去年开始我妈做饭越来越慢了}
  第3-5秒：镜头缓缓摇向厨房方向，切入空镜——
  中景，妈妈站在灶台前，右手拿着锅铲翻菜，翻了两下停下来，
  左手撑在灶台边上，低头缓缓呼了口气，然后又继续翻菜。
  旁白：{但她从来不肯说哪里不舒服}（画外声，不写口型）
  <油锅滋滋声>
  第5-7秒：回切至近景，口播者低头看着自己交握的手
  @VOX_口播者 嘴唇随台词清晰张合，说：{后来我才知道她膝盖已经疼了三年}
  第7-10秒：镜头从口播者缓缓摇向茶几，切入空镜——
  近景，茶几上一个白色保温杯和一盒分格药盒（不拍药名），
  旁边沙发扶手上搭着一条米色薄毯，薄毯边角有洗过多次的毛边。
  午后阳光从窗户照进来，只照亮了茶几这一小块。
  <安静环境声>

  Environmental SFX only. No music. No BGM.

第四层：约束
  禁止画面中出现医生（白大褂/听诊器）、护士、医护角色、药品名称/药盒品牌/处方药等医疗敏感元素，同时禁止出现医疗仪器特写（心电监护仪读数、输液架输液瓶、手术灯）。药盒只拍外观不拍药名标签。（约束层见 prompt_craft_guide.md 第四层唯一权威版：真实摄影质感+禁明星脸+禁医护+禁电子屏幕+无水印无字幕）
  时长：10秒，比例：16:9
```
