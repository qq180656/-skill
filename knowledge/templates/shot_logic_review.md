# 镜头逻辑自审

> 用于单段 Prompt 的画面阶段自审，以及多段 storyboard 的 shot 间自审。目标是检查同一物理场景内的镜头状态是否连续、自洽、可生成。对标平台原生 `shot-logic-review.md`，适配保险视频场景。

## 场景状态表

按时间顺序维护内部状态表，不写入最终交付内容：

| 状态项 | 检查内容 |
|--------|----------|
| 角色位置 | 角色在场景中的具体位置、与关键物件的距离、画面左/右/前/后关系 |
| 银幕侧 | 同一角色在连续镜头中的画面左侧/右侧关系 |
| 朝向 | 面朝镜头、背对镜头、侧身朝左/右、视线目标 |
| 注视轴 | 看书/看手机/读信等动作中，眼睛→目标内容面→镜头侧是否一致 |
| 对峙互视轴 | 对立双方是否真实面朝彼此；同框时近景/远端、左/右双方的绝对朝向是否相对 |
| 姿态 | 站立、坐下、跪地、倒地、倚靠、奔跑、停步等身体状态 |
| 动作结果 | 上一阶段动作是否完成，下一阶段是否承接该结果 |
| 手中道具 | 道具在谁手里、哪只手、是否交接/掉落/收起 |
| 环境锚点 | 桌边、门框、台阶、墙面、车门、柜台、病床等可见承接物 |
| 情绪状态 | 情绪是否有触发事件和表情递进 |
| 画面焦点 | 镜头为什么从当前主体切到下一主体，叙事焦点是否有因果 |
| 机位路径 | 运镜起点/终点、移动方向、机位高度、景别跨度是否可连续到达 |

## 必须拦截的冲突

- **位置冲突**：上一镜角色在门口、桌边、画面左侧或场景远端，下一镜没有走位或转场却出现在窗边、画面右侧或另一空间
- **银幕方向冲突**：同一场对话、追逐、对峙中，角色左右关系无机位说明地翻转
- **朝向冲突**：上一镜背对镜头离开，下一镜立刻正面站定；上一镜侧身朝左，下一镜无转身动作变成侧身朝右
- **对峙互视轴冲突**：两人对峙时禁止都面朝镜头。前后纵深写近景一方背对/侧背对镜头、远端一方面朝镜头；左右对峙写左侧侧身朝右、右侧侧身朝左。**适用范围：剧情对峙/争吵/谈判等角色面对面交互场景。口播/带货场景说话者面朝镜头念台词、听者侧头看说话者但脸朝镜头侧3/4，不适用本条——口播场景的空间锁定见 `prompt_craft_guide.md` 多人场景空间锁定模块。**
- **注视轴冲突**：看手机/保单/条款时人物持续正脸直视镜头，或屏幕无剧情理由地正对镜头
- **动作状态冲突**：上一镜动作已完成，下一镜又重复同一动作；上一镜动作未完成，下一镜直接进入结果状态
- **道具状态冲突**：上一镜右手拿保单/手机/杯子，下一镜没有交代却空手、换手、道具消失或凭空出现
- **身体/环境锚点冲突**：上一镜靠墙、坐在病床边、抓住门框，下一镜没有起身/松手却站在空地
- **情绪跳变冲突**：上一镜平静交谈，下一镜突然崩溃或暴怒，但没有触发事件和表情递进
- **镜头焦点冲突**：同一场景连续镜头的叙事焦点无因果跳转
- **机位路径冲突**：连续运镜中机位位置/高度/景别已收束到特定主体，下一阶段却无切镜说明地跳到大范围空间
- **机位-景别自矛盾**：远机位词（全景/远景）与近机位诉求（面朝镜头/正脸口型）并存于同句
- **阶段密度冲突**：同一阶段同时要求多个无因果关系的核心动作

## 保险视频特化检查项

除通用检查外，保险视频还需额外关注：

| 检查项 | 说明 |
|--------|------|
| 医护形象合规 | 画面中不出现医护服装/白大褂/听诊器（除非用户明确要求且合规通过） |
| 药品/器械合规 | 不出现具体药名、医疗器械品牌标识 |
| 警示语挂载点 | 分镜中标注的警示语触发句时间点与画面内容匹配 |
| 场景推断标注 | 推断场景标注"场景为推断"供用户确认 |
| 产品名出现时机 | 产品名只在脚本指定的镜头出现，不提前透露 |
| 转场自然性 | 医院场景→家庭场景等跨场景转场需有过渡（空镜/光影变化/角色移动） |

## 自审流程

1. **单段自审**：构造完每段Prompt后，按场景状态表逐项标注当前状态，检查阶段间是否有冲突
2. **多段自审**：所有段构造完成后，按段顺序维护跨段状态表，检查段间衔接处是否有冲突
3. **保险特化自审**：在通用自审通过后，额外跑保险视频特化检查项
4. **冲突修复**：发现冲突时优先在Prompt中补足走位/转身/道具交接描写；无法补足则调整分镜拆分
