# 角色锁定协议

## 强制规则

- **逐镜头传参**：每个镜头的ImageList都必须传入该镜头所有出场角色的参考图，工具无状态，不会记忆之前的角色
- **视觉锁定由参考图承担**：已传参考图的角色Prompt只写「参考@图片N的形象作为{角色名}」，禁止复写图上可见的静态外观
- **风格基准统一**：AI生成角色参考图时（如游戏广告、动画角色），建议引用同一个风格锚点（style_anchor.png）确保画风一致；真人参考图场景不需要风格锚点，风格统一通过参考图本身的拍摄风格/光影/滤镜一致实现。主要风格锁定方式是文字关键词（见 style_reference.md），风格锚点图为可选辅助
- **群像例外**：无姓名、无独立身份的群像/类型角色（孩童、老人、村民、路人等）不生成四视图，改用群像类型参考图（character_xxx_group.png），只锁定年龄层、服饰、发型和群体气质，允许个体有轻微差异
- **多形象规则**：同一角色有多个显著外观变化时，每个形象生成独立参考图，每段只传当前形象图；段内发生形象切换时才同时传切换前后两张图，并在Prompt明确阶段

## 角色锁定卡模板

```
### [角色名] 锁定卡
| 字段 | 内容 |
|------|------|
| 面型 | {描述，如：鹅蛋脸} |
| 眼型+瞳色 | {描述，如：大杏眼、棕色瞳孔} |
| 发色 | {描述，如：乌黑} |
| 发型+长度 | {描述，如：齐肩直发} |
| 肤色 | {描述，如：白皙肤色，脸颊微红} |
| 体型 | {描述，如：纤瘦，约165cm} |
| 标志特征 | {描述，如：左耳银色耳钉、鼻梁小雀斑} |
| 默认服装 | {描述，如：白色衬衫、藏蓝百褶裙} |
| 参考图文件 | {sheet: character_xxx_sheet.png 或 用户原照: upload/xxx.png} |
| 音色锚定文件 | voice: voice_xxx.mp3（主要角色+有台词时生成） |
```

## 多角色场景引用规则

| 场景 | ImageList排列 | Prompt引用方式 |
|------|--------------|----------------|
| 单角色镜头 | [sheet, scene] | 参考@图片1的角色形象，场景参考@图片2 |
| 双角色镜头 | [A_sheet, B_sheet, scene] | @图片1的[A角色名]与@图片2的[B角色名]，场景参考@图片3 |
| 群像/类型角色镜头 | [group_ref, scene] | 参考@图片1的{群体类型}造型范围，场景参考@图片2 |

### 多角色布局控制（见 `scripts/multi_character_layout_spec.md`）

上表解决"个体形象锁定"，但多角色镜头还需控制角色间的空间关系，防止角色融合/变脸。完整方案见上述 spec，要点：

- **策略 A（角色解耦引用法）**：Prompt 中强制加入方位词（"角色A位于画面左侧，角色B位于画面右侧"），禁止用"两人在一起"等模糊描述
- **策略 B（空间占位锚定法）**：先定义构图底座（画面分左/中/右区域），再逐角色填入方位，最后描述交互动作
- **角色锁定卡扩展**：多角色场景需新增三个布局属性字段：典型站位、交互关系、视觉优先级
- **角色融合拦截**：轻量级修 Prompt 加隔离词（"两人中间有桌子隔开"），重做级改用分镜规避（拆成单人镜头+镜头切换）
- **能力边界**：物理接触类镜头（拥抱等）融合风险高，应通过 VERIFYING 高风险人工审核解决，不做无限重试

## 红线

- 禁止只在第一个镜头传角色参考图，后续镜头不传，导致角色变脸
- 禁止使用多张独立图片（面部特写与全身视图分开生成），必须用一张四视图设定稿确保一致性
- 禁止在Prompt中复写参考图上可见的外观描述，占用信息密度且易引发文图冲突
- 禁止同一角色换形象后沿用错误参考图，或把多个形象都塞进每一段导致串台

## 人物参考图（四视图角色设定稿）

固定格式：同一角色的正面头肩特写 + 正面/侧面/背面三个完整全身视图横向排列，三个全身视图从头顶完整到脚尖，纯白色背景，均匀平光照明，无阴影。

Prompt模板：
```
{角色由头到脚的物理白描外观描述}的四视图角色设定稿，
同一角色的人物正面头肩特写、正面、侧面、背面三个完整全身视图横向排列，人物特写只显示头部至肩部，不显示腰部、腿部和脚，
三个全身视图从头顶完整展示到脚尖，自然站立、双足平踏地面、平视镜头，
四视图角色特征与服装细节完全一致，色彩准确统一。
纯白色背景，均匀平光照明，无明显阴影。
{风格关键词}。
正面、侧面、背面三个全身视图严禁裁切下半身，人物特写禁止生成成全身视图，禁止生成任何背景、文本、标注、字幕。
比例:16:9
```

物理白描要求：从头发到脚连贯描述，按顺序：骨相→面部→发型→配饰→上衣→下装→鞋履，禁用笼统脸型词，用骨相矩阵差异化（面部折叠度+颅骨比例+下颌角折角+皮肉包裹度）

## 场景参考图

固定格式：纯空镜环境概念图，无人物、无人影、无剪影，默认高角度俯拍（约45°）暴露完整空间布局。

Prompt模板：
```
高角度俯拍的纯空镜场景，从上方约45度角俯瞰{空间名称}整体布局。
核心主体:{建筑/空间结构 + 具体材质 + 固有色}。
地面:{材质纹理 + 家具/物件分布位置}。墙面/边界:{围合结构与开口}。顶部:{可见的梁/顶/棚结构}。
{光源方向 + 在地面形成的光区/暗区分界 + 空气感}。
强化俯视空间布局感，材质物理质感清晰。
无人物、无人影、无剪影、纯空镜场景，禁止生成任何文本、标注、字幕。
{风格关键词}。
比例:{跟随视频最终比例}
```

## 参考图红线

- 禁止在参考图Prompt中使用8k/photorealistic/RAW/V-Ray/Unreal/85mm/电影感光影等技术黑话
- 角色参考图禁止加入任何背景、场景、天气、地点描述
- 场景参考图必须纯空镜，禁止出现任何人物/人影/剪影
- 风格锚是AI生成参考图时的图像层基准，不是滤镜；AI生成参考图时建议引用它确保风格统一，真人参考图场景不适用
