# 角色锁定协议

## 强制规则

- **逐镜头传参**：每个镜头的ImageList都必须传入该镜头所有出场角色的参考图，工具无状态，不会记忆之前的角色
- **音色锚定逐镜头传参**：有音色锚定音频的角色，每次视频生成调用必须通过 AudioList 传入该镜头所有说话角色的 voice mp3。Seedance 2.5 可纯音频参考；其他模型 AudioList 不能单独使用；有出镜且需身份锁定的角色仍须传对应 ImageList
- **用户已上传角色照片时例外**：用户原照直接用作参考图，禁止再生成四视图，锁定卡描述从原照可见特征提取
- **视觉锁定由参考图承担**：已传参考图的角色Prompt只写「参考@图片N的形象作为{角色名}」，禁止复写图上可见的静态外观。需要文字描述的仅三类：①图上不可见的特征；②本段需改变的特征（写明"此段不按参考图"）；③无参考图的角色——此时锁定卡描述逐字复制，禁止近义词改写
- **单图不超4人**：每张参考图中人物不超过4个，超过时分批生成
- **风格基准统一**：启用风格锚定的项目，所有角色参考图（含中途新增角色）生成时 ImageList 必须传入 @style_anchor，引用语见下方四视图规范；真人参考图场景不需要风格锚点，风格统一通过参考图本身的拍摄风格/光影/滤镜一致实现。主要风格锁定方式是文字关键词（见 style_reference.md），风格锚点图为可选辅助
- **群像例外**：无姓名、无独立身份的群像/类型角色（孩童、老人、村民、路人等）不生成四视图，改用群像类型参考图（character_xxx_group.png），只锁定年龄层、服饰、发型和群体气质，允许个体有轻微差异
- **多形象规则**：同一角色有多个显著外观变化时，每个形象生成独立参考图，每段只传当前形象图；段内发生形象切换时才同时传切换前后两张图，并在Prompt明确阶段。所有形象共用一组身份锚点和一个角色名，默认共用一个角色级音色文件

## 角色锁定卡模板

```
### [角色名] 锁定卡
| 字段 | 内容 |
|------|------|
| 面型 | {描述，如：鹅蛋脸} |
| 眼型+瞳色 | {描述，如：大杏眼、棕色瞳孔} |
| 发色 | {描述，如：乌黑} |
| 发型+长度 | {描述，如：齐肩直发} |
| 肤色 | {描述，如：白皙肤色，脸颊微红} |
| 体型 | {描述，如：纤瘦，约165cm} |
| 标志特征 | {描述，如：左耳银色耳钉、鼻梁小雀斑} |
| 默认服装 | {按穿搭四维模型展开：色彩搭配(主色+辅色+点睛色+色温) / 单品层次(外层→内层→下装→鞋履，标面料+颜色+叠穿露出位置) / 配饰系统(从头到脚，标呼应关系) / 氛围质感(风格关键词+面料动态物理特征)} |
| 参考图文件 | {sheet: character_xxx_sheet.png 或 用户原照: upload/xxx.png} |
| 音色锚定文件 | voice: voice_xxx.mp3（主要角色+有台词时生成） |
```

## 多角色场景引用规则

| 场景 | ImageList排列 | Prompt引用方式 |
|------|--------------|----------------|
| 单角色镜头 | [sheet, scene] | 参考@图片1的角色形象，场景参考@图片2 |
| 双角色镜头 | [A_sheet, B_sheet, scene] | @图片1的[A角色名]与@图片2的[B角色名]，场景参考@图片3 |
| 群像/类型角色镜头 | [group_ref, scene] | 参考@图片1的{群体类型}造型范围，场景参考@图片2 |

> **多角色布局控制**（空间占位锚定法 / 角色融合拦截 / 布局属性字段 / 策略 A·B）见 `multi_character_layout_spec.md`——本表只给 ImageList 排列与引用方式，多角色的站位稳定与防融合控制在该文件。

## 红线

- 禁止只在第一个镜头传角色参考图，后续镜头不传，导致角色变脸
- 禁止使用多张独立图片（面部特写与全身视图分开生成），必须用一张四视图设定稿确保一致性
- 禁止在Prompt中复写参考图上可见的外观描述，占用信息密度且易引发文图冲突
- 禁止同一角色换形象后沿用错误参考图，或把多个形象都塞进每一段导致串台

## 人物参考图（四视图角色设定稿）

固定格式：同一角色的正面头肩特写 + 正面/侧面/背面三个完整全身视图横向排列，三个全身视图从头顶完整到脚尖，纯白色背景，均匀平光照明，无阴影。

Prompt模板：
```
{角色由头到脚的物理白描外观描述}的四视图角色设定稿，
同一角色的人物正面头肩特写、正面、侧面、背面三个完整全身视图横向排列，人物特写只显示头部至肩部，不显示腰部、腿部和脚，
三个全身视图从头顶完整展示到脚尖，自然站立、双足平踏地面、平视镜头，
四视图角色特征与服装细节完全一致，色彩准确统一。
纯白色背景，均匀平光照明，无明显阴影。
{风格关键词}。
正面、侧面、背面三个全身视图严禁裁切下半身，人物特写禁止生成成全身视图，禁止生成任何背景、文本、标注、字幕。
比例:16:9
```

物理白描要求：从头发到脚连贯描述，按顺序：骨相→面部→发型→配饰→上衣→下装→鞋履，禁用笼统脸型词，用骨相矩阵差异化（面部折叠度+颅骨比例+下颌角折角+皮肉包裹度）

## 场景参考图

固定格式：纯空镜环境概念图，无人物、无人影、无剪影，默认高角度俯拍（约45°）暴露完整空间布局。

Prompt模板：
```
高角度俯拍的纯空镜场景，从上方约45度角俯瞰{空间名称}整体布局。
核心主体:{建筑/空间结构 + 具体材质 + 固有色}。
地面:{材质纹理 + 家具/物件分布位置}。墙面/边界:{围合结构与开口}。顶部:{可见的梁/顶/棚结构}。
{光源方向 + 在地面形成的光区/暗区分界 + 空气感}。
强化俯视空间布局感，材质物理质感清晰。
无人物、无人影、无剪影、纯空镜场景，禁止生成任何文本、标注、字幕。
{风格关键词}。
比例:{跟随视频最终比例}
```

## 参考图红线

- 禁止在参考图Prompt中使用8k/photorealistic/RAW/V-Ray/Unreal/85mm/电影感光影等技术黑话
- 角色参考图禁止加入任何背景、场景、天气、地点描述
- 场景参考图必须纯空镜，禁止出现任何人物/人影/剪影
- 风格锚是AI生成参考图时的图像层基准，不是滤镜；AI生成参考图时建议引用它确保风格统一，真人参考图场景不适用

## 三步逐级传递出图流程（v4.3新增）

> 本节为推荐流程，详见 `character_asset_pipeline.md`。用户已上传角色照片时跳过本流程。

### 流程概述
角色参考图建议按S1→S2→S3三步逐级传递出图，每步出完停下来等用户确认：

| 步骤 | 产物 | 画幅 | 职责 | 身份依据 |
|------|------|------|------|---------|
| S1 | 单张大头 | 竖构图2K | 验脸闸门，像才往下走 | 原图或问诊设定 |
| S2 | 面部四视图 | 3:4 | 锁脸型轮廓、五官、发型 | S1的成图 |
| S3 | 全身四视图 | 9:16 | 锁身高比例与服装 | S2的成图 |

### 与四视图角色设定稿的关系
- S2/S3的产出可直接作为本文件上方的"四视图角色设定稿"使用
- S2对应面部四视图，S3对应全身四视图
- S3的全身四视图产出后，按本文件的"角色锁定卡模板"登记锁定卡

### 验脸闸门自检（S1出图后必做）
1. 拼一张并排对照图（原图 | 生成图）
2. 逐项核对六项：脸型轮廓、眼睛大小与眼距、鼻梁高度与鼻头形状、唇的厚薄与唇峰、发型轮廓与发际线、原图可见的配饰
3. 不通过则改提示词重出，绝不带着不像的脸往下走

### 服装字段规则（S3出图时必查）
- 可见的照抄，不可见的绝不补全
- 需要补全时先问用户，给三个选项：裁到可见范围/用户指定/按原风格拟一版
- 同一人物服装字段全程复用同一个值

### 保险多角色出图顺序建议
1. 先出主角（通常妈妈或爸爸）的S1→S2→S3
2. 主角确认后再出第二角色的S1→S2→S3
3. 孩子角色如果只出镜不说话，可只做到S2
4. 销售/医生等配角用群像类型参考图即可
