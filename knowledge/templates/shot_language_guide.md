# 镜头语言速查 (Shot Language Guide)

> 9 种核心镜头类型的**使用场景与创作意图**。分镜设计时按场景需求选镜头,不要默认全用中近景口播。给模型的 Prompt **只写具体景别/动作描述,不写抽象术语**(如"正反打""OTS")——模型不懂术语,但能执行"切至B近景面部特写,B微微点头"。

---

## 1. 反打镜头(Shot Reverse Shot)

**什么时候用**:
- **覆盖对白**:切到反打让观众站到听的人这一边,一段对话成了一来一回,而不是一个人的独白
- **接住回答**:反打镜头正好接住回应,让观众从一张脸上先读出答案,再听见它被说出口
- **视线与权力**:正反打之间对上的视线交代了谁在看谁;角度高低能悄悄倾斜谁占上风
- **审讯与对峙**:隔着桌子紧密来回的反打,是对峙戏天然的节奏

**Prompt 写法(≤30s 段内切镜)**:
```
第0-5秒：近景，A面朝镜头，嘴唇张合说：{A的台词}
第5-10秒：切至B近景面部特写，B微微点头后开口，嘴唇张合说：{B的台词}
```

**保险场景典型用法**:街采记者提问→路人回答;家庭对话妈妈担心→爸爸解释

---

## 2. 过肩镜头(Over-the-Shoulder / OTS)

**什么时候用**:
- **对话戏份**:两个过肩画面来回切换,让每一句台词都落在听的人脸上
- **锁定空间关系**:近处的人留一点在画面里,观众才能清楚知道两人的位置和朝向
- **制造紧张感**:近处肩膀压满画面一角、逼向对面角色,用于对峙和压迫感强的场景
- **对峙与谈判**:两个立场相对的人分置桌子两侧,那道肩膀就是他们之间的界线

**Prompt 写法**:
```
第X-Y秒：过肩视角，A的肩膀和后脑勺占画面左前景约1/3（虚化），
焦点落在B的脸上，B表情凝重，嘴唇张合说：{台词}
```

> ⚠️ Seedance 单次调用内**禁止**摄影机从A肩绕拍到B肩(漫游机位),过肩镜头只做固定或单向推拉。

---

## 3. 主观镜头(POV / Subjective Shot)

**什么时候用**:
- **拉进动作**:第一人称视角是最有代入感的呈现,适合紧张刺激或强烈身体动作场景
- **揭示角色看到的东西**:让观众和角色在同一瞬间看见他们注意到的东西
- **拉近情感距离**:透过角色的双眼看世界,比文字描述更能缩短观众与角色的距离

**Prompt 写法**:
```
第X-Y秒：第一人称视角，镜头模拟角色A的眼睛高度，
画面中看到{A看到的场景/物品/人},画面随A的头部轻微晃动。
```

**保险场景典型用法**:患者躺在病床上看到天花板→护士推门进来(代入住院体验)

---

## 4. 鸟瞰镜头(Bird's Eye / Top-Down)

**什么时候用**:
- **衬托渺小**:从高处往下一压,角色立刻变小,表现孤立、无力最直接
- **读出图案**:人群、田野、路网从空中看会自己排出形状和走向
- **俯视的注视**:居高临下容易让人想到监视或命运的注视
- **交代布局**:短视频开场常用鸟瞰起手,先把方位交给观众再切进去

**Prompt 写法**:
```
第0-3秒：俯拍鸟瞰，镜头从正上方垂直俯瞰{场景}，
角色A渺小的身影独自走在{环境描述}中。
```

---

## 5. 双人镜头(Two-Shot)

**什么时候用**:
- **交代关系**:两人放进同一画面,姿态、距离和视线不用台词就能说清关系
- **不切镜演对话**:一整段对话用一个双人镜头拍完,两人始终同框,不需要来回切
- **用距离制造张力**:拉开或收拢两人之间的空间,在同一稳定画面里调高或调低紧张感
- **一个连接的瞬间**:重逢、拥抱或安静的共同劳作,两张脸都留在画面里情绪更打动人

**Prompt 写法**:
```
第X-Y秒：中景双人同框，A站在画面左侧面朝右侧，B站在画面右侧面朝左侧，
两人间隔约一臂距离，{互动动作描述}。
```

**保险场景典型用法**:街采记者+路人同框建立空间关系;家庭场景夫妻/母子同框

---

## 6. 牛仔镜头(Cowboy Shot / Medium-Long)

**什么时候用**:
- **对峙时刻**:把手和腰部一起收进画面,全身读出蓄势待发
- **展现气场**:大腿取景能同时展现姿态和气质,适合介绍自信、有存在感的角色
- **手部动作重要时**:手在做关键事(握手机展示App、递保单、比手势),牛仔镜头能把手和脸一起收进画面

**Prompt 写法**:
```
第X-Y秒：中远景（大腿以上取景），A自信站立，
一手拿着手机屏幕朝向镜头展示{内容}，另一手自然下垂。
```

---

## 7. 全身镜头(Full Shot)

**什么时候用**:
- **角色设定**:从头到脚的一帧画面能同时呈现服装、剪影和姿态,是设计角色的标准参考
- **环境交代**:全身镜头会带出完整环境,适合建立"人在哪"的空间感

**保险场景典型用法**:角色四视图设定稿(三个全身视图横排);街头采访开场全景交代街道环境

---

## 8. 反应镜头(Reaction Shot)

**什么时候用**:
- **让台词落地**:台词砸出去的那一刻切到听的人,观众从这张脸上读出分量
- **堆积悬念**:揭晓的瞬间切到旁观者的脸,恐惧或期待透过别人眼神传给观众
- **短视频节奏**:反应镜头是短视频剪辑的常用节拍,一个眼神就能敲实一个瞬间的情绪

**Prompt 写法**:
```
第X-Y秒：切至B近景，B听到A的话后{可见表情反应：睁大眼睛/皱眉/嘴角上扬/点头},
嘴唇紧闭不说话，约1-2秒。
```

> ⚠️ **反应镜头不能省**:多人对话中,听者不能写"嘴唇闭合不出声"就完事(渲染成蜡像)——必须有侧头看说话者+点头/皱眉等可见微表情。

---

## 9. 插入镜头(Insert / Cutaway)

**什么时候用**:
- **埋下关键信息**:当观众需要看清广角藏起来的细节,插入镜头能干净利落交代
- **积累紧张感**:切到一个滴答的钟或一只发抖的手,靠聚焦一件事绷紧整场戏
- **产品细节**:产品视频和教程的骨架,稳稳停在物件上让观众看清楚
- **为剪辑留余地**:简短插入镜头能给一个干净的切点,抹平时间或机位的跳跃

**Prompt 写法**:
```
第X-Y秒：特写，镜头聚焦{物品/细节}，{物品状态描述}，
画面稳定不晃动，约2秒。
```

**保险场景典型用法**:手机屏幕展示支付宝App;医疗账单特写;保单文件细节

## 镜头选择速查表(保险视频常用组合)

| 场景类型 | 推荐镜头组合 | 节奏 |
|----------|-------------|------|
| **街采(记者+路人)** | 双人同框(建立关系) → 反打切镜(问答) → 反应镜头(路人听完的表情) → 记者近景(收尾口播) | 每4-5秒切一次 |
| **家庭对话(夫妻/母子)** | 双人同框(客厅环境) → 反打切镜(担忧→解释) → 插入镜头(手机展示App) | 每3-4秒切一次 |
| **单人口播** | 中近景口播 → 插入镜头(产品画面) → 回到口播 | 每5-8秒切一次 |
| **剧情(医院/就诊)** | 鸟瞰(医院全景开场) → 过肩(医患对话) → 主观(患者视角) → 反应(家属担忧) | 按剧情节拍 |
| **产品讲解** | 牛仔镜头(讲解人全身) → 插入镜头(产品细节) → 近景口播(利益点) | 每4-6秒切一次 |
