## 0. 影视剪辑基础法则(分镜/切镜的底层原则)

> 以下法则是所有镜头切换的底层逻辑。违反它们,观众会困惑、出戏。AI 生成视频同样适用——Prompt 里的景别/朝向/视线描述,本质上就是在执行这些法则。

### 180度法则(轴线规则)

两个角色之间画一条假想的**轴线**,摄影机始终待在轴线的**同一侧**拍摄。

- A面朝右 → **所有镜头**中A都面朝右;B面朝左 → 所有镜头中B面朝左
- **越轴**(摄影机跑到轴线另一边)→ AB朝向突然翻转,观众空间感崩溃
- **Prompt 怎么守**:写"A站在画面左侧面朝右侧,B站在画面右侧面朝左侧",全场景不改朝向;切镜只换景别,不换朝向

### 情感节奏(Emotional Pacing)

**不一定每次都展示正在说话的人**——选择当下**表演最精彩、情绪最丰富**的那张脸给观众看。

- 台词砸出去的那一刻 → 切到**听的人**(反应镜头),观众从听者脸上读出台词分量
- 关键回答 → 先给听者一个期待/紧张的表情,再切到说话者开口——悬念拉满
- 喜剧 → 反应镜头几乎等于半个笑点(那一拍呆住或乐开花的表情=笑声响起的地方)
- **Prompt 怎么守**:切镜点优先放在情绪转折处,不是机械地按台词轮次切;调度频率数值 → 见 [cutting_rules.md](cutting_rules.md) ⑤·切镜节奏

### 30度角原则 / 视线匹配 / 建立镜头 → 反打

→ 切镜规则统一见 [cutting_rules.md](cutting_rules.md)(唯一权威)⑥·两条机位配合法则(30°角原则、视线匹配)与⑥·建立镜头 → 反打,本节不再复述。

## 1-9. 九种镜头的 Prompt 写法模板

→ 切镜规则统一见 [cutting_rules.md](cutting_rules.md)(唯一权威)⑥·镜头选型(9 种镜头的使用时机),以下各节不再复述"什么时候用",只保留 **Prompt 写法模板**与**保险场景典型用法**。

## 1. 反打镜头(Shot Reverse Shot)

**Prompt 写法(≤30s 段内切镜)**:
```
第0-5秒：近景，A面朝镜头，嘴唇张合说：{A的台词}
第5-10秒：切至B近景面部特写，B微微点头后开口，嘴唇张合说：{B的台词}
```

**保险场景典型用法**:街采记者提问→路人回答;家庭对话妈妈担心→爸爸解释

---

## 2. 过肩镜头(Over-the-Shoulder / OTS)

**Prompt 写法**:
```
第X-Y秒：过肩视角，A的肩膀和后脑勺占画面左前景约1/3（虚化），
焦点落在B的脸上，B表情凝重，嘴唇张合说：{台词}
```

---

## 3. 主观镜头(POV / Subjective Shot)

**Prompt 写法**:
```
第X-Y秒：第一人称视角，镜头模拟角色A的眼睛高度，
画面中看到{A看到的场景/物品/人},画面随A的头部轻微晃动。
```

**保险场景典型用法**:患者躺在病床上看到天花板→护士推门进来(代入住院体验)

---

## 4. 鸟瞰镜头(Bird's Eye / Top-Down)

**Prompt 写法**:
```
第0-3秒：俯拍鸟瞰，镜头从正上方垂直俯瞰{场景}，
角色A渺小的身影独自走在{环境描述}中。
```

---

## 5. 双人镜头(Two-Shot)

**Prompt 写法**:
```
第X-Y秒：中景双人同框，A站在画面左侧面朝右侧，B站在画面右侧面朝左侧，
两人间隔约一臂距离，{互动动作描述}。
```

**保险场景典型用法**:街采记者+路人同框建立空间关系;家庭场景夫妻/母子同框

---

## 6. 牛仔镜头(Cowboy Shot / Medium-Long)

**Prompt 写法**:
```
第X-Y秒：中远景（大腿以上取景），A自信站立，
一手拿着手机屏幕朝向镜头展示{内容}，另一手自然下垂。
```

---

## 7. 全身镜头(Full Shot)

**保险场景典型用法**:角色四视图设定稿(三个全身视图横排);街头采访开场全景交代街道环境

---

## 8. 反应镜头(Reaction Shot)

**Prompt 写法**:
```
第X-Y秒：切至B近景，B听到A的话后{可见表情反应：睁大眼睛/皱眉/嘴角上扬/点头},
嘴唇紧闭不说话，约1-2秒。
```

---

## 9. 插入镜头(Insert / Cutaway)

**Prompt 写法**:
```
第X-Y秒：特写，镜头聚焦{物品/细节}，{物品状态描述}，
画面稳定不晃动，约2秒。
```

**保险场景典型用法**:手机屏幕展示支付宝App;医疗账单特写;保单文件细节

---

## 镜头选择速查表(保险视频常用组合)

→ 切镜节奏数值(每类场景几秒一切)统一见 [cutting_rules.md](cutting_rules.md)(唯一权威)⑤·分场景节奏,本表不再复述,只保留镜头组合建议。

| 场景类型 | 推荐镜头组合 |
|----------|-------------|
| **街采(记者+路人)** | 双人同框(建立关系) → 反打切镜(问答) → 反应镜头(路人听完的表情) → 记者近景(收尾口播) |
| **家庭对话(夫妻/母子)** | 双人同框(客厅环境) → 反打切镜(担忧→解释) → 插入镜头(手机展示App) |
| **单人口播** | 中近景口播 → 插入镜头(产品画面) → 回到口播 |
| **剧情(医院/就诊)** | 鸟瞰(医院全景开场) → 过肩(医患对话) → 主观(患者视角) → 反应(家属担忧) |
| **产品讲解** | 牛仔镜头(讲解人全身) → 插入镜头(产品细节) → 近景口播(利益点) |
