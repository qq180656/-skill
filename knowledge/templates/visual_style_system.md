## 1. 风格配方速选表

> 核心原则：模型不认识导演，只认识画面。选风格不是贴导演名，是把"谁的语言"展开成可执行的画面特征。

配方 = 1主语言 + 最多1辅助语言 + 1成像基底。选多了必糊。

### 保险场景适用的主语言

| 你要的感觉 | 主语言名称 | 展开后的画面特征（写进提示词的是这列） | 适用险种/场景 |
|---|---|---|---|
| 家庭日常/温暖叙事 | 东方日常观察派 | 固定中远景门窗框景，深焦含蓄留白，环境自然光低饱和暖灰，真实旧物 | 重疾/养老/家庭场景 |
| 医院困境/冷峻压迫 | 精密暗调派 | 稳定微偏心构图，黄绿青灰深棕色域，低调布光干净黑位，金属玻璃旧墙质感 | 医疗/重疾/医院场景 |
| 突发事故/紧急救援 | 手持纪录式35mm | 手持轻晃跟拍，自然光现场灯，高对比粗颗粒，动作模糊残影 | 意外险/事故场景 |
| 自然诗意/成长记忆 | 自然光诗意派 | 贴近人物广角，逆光黄金时刻耀斑，人物与风草木水面身体互动，通透空气 | 养老/年金/亲子场景 |
| 克制叙事/心理压力 | 负空间光影派 | 简洁几何+精确留白，只信一个主光，明暗过渡磨得极细，轻雾真实反射 | 重疾/心理困境场景 |
| 都市群像/现代关系 | 理性深焦派 | 中远景深焦多区信息清晰，中性自然光，玻璃幕墙反射，现代建筑表皮，又冷又准 | 意外/职场场景 |

### 成像基底（每条片只选一个，全片统一）

- 35mm放映拷贝感（默认）：细腻颗粒，宽动态范围，柔和锐度
- 16mm电视转拍感：粗颗粒，窄动态范围，适合纪实/回忆段
- 早期数字摄影机：干净少颗粒，偏硬锐度，适合现代都市
- 手持纪录式35mm：颗粒+轻微晃动，适合事故/急救

### 胶片调味（可选，最多各1）

需要更具体的胶片性格时叠加：
- 色片：高饱和暖调日光片 / 冷青阴影夜景片 / 褪色柔和人像片
- 印片：暖黄高光复古印片 / 冷蓝阴影现代印片

叠加后总描述词不超过两行。

## 2. 色彩命题一句话

> 从CineForge提炼。每组片先写一句色彩命题，再谈任何"色调"。

公式：
> 【主色域】之上，【唯一强调色】因为【物理来源】而存在；随剧情，色彩从【起】走向【讫】。

### 保险场景示例

正确："潮湿青灰的医院走廊之上，唯一一块褪色暖橙来自孩子手中的毛绒玩具；随理赔到账，暖橙从玩具移到妈妈脸上的光，最后充满整个画面。"

正确："低饱和暖灰的老旧家庭客厅之上，唯一一块冷白来自医疗账单的纸面；随保单被发现，冷白从账单移到保单表面，最后化为柔和的暖光。"

错误："整体赛博朋克蓝紫色调，高级感。"——没有物理来源，没有叙事路径。

### 规则
- 强调色全片只能有一个，它出现在哪，戏就在哪
- 颜色必须有出处：日光灯/窗户/手机屏幕/钨丝灯/药品包装。说不出来的颜色删掉
- 拒绝默认阴冷蓝灰。选冷色要给冷色的叙事理由
- 随剧情变化路径要写清从哪到哪

## 3. 60:30:10配色体系

> 从导演色卡技能提炼。给模型可执行的量化目标。

| 色组 | 占比 | 功能 | 保险场景 |
|------|------|------|---------|
| 主色组 | 60% | 建立环境底色 | 医院走廊灰白/家庭客厅暖灰/办公区冷白 |
| 辅助色组 | 30% | 承载生活温度 | 旧木家具/棉麻服装/暖灯/皮肤暖桃 |
| 强调色组 | 10% | 小面积情绪锚点 | 退色朱红（保单信封）/暖橙（孩子玩具）/琥珀金（理赔到账时的光） |

### 配色提示词写法

不只写"冷调"，而是写明每个颜色的HEX、占比、物理载体和光源：

示例（医院困境段）：
```
色调：医院走廊日光灯#D8E0E4占30%+旧木诊台#4D4035占15%+焦虑阴影#17252E占15%
（主色组合计60%）；护士服淡蓝#A8C4D0占10%+走廊墙面灰白#C5C8C0占10%+患者皮肤暖灰#B8A898占10%
（辅助色组合计30%）；药盒暖橙#D99B48占5%+手机屏幕冷光#E8EDF0占5%
（强调色组合计10%）。
光源：日光灯从顶部直射，面部半明半暗，阴影偏蓝灰。
```

## 5. 五子层光影量化体系

> 从GRWM美妆教程广告技能提炼的五子层量化方法，适配保险场景。

所有涉及光影描述的提示词，按五个子层结构化描写：

### 子层1：光源角度
写明主光方位角、仰角和距离。
- 保险场景示例（困境段）：`主光日光灯从顶部90度直射，距离2.5米，冷白4800K`
- 保险场景示例（解决段）：`主光黄昏侧逆光从右侧30度平射，距离3米，暖橙3200K`

### 子层2：色温显色
写明主光色温、CRI值、白平衡偏置。
- 示例：`主光4800K CRI 95，辅光5200K CRI 92，白平衡5000K冷偏置`

### 子层3：视角机位
写明机位高度、方位角、焦距、光圈。
- 示例：`机位高度1.5米齐眼，正方位角0度，50mm T2.8面部近景`

### 子层4：微观质感证据链
写明画面中可见的物理质感细节。
- 保险场景示例：`真实皮肤毛孔细纹，旧衣服棉麻纹理磨损，病房墙面油漆斑驳，金属器械冷反光`

### 子层5：大气体积介质
写明画面中的空气质感和氛围。
- 保险场景示例：`消毒水气味的清洁空气，日光灯轻微频闪，走廊纵深有微弱雾感`

### 光比量化
写明主光与辅光的比值。
- 困境段：`Key:Fill = 4:1，高对比戏剧感，70%面部在阴影中`
- 转折段：`Key:Fill = 2:1，过渡阶段，阴影开始后退`
- 解决段：`Key:Fill = 1.5:1，柔和均匀，面部充分受光`

## 6. 空泛词禁令

提示词和方案里出现以下词，必须在其后追加具体画面信息，否则删词：

```
电影感 / 高级感 / 氛围感 / 史诗 / 大片 / 8K / 超高清 / cinematic / epic /
atmospheric / masterpiece / 温馨 / 感人 / 专业
```

这些词对模型是噪音，对方案是偷懒。

正确用法：
- `电影感，具体为：35mm颗粒，深焦构图，自然光侧逆光，低饱和暖灰主色域`
- `温馨，具体为：午后阳光从窗户30度侧射，暖金色光洒在旧木桌面上，棉麻窗帘轻微飘动`

## 7. 风格签名串机制

> 从VOX纸艺导演的风格签名串思路迁移。每种风格定义一套签名串，确保Prompt里风格不掉。

### 签名串定义

| 风格 | 签名串（必须逐字包含） |
|------|---------------------|
| 写实纪录片 | `写实纪录片风格，手持摄影质感，自然光，35mm胶片颗粒，低饱和` |
| 电影叙事 | `电影叙事风格，多镜切镜，因果连续动作，光线物理可信，胶片质感` |
| 温暖家庭 | `温暖家庭影像，柔和暖光，自然生活质感，低对比度，真实旧物细节` |
| 紧张纪实 | `紧张纪实感，手持跟拍，高对比粗颗粒，动作残影，现场环境光` |
| 回忆穿插 | `回忆滤镜，偏暖偏黄，轻微柔焦颗粒感，溶解转场，怀旧色调` |

### 使用规则
- 每段视频提示词以风格签名串开头
- 签名串之后追加该段具体画面描述
- 全片使用同一种风格签名串，不混用
- 回忆穿插型可交替使用"写实纪录片"和"回忆穿插"两套签名串，但各段内部不混
