# 多人场景执行引导 (Multi-Scene Director)

## 核心问题

文档层（如 prompt_craft_guide.md）已定义完整的多人对话规范：
- 空间关系三要素（景别 + 相对大小 + 间隔物）
- 正反打节奏（说话方近景 / 听话方反应镜）
- 站位锁 / 轴线锁（180度轴线规则）

→ 切镜规则统一见 [cutting_rules.md](../cutting_rules.md)（唯一权威），本 Skill 不再复述：正反打实现方式（≤30s/>30s 分流）、轮次调度5种、采访场景节奏、听者反应防蜡像、正反打覆盖强制门均以其③为准；本 Skill 只保留多人场景模板、强制规则与门拦流程。

但执行层存在三缺，导致规范落不了地：

| 缺失项 | 后果 | 典型症状 |
|--------|------|----------|
| 执行引导缺失 | 执行时默认走单人模板 | 多人对话被拆成多个独立单人口播 |
| 可复用模板缺失 | 每次临时写，质量靠运气 | 所有角色套同一个"面对镜头说话"骨架 |
| 检查门拦缺失 | 多人被拆成单人也能通过 | 门拦只查禁用词/警示语，不查人物关系 |

本 Skill 补齐这三项，形成"模板 + 强制 + 门拦"三层防线。

---

## 何时使用

当分镜脚本文本中出现以下任一信号时，**必须加载本 Skill 并执行全部校验**：

1. 脚本包含 **2个及以上有台词的角色**
2. 场景描述包含"采访""对话""交谈""问""答""讨论"等互动词
3. 角色关系为"记者-路人""医生-患者""老师-学生""客服-用户"等双人互动关系
4. 用户描述中明确提到"街头采访""多人对话""群戏""辩论"等场景类型

## 第一层：可复用场景模板

### 模板 1：街头采访（记者 + 受访者）

**适用场景**：保险/金融/健康类街采，记者提问、路人回答、记者总结。

**核心规则**：
- 话筒只在记者手中，受访者不持话筒
- 至少一个双人同框镜头（建立空间关系）
- 问答用正反打（记者问拍记者，路人答拍路人）
- 记者总结时面对镜头（此时是口播模式，非对话模式）

**Prompt 骨架**：

```
=== 素材绑定 ===
参考@图片1的形象作为记者（手持话筒），参考@图片2的形象作为受访路人，场景参考@图片3的{场景描述}。

=== 概述 ===
{风格关键词}，{场景}，记者手持话筒采访路人，两人同框互动对话。

=== 画面 ===
第0-X秒：中景双人同框，记者站在画面左侧面朝右侧手持话筒，路人在画面右侧面朝左侧，
两人间隔约一臂距离，话筒递向路人方向。记者嘴唇随每个字清晰一开一合，说：{记者提问台词}
<X秒环境音>

第X-Y秒：切至路人近景面部特写，路人微微点头或表情变化，嘴唇张合说：{路人回答台词}
<自然环境声>

第Y-Z秒：回到双人中景，记者收回话筒转向镜头，面朝镜头做总结。
记者嘴唇张合说：{记者总结台词}
<环境声，BGM渐入>

=== 约束 ===
{风格关键词}，竖屏9:16，双人同框时保持180度轴线（记者面朝右、路人面朝左），
话筒只在记者手中，受访者不持话筒。五官清晰不变形、服装发型一致，
禁明星脸、禁医护形象、禁电子屏幕、无字幕无logo无水印。
时长：{N}秒，比例：9:16
```

**ImageList 排列**：
```
[记者四视图, 路人四视图, 场景空镜图]
→ Prompt中 @图片1=记者, @图片2=路人, @图片3=场景
```

**分镜拆解建议**（30秒街采）：

| 镜头 | 内容 | 模式 | 时长 |
|------|------|------|------|
| s1 | 记者提问 + 路人回答（同框 + 正反打） | 对话模式 | 10s |
| s2 | 记者追问 + 另一路人回答（同框 + 正反打） | 对话模式 | 10s |
| s3 | 记者面对镜头做产品总结 | 口播模式 | 10s |

### 模板 2：双人对话（A-B 互动）

**适用场景**：两人面对面交谈、争论、解释、说服。

**核心规则**：
- 必须有至少一个双人中景建立空间关系
- 对话用正反打（A说话拍A近景，B说话拍B近景）
- 听话方需有反应镜头（点头/皱眉/惊讶等可见表情）
- 180度轴线：A面朝右则B面朝左，全场景不越轴

**Prompt 骨架**：

```
=== 素材绑定 ===
参考@图片1的形象作为{角色A名}，参考@图片2的形象作为{角色B名}，场景参考@图片3的{场景描述}。

=== 概述 ===
{风格关键词}，{场景}，{角色A名}与{角色B名}面对面交谈，{互动类型：争论/解释/说服}。

=== 画面 ===
第0-X秒：中景双人同框，{角色A名}站在画面左侧，{角色B名}站在画面右侧，
两人间隔{可见空间描述：如一张桌子/两步距离}。
{角色A名}嘴唇张合说：{A的台词}
<环境音>

第X-Y秒：正反打近景切至{角色B名}，{可见表情反应描述}，
{角色B名}嘴唇张合说：{B的台词}
<环境音>

第Y-Z秒：回到双人中景，{角色A名}{可见动作反应}，
{角色A名}嘴唇张合说：{A的台词}
<环境音>

=== 约束 ===
{风格关键词}，竖屏9:16，双人同框保持180度轴线（{A}面朝右、{B}面朝左），
五官清晰不变形、服装发型一致，禁明星脸、无字幕无logo无水印。
时长：{N}秒，比例：9:16
```

### 模板 3：群戏（3人及以上）

**适用场景**：多人讨论、家庭场景、办公室群戏。

**核心规则**：
- 开场必须有一个全景/中景建立所有角色的空间站位
- 每次只聚焦当前说话者（近景/中景），但画面中需可见其他角色的存在感（前景/背景虚化人物）
- 说话者切换时用"目光引导"转场（前一个说话者看向新说话者 → 镜头跟随移向新说话者）
- 群像角色（无姓名的路人/村民/同事）使用群像参考图，不单独生成四视图

**Prompt 骨架**：

```
=== 素材绑定 ===
参考@图片1的形象作为{主角A}，参考@图片2的形象作为{主角B}，参考@图片3的形象作为{主角C}，
场景参考@图片4的{场景描述}，参考@图片5的{群像类型}群像造型范围。

=== 概述 ===
{风格关键词}，{场景}，{角色A/B/C}与其他人在{场景}中讨论{话题}。

=== 画面 ===
第0-X秒：全景，{场景}内{角色A}站在{位置}，{角色B}站在{位置}，{角色C}站在{位置}，
群像角色分布在背景中。{角色A}嘴唇张合说：{A台词}
<环境音>

第X-Y秒：中景推至{角色B}近景，{角色A}的虚化身影在前景左侧（暗示仍在场），
{角色B}嘴唇张合说：{B台词}
<环境音>

第Y-Z秒：镜头横移至{角色C}，{角色C}{可见表情}，嘴唇张合说：{C台词}
<环境音>

=== 约束 ===
{风格关键词}，竖屏9:16，全场景保持180度轴线一致，
群像角色不抢焦点但需可见存在感，五官清晰不变形、服装发型一致，
禁明星脸、无字幕无logo无水印。
时长：{N}秒，比例：9:16
```

## 第二层：多人脚本强制规则

在分镜规划（storyboard）阶段，当检测到脚本包含2个及以上说话角色时，**强制执行以下规则**：

### 规则 1：同框存在性
> 至少一个镜头必须是双人（或多人）同框画面。

违反示例：3个角色各自独立面对镜头说话，没有任何两人出现在同一画面中。
判定：**FAIL**，要求重写分镜。

### 规则 2：正反打覆盖
> 对话场景中，每个说话者的台词必须对应其本人的口型镜头（正反打），不能只听到声音而画面是别人。（规则本体以 [cutting_rules.md](../cutting_rules.md) ③·强制门拦为准，此处保留为门拦检查项）

违反示例：镜头始终对准记者，路人台词作为画外音播放。
判定：**FAIL**，要求补充路人近景镜头。

### 规则 3：角色功能区分
> 必须明确区分每个角色的功能定位（谁采访/谁受访，谁提问/谁回答），不能所有角色用同一套"面对镜头独白"骨架。

违反示例：记者和路人都手持话筒面对镜头自说自话。
判定：**FAIL**，要求按角色功能重写。

### 规则 4：道具归属一致
> 互动道具（话筒、文件、手机等）的归属必须在所有镜头中保持一致。话筒属于记者就不属于受访者。

违反示例：镜头1记者拿话筒，镜头2路人也拿着话筒。
判定：**FAIL**，要求修正道具归属。

### 规则 5：轴线一致性
> 双人同框时，角色面朝方向必须在所有镜头中保持一致（A始终面朝右，B始终面朝左），禁止越轴。

违反示例：镜头1记者面朝右，镜头2记者突然面朝左。
判定：**FAIL**，要求修正朝向。

### 规则 6：空间关系三要素
> 双人同框镜头必须同时写明：景别 + 相对大小 + 间隔物。缺一不可。

违反示例：只写"两人在公园里说话"，没有写景别、相对大小、两人之间的可见空间。
判定：**FAIL**，要求补充三要素。

## 第三层：人物关系校验门拦

在分镜产出后、提交用户确认前，执行以下校验流程：

### 校验流程

```
输入：分镜脚本（storyboard）
输出：PASS / FAIL + 具体问题列表

Step 1: 角色识别
  - 从脚本文本中提取所有有台词的角色名
  - 记录角色数量 N

Step 2: 单人/多人判定
  - N = 1 → 跳过本门拦，走单人口播流程
  - N >= 2 → 继续执行本门拦

Step 3: 同框检查
  - 扫描所有镜头的 Prompt 文本
  - 检查是否存在至少一个镜头包含两个或以上 @图片N 引用
  - 且对应的 ImageList 中包含多个角色参考图
  - 不存在 → FAIL：多人场景缺少同框镜头

Step 4: 正反打检查
  - 对每个有台词的角色，检查是否存在对应的口型镜头
  - （即该角色的 @图片N 在某个镜头中被引用，且 Prompt 包含该角色的"嘴唇张合说"）
  - 某角色有台词但无口型镜头 → FAIL：角色{X}有台词但无对应口型镜头

Step 5: 角色功能检查
  - 检查所有镜头的 Prompt 是否使用了同一套"面对镜头说话"骨架
  - 如果所有角色的画面描述完全同构（只是换了角色名和台词） → WARN：可能将多人场景降维为单人口播

Step 6: 道具归属检查
  - 提取所有镜头中提到的道具（话筒、文件等）
  - 检查同一道具是否在不同镜头中归属于不同角色
  - 归属不一致 → FAIL：道具{X}归属冲突

Step 7: 轴线检查
  - 提取双人同框镜头中角色的面朝方向
  - 检查同一角色在不同镜头中的面朝方向是否一致
  - 越轴 → FAIL：角色{X}轴线越轴

Step 8: 空间三要素检查
  - 对每个双人同框镜头，检查是否包含：
    a) 景别描述（中景/近景/全景）
    b) 相对大小描述（左侧/右侧/前景/背景）
    c) 间隔物描述（两人之间的可见空间）
  - 缺失任一 → FAIL：同框镜头缺少空间关系要素
```

### 校验结果处理

| 结果 | 处理 |
|------|------|
| PASS | 继续进入用户确认环节 |
| FAIL | 阻断，列出具体问题项，要求按对应模板重写后重新校验 |
| WARN | 不阻断，但在提交用户确认时附加提示："检测到多人场景可能被拆解为单人口播，请确认是否符合预期" |

## 常见错误 vs 正确写法对照

### 错误：街采被拆成单人口播

```
❌ s1: 记者面对镜头说：{八零九零后注意了...}
❌ s2: 路人面对镜头手持话筒说：{我给爸妈买了...}
❌ s3: 另一路人面对镜头手持话筒说：{我爸有高血压...}
```

问题：三人各自面对镜头独白，路人也拿话筒，没有同框，没有正反打。

### 正确：街采按对话模式构建

```
✅ s1: 中景双人同框，记者（画面左侧，手持话筒）提问，路人（画面右侧）回答。
       正反打：记者近景说{提问} → 路人近景说{回答}
✅ s2: 中景双人同框，记者追问另一位路人，正反打切换。
✅ s3: 记者面对镜头做产品总结（此时才是单人口播模式）。
```

### 错误：双人对话无空间关系

```
❌ 两人站在公园里交谈。A说：{...} B说：{...}
```

### 正确：空间关系三要素齐全

```
✅ 中景，A站在画面左侧面朝右侧，B站在画面右侧面朝左侧，
   两人间隔约一臂距离，话筒递向B的方向。A说：{...}
```
