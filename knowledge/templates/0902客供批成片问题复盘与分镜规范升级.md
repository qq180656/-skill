## 一、问题清单（实测坐实）

### P1 场景硬切，过渡不自然

**现象**（HYB53408-260920脚本1-B，55.08s，ffmpeg scene 检测 8 个切点）：
- 14.33s：餐厅暖光全家（爸爸蹲着哄孩子）→ 0.1秒后直接是夜色阳台双人，零过渡
- 41.58s：阳台妈妈近景 → 直接跳儿童房门口中景
- 切点位置基本守时（与设计镜头边界±0.5s），但过渡语言为零
- 25s 的 concat 段间边界**完全无缝**（extend 承接语生效）——证明段间拼 接不是问题，问题全在段内

**根因三层**：
1. **规范条款误导**：prompt_craft_guide 原文「≤30s 不拆调用，靠 Prompt 时间轴切镜」没有空间豁免——为省调用次数把跨空间（餐厅→阳台）塞进同一段，模型对段内"换地点"的唯一渲染方式就是裸硬切
2. **提示词没有过渡语言**：镜头衔接写的是「切到手术室门口」——等于明确指示硬切；无运镜桥接、无动作承接
3. **切点不等动作完成**：引子里妈妈擦鼻血做到一半（2.35s 帧动作进行中）被切走（2.6s 帧已直起身）——镜头末尾没写动作完成锚，模型按时间码机械切换

**修复**：
- 9-A/9-B/10-A/10-B 段内跨空间拆回独立段（并行 t2v+concat）
- 12-B 化验窗→谈话窗（相邻柜台）不拆段，改侧移跟随桥接
- 全部裸「切到」改运镜桥接
- 引子补完整动作闭环，时长放宽 0-4s

### P2 利益点台词讲到一半就切（切点时机不对）

**现象**：一个镜头塞 60-90 字利益点长台词（镜头4 整整 11 秒 90 字，每秒 8.2 字超语速），话没说完画面切走或被时间码挤掉。

**根因**：切点定在情绪/场景转换，不定在台词节拍上；对白镜头没有"每镜台词容量"概念。

**修复**：利益点长台词拆"说话人→听者反应（画外音续台词）→说话人"交替镜，切点全落句读边界；镜头时长=台词字数÷语速+1秒收束余量。本批实拆：脚本7 十镜、脚本15 六镜、脚本8-12（代理在途）。

### P3 台词与画面语义矛盾（孩子伤病状态丢失）

**现象**（HYB53408-260920脚本3-B）：
- 台词："孩子课间从楼梯摔下来，骨折，住院要四万六"
- 画面：8s/24s 帧——**孩子在屋里活蹦乱跳跑动**；36s 帧站着，无石膏无纱布无任何伤病痕迹

**根因**：分镜里孩子只是背景存在（"额头贴小纱布坐在餐桌边"只提了一次），父母对话是画面主体——模型把孩子当日常家庭戏渲染，伤病状态完全丢失。**台词讲伤病 ≠ 画面自动带伤病，必须逐镜显式锚定。**

**修复**（5 处真 bug）：
- 3-B 镜头7「一蹦一跳扶墙挪」→ 儿童房门虚掩、孩子已睡不入画
- 2-B 镜头7/镜头11 客厅蹦跳残留 → 布兔子道具讲故事/缓步挪到父母身边
- 4-A/B 收束镜孩子举玩偶太活跃 → 半坐靠枕轻轻举给父母看
- 3-B 成片判废，移入 `_废片重跑/`，列入明天重跑清单

### P4 LLM 审查追查出的人工盲区（4 个真 bug）

写完 storyboard_review.py 后全量复审 part1，抓到人工审漏掉的：
- 2-B 另一处蹦跳残留（人工只修了第一处）
- **5-B 台词「儿子马上开学了」与 B 版女孩的性别冲突**（A版男孩无此问题；客供源脚本原文如此，B版必须改「孩子」）
- 4-A/B 报「6万8」时画面无缴费语境锚（补"攥无字缴费单"道具）

**误报甄别原则**（审查报告 ≠ 盲改指令）：
- 脚本6"隔壁孩子不出镜"是设计（源脚本明写仅对白提及，避免暗示他人病情）
- "产品名2次"是 A/B 两条独立视频各1次（全片=单条内1次）
- 闲聊场景（小区婆媳聊别人家事）不该硬塞缴费单

## 二、写进规范的新规则（prompt_craft_guide.md 等）

### 1. 段内切镜空间红线
段内时间轴切镜只允许**同一空间内**换景别/机位/构图。**跨空间场景切换即使总时长≤30s 也必须拆成独立段**（并行 t2v+concat 或 extend）。相邻贯通空间（走廊→病房门口）可用跟随运镜写进同段，但必须是人物可走到的连续动线。

### 2. 切点三铁律
- **动作完成锚**：镜头末尾进行中的动作必须写完收束再切；引子写完整动作闭环（时长放宽 3-4s）
- **禁裸"切到"**：改运镜/动作桥接（"镜头随人物起身横移，带出走廊尽头"）
- **台词时长余量**：镜头时长=台词字数÷语速+1秒；切点落在句读边界之后

### 3. 场景切换时机决策表（有理由才切，理由决定切法）

| 触发条件 | 切法 |
|---|---|
| 物理时空转变（空间转移/时间跳跃） | 拆段；切点落在动作完成后、台词说完后（叙事节拍硬切，观众有心理预期） |
| 平行叙事/交叉剪辑（两段式反转） | 拆段；两段各自完整，靠剧情对位形成张力，不来回碎切 |
| 台词>15字 | 同空间拆镜正反打：说话人→听者反应（画外音续）→说话人；切点全落句读边界 |
| 情绪拐点（崩溃→转折/放心） | 切反应特写，≤5s，切点落在情绪翻转瞬间 |
| 新信息载体（单据/胶片/监护仪/存钱罐） | 切物件特写 1-2s 再切回 |
| 相邻可达空间 | **不切**——跟随运镜写进同段 |
| 无以上任何理由 | **不切**，一镜到底到自然耗尽；禁止凑"每4-5秒一镜"为切而切 |

### 4. 利益点长台词铁律
保障枚举长句绝不能整段塞进一个镜头——按句读拆成交替镜消化；画外音续台词时听者必须有具体微表情，不是蜡像静听。**切走了说话人，台词不中断。**

### 5. 剧情伤病状态锚铁律
台词讲"摔伤住院/骨折/肺炎卧床"时，孩子**每个出场镜头**必须带 状态+动作+位置 三件套（"孩子额头贴小纱布坐餐椅，左臂吊带，安静不动"）；伤病锚跨镜一致不消失；病情与台词矛盾=废片；时间线自洽（住院期间不出现家中蹦跳，在家=已睡/石膏养伤/不入画）。

### 6. 跟随镜头写法规范（相邻空间桥接的标准写法）
禁笼统"镜头跟随/摇镜跟随"，必须写全三要素：**跟随方向**（后方=其视角推进/旁侧=边走边谈首选/前方=移动中面部）+**节奏**（平稳匀速=安抚段/手持微晃=紧张段）+**环境语境**（穿越途中的具体环境）。摇镜头只用于站定原地转头看另一主体。

### 7. 多人镜头写法规范（三人/四人）
禁"N人同框/围在一起"式含糊描述，必须：**方位逐人点名**（"A左、B中央、C右"，谁居中=谁主导）+**景深走位**（三角安排=前景1锚+中景两侧，最稳；线性横排需写间距）+**景别**（中景三人为对话首选）；婴儿/卧床孩子写"前景病床一角"不占主焦平面；视线与180°跨镜一致；三人关系有叙事意义→三人镜，个体反应是重点→切个体。何时用三人的判断：围床问答、医生-父-母同框优先三角构图。

### 8. LLM 语义审查进 P0 关卡（wf_storyboard Step 2）
机械门（字数/时长/合规词/保真diff）全过后**必须**跑 `storyboard_review.py`，ERROR 逐条修到 ALL PASS 才准进生成。它抓正则抓不到的：台词-画面冲突/伤病锚缺失/时间线倒错/听者蜡像/跨空间未拆段/长台词未拆正反打/多人无方位。

## 三、新增工具（AI视频生产规范\scripts\）

| 工具 | 职责 | 用法 |
|---|---|---|
| `storyboard_review.py` | 分镜 LLM 语义审查（按脚本分章喂 LLM，10 类检查，输出 镜头号+问题+修法 清单） | `python storyboard_review.py --file 分镜.md --strict`；实测两轮：埋的 bug 命中、4 个人工盲区 bug 抓出、修复后 ALL PASS |
| `xfade_transitions.py` | 段间 xfade 叠化后处理（0.4s 半透明交叠，治段间硬切观感，零生成成本纯 ffmpeg） | `python xfade_transitions.py --input 成片/ --output 成片_叠化/`；1-A 实测过渡丝滑无黑帧 |
| `atomize_script.py` | 脚本原子化（去括号/删词/空格注入/计时长） | `--file 脚本.txt --product X --output ./_session/` |
| `fidelity_diff.py` | 台词保真硬门（分镜台词 vs 原子稿逐字 diff，缺字精确定位） | `--atomic a.json --storyboard sb.md` |
| `gen_character_sheets.py` | 角色四视图批量生图（含无痣约束、URL 台账落盘） | `--config 角色配置.json` |
| `video_submit.py` | 视频单段提交（参考图 CDN URL 优先/base64 兜底双方案） | 库调用 submit_segment / CLI |

## 四、后续批次执行清单（防复发 SOP）

1. **写分镜时**：对照决策表逐镜自问"这个切有理由吗？理由决定切法"；长台词先拆正反打再写时间码；孩子出场逐镜带伤病三件套；跟随/多人镜头写全三要素/方位点名
2. **写完必审**：机械门（时长/合规/保真）→ `storyboard_review.py` LLM 语义审 → ERROR 修复 → 复审到 ALL PASS → 才准生成（P0 关卡）
3. **误报甄别**：LLM 报告逐条人审，设计使然/双版本计数的按理由驳回并记录
4. **生成后**：多段成片统一过 `xfade_transitions.py`（0.4s）；抽帧核验切点（ffmpeg scene 检测 + 切点前后帧对照）
5. **看片反馈回路**：新问题类型 → 补进 prompt_craft_guide 决策表/铁律 → 下批执行（本批三问题即走完该回路）
