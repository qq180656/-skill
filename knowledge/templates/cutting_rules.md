# 切镜规则(唯一权威)

> **所有"镜头切换/转场/正反打/切点/景别切换"一律以本文件为准。** 其他文档不再复述这些规则,只保留指向本文件的指针。
>
> 本文件收编原散在 12 处的切镜规则(已去重),分 6 块:①切点铁律 ②转场方式 ③正反打/对话切镜 ④空间与拆段 ⑤切镜节奏 ⑥镜头选型。

---

## ① 切点铁律(什么时候才能切)

切镜必须同时满足以下条件,缺一不可:

| 铁律 | 要求 |
|---|---|
| **动作完成锚** | 镜头末尾进行中的动作/台词必须**写完收束再切**("说完最后一个字,把单子轻放膝上");引子要写完整动作闭环,时长放宽到 3-4s。不写收束,模型会在动作中途切走 |
| **禁裸"切到"** | 不用"切到X",改运镜/动作桥接("镜头随人物起身横移,带出走廊尽头""脚步声先入画,随后门推开")。同空间换景别可用"镜头缓缓推近/后退拉开" |
| **台词时长余量** | 镜头时长 = 台词字数 ÷ 语速 + **1秒收束余量**,防止话没说完被下一镜时间码挤掉 |
| **切点落句读边界** | 切点在句号/感叹号/问号**之后**,禁止切半句;30s 落点在句中则前推到最近句末 |
| **有转场理由** | 台词提到要去的地方 / 旁白交代时间跳跃 / 动作暗示离开(起身/推门/挂电话) |
| **无理由不切** | 没有叙事理由就一镜到底到自然耗尽;**禁止为切而切、凑固定秒数切镜** |

> **跨物理空间拆段**还须额外满足"叙事节拍"条件,见 ④。

## ② 转场方式

| 转场 | 适用场景 | 写法要点 |
|---|---|---|
| **硬切** | 同场景时间推进、情绪转折;现实段落 | 切点落动作完成后、台词说完后(观众有心理预期) |
| **叠化 xfade** | 跨物理空间拆段后 | `xfade_transitions.py`,0.4s 半透明交叠,零生成成本纯 ffmpeg |
| **运镜桥接** | 相邻贯通空间、同空间换景别 | 跟随/摇镜/推近/横移,见下方"跟随三要素" |
| **溶解** | 回忆、时间流逝、情绪渐变 | — |
| **淡入淡出** | 段落分隔、日夜转换 | — |
| **遮挡转场** | 人物经过镜头、门关上、窗帘拉过 | — |
| **柔光/闪白** | 回忆段落(现实用硬切) | 与现实段落区分 |

**蒙太奇连接(4 种)**:
- **道具匹配**:前段道具特写 → 后段同一道具不同状态
- **色调反转**:冷调 → 暖调的视觉转折(落段边界)
- **声音桥接**:前段旁白尾句延续 → 后段首句
- **动作匹配**:前段手伸向某物 → 后段手拿到某物

**显式转场标记(段间)**:切场景那一镜,上镜末写转场动作(转身/走向/推门),下镜描述开头写 `【画面转到XX】`,由 extend 自然过渡。

### 运镜桥接·跟随三要素(相邻空间必须写全,禁笼统"镜头跟随")

- **跟随方向(三选一)**:
  - **后方跟随**——相机在主体身后,展示其视角朝目的地推进(悬念/行动)
  - **旁侧跟随**——相机与主体并行,同展行进环境+面部表情(**边走边谈首选**;保险片走廊/连廊讲保障就是这类)
  - **前方跟随**——相机后退、主体向其推进,展移动中面部与反应(情绪收束)
- **节奏**:平稳匀速(安抚/讲述)/ 略带手持微晃(紧张)
- **环境语境**:跟随途中的具体环境("穿过连廊大窗光与绿植""越过候诊椅与推让的人群")
- **与摇镜头区别**:摇=相机原地转轴(观察感、距离感);跟随=相机实际穿越空间(沉浸、陪伴)。相邻空间桥接用**跟随**,站定原地转头看另一主体才用**摇**。
- 示例:❌"摇镜跟随两人走入病房门" → ✅"旁侧跟随:相机与两人并行推进,妈妈挽着爸爸边走边说,沿途经过连廊大窗自然光与绿植,爸爸端着无字胶片侧头应答,到病房门口相机减速停住,门框构图收束"

### 多人镜头写法(三人/四人,禁含糊"N人同框")

- **方位逐人点名**:"A在画面左侧,B在中央,C在右侧,中景"。谁居中=谁主导/调停(主讲人/医生居中,听者两侧)
- **景深走位**:**三角形安排**(一主体前景锚定、两位中景两侧,构图金字塔,最稳)优于**线性横排**(需写明间距防拥挤);跨镜走位保持一致
- **景别**:宽三人(全身+环境,确立空间)/ 中景三人(腰部以上,聚焦表情,保险对话首选)
- **群戏/含婴儿**:仍逐人点名;婴儿/卧床孩子写"前景病床一角/包被轮廓"不占主焦平面;单图 ≤4 人
- **视线与 180° 跨镜一致**:A 在三人镜朝右看 B,切 A 单人镜也必须朝右;群体所有角度共享同一轴线
- **何时用三人 vs 切个体**:三人关系本身有叙事意义(谁靠近谁/谁被排除/谁掌控)→ 三人镜头;某角色具体反应是重点 → 切个体。保险片围床问答、医生-父-母同框优先三角构图(父母两侧中景、医生或孩子为前景/中央锚点)

## ③ 正反打 / 对话切镜

### 核心:正反打怎么落地

| 时长 | 实现方式 |
|---|---|
| **≤30s(单段)** | **不拆调用**,正反打写在 Prompt **时间轴**内:"第0-4秒:近景妈妈面朝镜头说话→第4-8秒:切近景爸爸面朝镜头回答" |
| **>30s(拆段)** | 通过**相邻独立镜头**实现:A说话拍A一个镜头,B说话拍B下一个镜头,各自独立 Prompt、各自调用 |

- **禁止在 >30s 的单镜头 Prompt 里写"正反打"指令**——模型可能忽略或闪烁(观感像卡顿)。
- 双人中景(两人同框不切机位)可以用,但不叫正反打。

**写法对照**:

```
❌ 镜头1：中近景正反打，A和B对话     → 模型不知道拍谁
✅ 镜头1a：近景，A面朝镜头说话
   镜头1b：近景，B面朝镜头回答
```

### 对话切镜节奏(避免呆板)

- **说话方**:近景/中近景(口型清晰)
- **听话方**:反应近景(点头/皱眉/表情变化,约 1 秒,对应角色切换停顿)
- **关键情绪点/转折**:双人中景(交代空间关系)
- 避免连续两个镜头**同一景别同一角色**;每隔 3-4 句插入双人中景或听者反应**重置空间感**。

### 听者反应镜不能省(防蜡像)

多人对话中,听者不能只写"嘴唇闭合不出声"(会渲染成蜡像),必须有:
- **侧头看向说话者** + **点头/皱眉等可见微表情**。
- 禁止写"仅轻微呼吸"。

### 利益点长台词铁律

- 保障枚举长句**绝不整段塞进一个镜头**——按句读拆成"说话人→听者反应(画外音续台词)→说话人"交替镜消化。
- 画外音续台词时,听者**必须有具体微表情**,不是蜡像静听。
- **切走了说话人,台词不中断。**

### 轮次调度(5 种)

| 模式 | 时机 | 写法 |
|---|---|---|
| 说话人近景切镜 | 说话人切换 | 硬切至新说话人近景,面朝对话方向,带口型 |
| 环拍收全景 | 新话题/情绪转折 | 环绕拍摄,扫过所有人表情后落在新说话人 |
| 反应镜头插入 | 长发言中 | 硬切听者近景,嘴唇紧闭+微表情,说话方转画外声 |
| 双人争执 | 两人交锋 | 过肩镜头在两人之间正反打,第三人降为背景 |
| 群体反应 | 关键信息公布 | 2-3 个有先后差异的个体反应,禁止"纷纷"同拍 |

### 采访场景节奏

- **提问段**:受访者保持"听"的状态(嘴唇紧闭、微微点头、眼神偏画外)
- **回答段**:受访者近景面朝画外记者方向,嘴唇张合说台词
- 每 4-5 秒一次调度:提问时切听者反应,回答时句间切近景/特写强调

### 强制门拦

- **正反打覆盖**:对话中每个说话者的台词必须对应**本人**口型镜头,不能只闻声而画面是别人 → 违反判 FAIL,补该角色近景。

## ④ 空间与拆段

### 段内切镜空间红线

| 场景关系 | 处理 |
|---|---|
| **同一空间内**换景别/机位/构图 | ✅ 允许同段,Prompt 时间轴切镜 |
| **相邻贯通空间**(走廊→病房门口,人物可步行的连续动线) | ✅ 允许同段,用**跟随运镜桥接** |
| **跨物理空间**(餐厅→阳台、家→医院等不可步行直达) | ❌ **必须拆段**,即使≤30s;拆段后用 xfade 叠化或 extend 承接 |

> 原因(实测):文生模型对段内"换地点"的唯一渲染方式是裸硬切——前一帧还在 A 空间,后一帧直接跳 B,观感"动作没做完就切场景"。

### 跨空间拆段时机(语义驱动,不是检测到地点变了就拆)

跨空间拆段必须落在**叙事节拍点**:对话说完一个话题 / 角色给了转场理由 / 情绪到拐点,观众有心理预期"该换地方了"。**禁止在对话进行中突然跳到另一个地方。**

| ❌ 对话没完就跳 | ✅ 节拍到了再跳 |
|---|---|
| 医院走廊讨论保费,话说一半突然切家里客厅 | 走廊讨论完→爸爸说"回家再商量"→切客厅 |
| 餐厅聊天,没理由突然切阳台 | 餐厅聊完→妈妈说"去阳台透透气"→起身→切阳台 |
| 孩子上课,画面突然跳医院 | 教室镜头结束→旁白"没想到下午出了事"→切医院 |

**拆段切点三条件(必须同时满足)**:
1. 台词到句读边界(句号/问号之后,不在逗号中间切)
2. 当前话题/轮次说完(不在 A 问 B 没答时切走)
3. 有转场理由(台词/旁白/动作暗示)

### 镜头衔接原则

相邻两镜至少保持一个连续元素(空间/时间/动作/视线方向),避免硬切断裂:
- **动作衔接**:上镜动作未完成,下镜接另一角度
- **视线衔接**:上镜人物看向某方向,下镜展示该方向所见
- **空间衔接**:同场景不同景别,环境元素一致

## ⑤ 切镜节奏

> 下面三个数值看似冲突,实际是**三个不同概念**,各管各的:

| 概念 | 数值 | 适用 |
|---|---|---|
| **对白段镜头调度(最低频率下限)** | 每 **4-5 秒** ≥1 次调度 | 不能比这更慢,防止一镜到底 |
| **段内动作点密度** | 每 **2-3 秒**一个动作点 | 出画入画/转身/物件易手/景别跳变,防贴片 |
| **无理由切镜禁令** | **禁止凑"每4-5秒一镜"** | 没有叙事理由时,不能机械按时间切 |

**30s 直出**:建议拆 **4-6 个时间段**写清节奏,否则后半段容易偏离重点。

### 分场景节奏

| 场景 | 节奏 |
|---|---|
| 街采(记者+路人) | 每 4-5 秒切一次 |
| 家庭对话(夫妻/母子) | 每 3-4 秒切一次 |
| 单人口播 | 每 5-8 秒切一次 |
| 产品讲解 | 每 4-6 秒切一次 |
| 口播讲解穿插空镜 | 每 3-4 秒穿插 |
| 群戏 | 按剧情节拍 |

### 拆镜后必做

**拆正反打/加反应镜后必须重算段时长**——字数不变但占用时间变多。预算不够就加段或删反应镜,**禁止压缩语速**(Seedance 不截断台词,时长赤字会 100% 转化为语速加快,利益点赶话听不清)。

## ⑥ 镜头选型(9 种镜头的使用时机)

| 镜头 | 什么时候用 |
|---|---|
| **反打 Shot Reverse Shot** | 覆盖对白(一来一回不是独白)/ 接住回答 / 视线与权力(角度高低倾斜谁占上风)/ 审讯对峙 |
| **过肩 OTS** | 对话戏份 / 锁定空间关系(近处肩膀定位)/ 制造紧张压迫感 / 对峙谈判。**禁同镜从A肩绕拍B肩**,只做固定或单向推拉 |
| **主观 POV** | 拉进动作(代入感)/ 揭示角色看到的东西 / 拉近情感距离 |
| **鸟瞰 Bird's Eye** | 衬托渺小孤立 / 读出图案走向 / 俯视=监视或命运注视 / 开场交代布局 |
| **双人 Two-Shot** | 交代关系(姿态距离视线)/ 不切镜演完整段对话 / 用距离制造张力 / 重逢拥抱 |
| **牛仔 Cowboy** | 对峙(手和腰部入画,蓄势待发)/ 展现气场 / 手部动作重要(展示App/递保单) |
| **全身 Full** | 角色设定(服装剪影姿态)/ 环境交代(人在哪) |
| **反应 Reaction** | 让台词落地(听者脸)/ 堆积悬念 / 短视频节奏节拍 |
| **插入 Insert** | 埋关键信息(广角藏的细节)/ 积累紧张感 / 产品细节 / 为剪辑留干净切点 |

### 两条机位配合法则

- **30°角原则**:连续两镜拍同一对象,摄影机角度至少变化 **30°**,太小像跳切、太大(>180°)越轴。对白切镜景别要明显变化(中景→近景),同一角色连续两镜至少换一档景别。
- **视线匹配**:切镜后两角色**眼睛高度保持一致**(A的眼睛在画面上1/3,B也在上1/3),观众才能直觉感到对视。俯拍=弱势,仰拍=强势。

### 建立镜头 → 反打

一段对话**先用双人同框**(建立镜头)交代空间关系,再切入反打/近景——直接从近景开始,观众不知道两人在哪、谁左谁右。每隔 3-4 句回一次双人同框重置方位。

### 机位红线

- 景别变化靠**摄影机真实靠近/后退**(前推后拉),不用数字变焦(刻意效果才显式指定)。
- 要在 A、B 间转移注意力,用**跨镜头切焦**(镜a实焦A、镜b实焦B),**用切镜代替同镜 rack focus**。
- **禁单镜内漫游机位/一镜到底绕拍**——需要跨越人物的调度一律拆相邻独立镜头。单镜只保留单一运镜(组合≤2种)。

### 空镜切入/回切

- **切入(人→空镜)**:硬切或运镜引导("镜头从说话者缓缓摇向窗外")。
- **回切(空镜→人)** 必须有触发:声音触发(台词提新人)/ 动作触发(环境变化)/ 情绪触发(旁白转折),不能让空镜自己结束。
- 空镜单次 ≤3 秒;总占比口播类 ≤30%、剧情类 ≤20%;连续空镜不超 2 次。
