# 开场方式库（Opening Hooks Library）

> 保险短视频AI生成专用开场方式完整库。配合 `prompt_craft_guide.md` 的「开场方式速查表」使用，速查表做快速选型，本库做深度执行。

## 使用说明

> **本库为参考和灵感来源，不是限定清单。** 鼓励组合、变体和创新。
> - **「禁止/必须」** = 合规红线或AI生成能力限制，需严格遵守（如禁手机屏幕内容、禁医护推荐保险、AI文字乱码需图形化）
> - **「建议/推荐/常见做法」** = 经验总结的有效方向，可根据创意突破（如时长控制、景别选择、节奏把握）
> - 库中方式可自由组合（如"药店场景口播+手持药品盒+大特写开场"），也可在基础上衍生新方式

1. **选型流程（参考路径，非唯一）**：可按「产品类型索引」找到适用的开场方式 → 再按「风格/时长」筛选 → 最后查阅对应条目获取写法和Prompt示例；也可直接从创意出发，自行设计开场方式
2. **硬约束（必须遵守）**：所有开场方式涉及手机时**禁止展示手机屏幕内容**；涉及医院/医护/药品时遵守医疗题材两条模式；AI生成文字必然乱码，所有需要文字的地方用图形/色块/【】标注代替
3. **时长建议（可调整）**：前贴（15-20s）开场建议在3秒内进入主题；成片（30s）可以有3-5秒场景建立；成片（60s）可以有5-8秒场景建立。特殊创意（如慢节奏情感向）可突破
4. **A/B测试建议**：同一脚本可配2-3种不同开场方式生成测试版，对比完播率和转化率

## 一、口播/Vlog类

### 1.1 直面镜头Hook

**画面描述**：中景，口播者面朝镜头直接开口说话，背景简洁或与产品相关。

**写法要点**：
- 第0秒即刻开口说话，不留前奏/空镜
- 建议前3秒是强信息句（痛点/反常识/提问），也可根据风格用氛围/悬念开场
- 口播者面朝镜头，眼神直视，口型随台词清晰张合
- 背景可以是纯色/居家/办公场景，不喧宾夺主

**Prompt核心片段**：
```
第0秒即刻开口说话，中景，口播者面朝镜头直视观众，嘴唇随台词清晰张合，说：{前3秒强信息句}
运镜：固定机位，全程机位不动，仅口播者动作和表情变化
背景：{简洁背景描述}，自然光，画面明亮通透
```

**适用**：口播/科普/带货/全险种
**避坑**：建议避免前3秒纯空镜/纯背景音乐前奏（容易流失观众）；建议口播者看镜头增强代入感，也可根据风格采用侧视/画外音

---

### 1.2 边走边说

**画面描述**：手持跟拍，口播者边走边说，背景随走动自然变化。

**写法要点**：
- 运镜：手持拍摄+跟随拍摄，带轻微自然晃动
- 口播者自然步态前行，边走边说，不僵直
- 背景环境随走动自然滑过（街道/走廊/商场）
- 建议口播者不要长时间静止，可配合手势或轻微移动增强活力；也可根据风格采用固定站姿

**Prompt核心片段**：
```
运镜：手持拍摄+跟随拍摄，镜头带轻微自然晃动，跟随口播者同步前行
中景，口播者面朝镜头（略侧45°），自然步态前行，边走边说，嘴唇随台词张合
背景为{街道/走廊}，随走动自然滑过，<环境脚步声>
```

**适用**：Vlog/探店/旅行/生活化引流
**避坑**：Vlog感常用手持晃动增强真实感，也可根据风格选择稳定器运镜；建议背景有自然变化增强空间感

---

### 1.3 翻转镜头

**画面描述**：先拍场景（第一视角），再翻转为自拍模式，口播者面对镜头。

**写法要点**：
- 前2-3秒是第一视角场景（看到的环境/手中物品）
- 然后"镜头翻转为自拍模式"，口播者面朝镜头
- 翻转动作要自然，像真实手机翻转
- 翻转后即刻开口说话

**Prompt核心片段**：
```
第0-2秒：第一视角，模拟角色视线，画面为{场景描述}，带轻微头部晃动
第2-3秒：镜头翻转为自拍模式，口播者面朝镜头出现
第3秒起：口播者面朝镜头说话，嘴唇随台词张合
```

**适用**：Vlog开场/日常分享/生活化引入
**避坑**：建议第一视角控制在3秒内（过长容易迷失主体）；翻转后建议即刻说话进入主题

---

### 1.4 物件特写拉开

**画面描述**：先拍手中/桌上物件特写，然后镜头后拉露出人物。

**写法要点**：
- 建议物件与话题相关（保险单/病历/合同/药品盒/银行卡等），也可用创意道具制造悬念
- 第0秒是物件特写，细节清晰
- 2-3秒后镜头后拉，露出手持物件的人物
- 人物后拉后即刻开口说话

**Prompt核心片段**：
```
第0-2秒：特写，{物件}占据画面中心，细节清晰，手握着物件
第2-4秒：运镜：镜头后拉，从特写拉至中景，露出手持物件的口播者
第4秒起：口播者面朝镜头说话，手中仍握着物件
```

**适用**：口播带道具/产品讲解/条款解读
**避坑**：建议物件与话题有一定关联（纯无关道具容易让观众困惑）；后拉后建议说话进入主题，也可保留静默营造氛围

---

### 1.5 背影转身

**画面描述**：角色背对镜头站立，然后缓缓转身面对镜头开口。

**写法要点**：
- 第0秒是角色背影，面向远方/窗户/场景
- 2-3秒后角色缓缓转身，面朝镜头
- 转身后眼神直视镜头，开口说话
- 适合悬念/情感类开场

**Prompt核心片段**：
```
第0-3秒：中景，角色背对镜头站立，面向{窗户/远方}，肩膀微沉
第3-4秒：角色缓缓转身，面朝镜头，眼神直视观众
第4秒起：角色面朝镜头开口说话，嘴唇随台词张合，语气{沉稳/感慨}
```

**适用**：悬念式口播/情感类/个人故事
**避坑**：建议转身控制在3秒内（过长容易拖沓）；转身后建议即刻说话，也可保留沉默营造悬念

## 二、场景化口播类

### 2.1 药店场景口播

**画面描述**：中景，口播者站在药店内，背景是药柜/处方药柜台，手持药品盒。

**写法要点**：
- 背景可见OTC标识/药柜/药品货架（不出现具体药名/品牌）
- 口播者穿便装，手持通用包装药品盒（纯色/简单图形）
- 可以偶尔指向药柜方向，但不拿起具体药品
- 语气专业可信，像药店工作人员或懂行的消费者

**Prompt核心片段**：
```
中景，口播者站在药店内，面朝镜头说话，嘴唇随台词张合
背景：药店药柜，货架上摆放通用包装药品盒（纯色包装，无可辨认文字/品牌），左侧有OTC标识
口播者手持一个通用包装药品盒（蓝白配色，无品牌名），自然手势
运镜：固定机位，自然光，画面明亮
```

**适用产品**：医疗险/重疾险/药品险/特药险
**避坑**：禁止出现具体药名/品牌/处方药包装；禁止穿白大褂（医护红线）

---

### 2.2 医院场景口播

**画面描述**：中景，口播者站在医院门诊楼前或大厅内，背景是医院建筑/标识。

**写法要点**：
- 背景可见医院标识/门诊大楼/导诊台（不出现医护人员推荐保险）
- 口播者穿便装，手持手机（屏幕朝下）或保单文件夹
- 站在医院外/大厅，不进入诊室/病房
- 语气客观，像刚从医院出来的消费者或探访者

**Prompt核心片段**：
```
中景，口播者站在医院门诊楼前，面朝镜头说话，嘴唇随台词张合
背景：医院门诊大楼，玻璃门上方有"门诊"字样（图形化，不生成可辨认文字），周围有绿化
口播者穿便装，手持手机（屏幕朝下，不展示屏幕内容），自然站姿
运镜：固定机位，白天自然光，画面明亮通透
```

**适用产品**：医疗险/重疾险/意外险/少儿险
**避坑**：禁止医护人员出镜推荐保险；禁止进入诊室/病房拍摄；禁止展示医院具体名称（用图形化代替）

### 2.3 社保局/政务大厅口播

**画面描述**：中景，口播者站在社保局/政务服务中心，背景是办事窗口/政务标识。

**写法要点**：
- 背景可见政务标识/办事窗口/排队叫号屏（图形化）
- 口播者穿便装，手持材料文件夹
- 语气像刚办完社保业务的消费者，客观介绍
- 可以提到"社保""医保"但不做具体政策解读

**Prompt核心片段**：
```
中景，口播者站在政务服务大厅内，面朝镜头说话，嘴唇随台词张合
背景：政务服务办事窗口，窗口上方有标识牌（图形化色块，无可辨认文字），远处有排队人群
口播者穿便装，手持文件夹，自然站姿
运镜：固定机位，室内冷白光，画面清晰
```

**适用产品**：社保/惠民保/政策险/百万医疗险（社保补充定位）
**避坑**：禁止穿制服/工装；禁止做具体政策解读（产品口径为准）

### 2.4 银行/理财场景口播

**画面描述**：中景，口播者站在银行大厅/理财区，背景是银行标识/ATM/理财柜台。

**写法要点**：
- 背景可见银行标识/ATM/理财柜台（不出现具体银行名称）
- 口播者穿便装或商务休闲装，手持理财单/银行卡
- 语气稳健，像理财顾问或有经验的储户
- 适合年金险/储蓄险的长期收益话题

**Prompt核心片段**：
```
中景，口播者站在银行大厅理财区，面朝镜头说话，嘴唇随台词张合
背景：银行大厅，右侧有ATM机（图形化界面），远处有理财柜台和等候区
口播者穿商务休闲装，手持银行卡和理财单（无银行logo），语气稳健
运镜：固定机位，室内暖白光，画面专业感
```

**适用产品**：年金险/储蓄险/理财险/增额终身寿
**避坑**：禁止承诺收益/保本保息（合规红线）；禁止出现具体银行名称/logo

**写法要点**：

**Prompt核心片段**：
```
中景，口播者站在体检中心大厅，面朝镜头说话，嘴唇随台词张合
背景：体检中心导检台，旁边有体检设备（图形化），墙上有流程图（图形化）
口播者穿便装，手持体检报告（封面朝外，不展示内页具体内容），语气有切身感
运镜：固定机位，室内明亮白光，画面干净
```

### 2.6 投影屏/白板讲解

**画面描述**：中景，主讲人站在投影屏幕/白板前，背后是产品PPT/数据图表。

**写法要点**：
- 背后投影屏显示产品PPT/数据图表（图表用色块/图形，不生成可辨认文字）
- 主讲人手持翻页笔/激光笔，偶尔指向屏幕
- 语气专业，像讲师/培训师
- 适合科普/产品深度讲解类内容

**Prompt核心片段**：
```
中景，主讲人站在投影屏幕前，面朝镜头说话，嘴唇随台词张合
背景：投影屏幕显示产品数据图表（用色块和柱状图图形化表示，不生成可辨认文字），屏幕下方有讲台
主讲人穿商务休闲装，手持翻页笔，偶尔指向屏幕方向
运镜：固定机位，室内灯光，屏幕光在脸上形成柔和反光
```

**适用**：全险种（科普/讲解向/产品深度解读）
**避坑**：投影屏文字必然乱码，必须用图形化/色块代替；禁止穿白大褂

### 2.7 客厅/家庭场景口播

**画面描述**：中景，口播者坐在家中沙发/餐桌前，背景是家庭环境。

**写法要点**：
- 背景是家庭环境（沙发/餐桌/全家福/绿植），温馨生活化
- 口播者穿居家便装，手持保单/遥控器/手机（屏幕朝下）
- 语气亲切，像家人朋友在聊天
- 适合家庭险/少儿险/年金险的情感化引入

**Prompt核心片段**：
```
中景，口播者坐在家中客厅沙发上，面朝镜头说话，嘴唇随台词张合
背景：家庭客厅，沙发上有靠垫，旁边有茶几和绿植，墙上挂着全家福（背影/侧影，不生成可辨认人脸）
口播者穿居家便装，手持保单文件夹，语气亲切自然
运镜：固定机位，室内暖黄光，画面温馨
```

**适用产品**：家庭医疗险/少儿险/年金险/寿险
**避坑**：全家福不生成可辨认人脸（用背影/侧影/虚化）；禁止过于奢华的家居（定位普通家庭）

## 三、手持道具类

### 3.1 手持保单/合同

**画面描述**：近景，口播者手持保单/合同面对镜头，手指指向条款区域。

**写法要点**：
- 保单/合同封面可见（用图形化设计，不生成可辨认文字）
- 手指指向特定区域（条款/保额/保费位置），边指边说
- 可以翻开保单内页，但内页用色块/线条代替文字
- 适合产品讲解/条款解读

**Prompt核心片段**：
```
近景，口播者手持保单合同面对镜头，嘴唇随台词张合
保单封面为深蓝色，有图形化logo和线条（不生成可辨认文字），口播者右手指向保单上的特定区域
口播者偶尔翻开保单内页，内页用色块和横线图形化表示（不生成可辨认文字）
运镜：固定机位，画面聚焦在保单和口播者上半身
```

**适用**：产品讲解/条款解读/全险种
**避坑**：保单文字必然乱码，必须用图形化/色块代替；手指不遮挡关键区域

---

### 3.2 手持药品盒/保健品

**画面描述**：近景，口播者手持药品盒（无品牌名）面对镜头介绍。

**写法要点**：
- 药品盒为通用包装（纯色/简单图形，不出现药名/品牌/处方药标识）
- 手持展示，可以转动盒子展示不同面
- 口播者介绍保障范围，不是推荐药品
- 适合医疗险/药品险/特药险

**Prompt核心片段**：
```
近景，口播者手持药品盒面对镜头，嘴唇随台词张合
药品盒为通用包装（蓝白配色，简单图形，无品牌名/药名/处方药标识），口播者左手持盒，右手轻指盒面
口播者偶尔转动盒子展示侧面，语气客观介绍保障范围
运镜：固定机位，画面聚焦在药品盒和口播者手部
```

**适用产品**：医疗险/药品险/特药险/重疾险
**避坑**：禁止出现具体药名/品牌/处方药包装（OTC红/绿标也避免）；禁止说"这个药能治XX"

---

### 3.3 手持手机（不展示屏幕）

**画面描述**：中近景，口播者手持手机，屏幕朝下或朝向自己，面对镜头说话。

**写法要点**：
- **手机屏幕必须不朝向镜头**，屏幕朝下/朝向人物自己/侧45°
- 人物偶尔低头看手机，但屏幕内容不可见
- 可以用<手机提示音>作为触发，但不展示屏幕
- 手机作为生活化道具，增加真实感

**Prompt核心片段**：
```
中近景，口播者手持手机面对镜头说话，嘴唇随台词张合
手机屏幕朝下（朝向地面），不展示屏幕内容，口播者自然握持
第3秒时<手机提示音>响起，口播者低头看了一眼手机（屏幕朝向自己，不可见），然后抬头继续说话
运镜：固定机位，生活化场景
```

**适用**：全险种（生活化/引流/真实感）
**避坑**：**绝对禁止展示手机屏幕内容**（AI生成文字乱码+与产品不一致）；手机屏幕必须朝下或朝向自己

---

### 3.4 手机提示音触发

**画面描述**：中景，人物正在做某事，<手机提示音>响起，人物拿起手机看（屏幕不朝向镜头），表情变化后转向镜头说话。

**写法要点**：
- 第0秒是人物日常动作（做饭/工作/带娃/散步）
- <手机提示音>作为声音触发，人物拿起手机（屏幕朝向自己，不可见）
- 表情从平静到关注/惊讶/凝重，然后放下手机面对镜头
- 适合痛点引入/消息触发/引流开场

**Prompt核心片段**：
```
第0-3秒：中景，人物正在{做饭/工作/带娃}，表情平静，<日常环境音>
第3秒：<手机提示音>突然响起，人物停下动作，拿起手机（屏幕朝向自己，不展示屏幕内容）
第3-5秒：人物看手机，表情从平静变为{关注/惊讶/凝重}，眉头微皱
第5秒起：人物放下手机，转身面朝镜头说话，嘴唇随台词张合，语气{郑重/急切}
```

**适用**：痛点引入/消息触发/引流/全险种
**避坑**：**绝对禁止展示手机屏幕内容**；提示音后必须在5秒内转向镜头说话（不能一直看手机）

---

## 四、采访/对话类

### 4.1 记者出镜采访

**画面描述**：中景，记者手持麦克风面对镜头，旁边是受访者。

**写法要点**：
- 记者穿正装/便装，手持麦克风（通用台标，不出现真实媒体logo）
- 记者先出镜介绍/提问，然后转向受访者
- 受访者在旁边听/回答，表情自然
- 适合深度采访/专题/用户证言

**Prompt核心片段**：
```
中景，记者和受访者并排站立，记者在画面左侧，受访者在画面右侧
记者手持麦克风（麦克风头部有通用圆形台标，无真实媒体logo），面朝镜头说话，嘴唇随台词张合：{记者介绍/提问}
记者说完后转向受访者，受访者面朝画外（记者方向），嘴唇随台词张合回答：{受访者回答}
运镜：固定机位，户外/室内场景，自然光
```

**适用**：深度采访/专题/用户证言/全险种
**避坑**：麦克风不出现真实媒体logo；建议受访者回答口语化、有真实感，避免过于书面或像背广告词

---

### 4.2 街头随机采访

**画面描述**：中景，记者在街道/商场拦住路人，手持麦克风采访。

**写法要点**：
- 背景是街道/商场人流，有路人走过
- 记者递麦克风动作，路人穿着日常，表情自然
- 路人回答简短（1-2句），口语化
- 适合街采/用户反馈/民意调查

**Prompt核心片段**：
```
中景，记者在街道旁拦住一位路人，记者手持麦克风递向路人
背景：城市街道，有行人和车辆经过（虚化），路边有商铺
路人穿日常便装，表情自然略带意外，面朝记者方向说话，嘴唇随台词张合：{路人简短回答}
记者在旁边点头倾听，偶尔追问
运镜：手持拍摄，带轻微自然晃动，街采真实感
```

**适用**：街采/用户反馈/民意调查/全险种
**避坑**：建议路人回答口语化、自然，避免过于书面；建议背景人流适度虚化，不喧宾夺主

---

### 4.3 多人接力采访

**画面描述**：快切，连续采访3-4个不同人，每人说一句话，最后定格在主讲人。

**写法要点**：
- 每个人1-2秒快切，背景/人物各不相同
- 每人说一句简短证言（不超过15字）
- 最后定格在主讲人，做总结/产品引入
- 适合多人证言/用户口碑/社会共识

**Prompt核心片段**：
```
第0-2秒：近景，第一位受访者（年轻女性，办公室背景）面朝镜头说：{证言1}
第2-4秒：硬切，近景，第二位受访者（中年男性，街道背景）面朝镜头说：{证言2}
第4-6秒：硬切，近景，第三位受访者（老年女性，家中背景）面朝镜头说：{证言3}
第6秒起：硬切，中景，主讲人面朝镜头说话，做总结/产品引入
运镜：每段固定机位，快切节奏，每人不超过2秒
```

**适用**：多人证言/用户口碑/社会共识/全险种
**避坑**：建议每人控制在2秒/15字内（快切节奏），也可根据内容调整；建议背景各不相同增强"多人"感；建议最后有主讲人总结，也可直接收尾

---

### 4.4 采访设备特写开场

**画面描述**：特写，麦克风/录音笔，随后镜头后拉露出采访场景。

**写法要点**：
- 第0秒是麦克风头条特写（通用台标）
- 2-3秒后镜头后拉，露出记者和受访者
- 适合专业感/仪式感开场

**Prompt核心片段**：
```
第0-2秒：特写，麦克风头部占据画面中心，麦克风头部有通用圆形台标（无真实媒体logo），金属网罩细节清晰
第2-4秒：运镜：镜头后拉，从特写拉至中景，露出手持麦克风的记者和旁边的受访者
第4秒起：记者面朝镜头/受访者说话，嘴唇随台词张合
```

**适用**：专业感/仪式感/深度采访开场
**避坑**：麦克风不出现真实媒体logo；建议后拉后即刻说话进入主题，也可保留环境音营造氛围

---

### 4.5 电话通话采访

**画面描述**：中景，人物拿着手机贴耳，表情认真，不展示手机屏幕。

**写法要点**：
- 手机贴耳（屏幕朝向脸部，不可见），人物表情随通话内容变化
- 对方声音以画外音/电话音质出现（带轻微电话滤镜感）
- 适合远程采访/咨询/回访场景
- 可以是人物在听电话，也可以是人物在打电话

**Prompt核心片段**：
```
中景，人物坐在{沙发/办公桌}前，手持手机贴耳（屏幕朝向脸部，不可见），表情认真
人物嘴唇微动（在听对方说话），偶尔点头，<电话音质的对方声音>从画外传来：{对方提问/说话}
第5秒起，人物开始说话，嘴唇随台词张合：{人物回答/介绍}，语气{专业/耐心}
运镜：固定机位，室内场景
```

**适用**：远程采访/咨询/回访/客服场景/全险种
**避坑**：**绝对禁止展示手机屏幕内容**；对方声音必须标注电话音质（画外音）

---

## 五、大特写/极近景类

### 5.1 面部大特写直入

**画面描述**：极近景，人物面部占画面80%以上，直面镜头说话。

**写法要点**：
- 第0秒就是面部大特写，五官清晰，眼神直视镜头
- 口型随台词清晰张合，背景完全虚化
- 建议前3秒是强信息句/情绪爆发点，也可用纯视觉冲击+后续旁白
- 适合强钩子/个人IP/情感共鸣

**Prompt核心片段**：
```
第0秒即刻开口说话，极近景，人物面部占画面80%以上，面朝镜头直视观众
五官清晰不变形，眼神坚定直视镜头，嘴唇随台词清晰张合，说：{前3秒强信息句}
背景完全虚化（浅景深），只有人物面部清晰
运镜：固定机位，面部保持在画面中心，不移动
```

**适用**：强钩子/个人IP/情感共鸣/全险种
**避坑**：AI生成大特写容易面部变形，建议加强"五官清晰不变形"约束；建议前3秒说话进入主题，也可保留沉默营造悬念

---

### 5.2 眼睛特写开场

**画面描述**：大特写，只有眼睛和眉毛区域，眼神变化。

**写法要点**：
- 第0秒是眼睛特写，瞳孔/睫毛清晰
- 眼神从平静到惊讶/坚定/湿润，有变化过程
- 2-3秒后镜头后拉露出全脸
- 适合悬念/情绪/觉醒时刻

**Prompt核心片段**：
```
第0-3秒：大特写，只有眼睛和眉毛区域占据画面，瞳孔/睫毛清晰可见
眼神从平静逐渐变为{惊讶/坚定/湿润}，眉毛微微上扬/紧皱，有细微的眼神变化
第3-5秒：运镜：镜头后拉，从眼睛特写拉至面部近景，露出人物全脸
第5秒起：人物面朝镜头说话，嘴唇随台词张合
```

**适用**：悬念/情绪/觉醒时刻/重疾险/医疗险
**避坑**：眼睛特写AI容易生成异常（瞳孔不对称/多眼皮），建议加强约束；建议眼神变化控制在3秒内，也可根据情绪需要延长

---

### 5.3 嘴巴说话特写

**画面描述**：大特写，只有嘴巴和下巴区域，嘴唇随台词张合。

**写法要点**：
- 第0秒是嘴巴特写，嘴唇自然状态
- 说话时嘴唇动作清晰，关键词时加重/放慢
- 适合强调关键词/耳语感/亲密感
- 可以配合手部动作（手指放在嘴唇上/触摸下巴）

**Prompt核心片段**：
```
第0秒即刻开口说话，大特写，只有嘴巴和下巴区域占据画面中心
嘴唇自然状态（涂自然色口红/无妆），说话时嘴唇随台词清晰张合，说到关键词时嘴唇动作加重/放慢
画面下方可见下巴和颈部，上方可见鼻子底部，不出现眼睛
运镜：固定机位，嘴唇保持在画面中心
```

**适用**：强调关键词/耳语感/亲密感/秘密分享/全险种
**避坑**：AI生成嘴巴容易牙齿异常/嘴唇变形，必须加强约束；不出现眼睛（避免面部整体变形）

---

### 5.4 手部动作大特写

**画面描述**：大特写，手部动作占满画面（签字/翻页/捏紧拳头/颤抖）。

**写法要点**：
- 第0秒是手部特写，动作具体可见
- 建议动作承载叙事信息（签字=决定/翻页=查看/捏拳=愤怒/颤抖=紧张），也可用纯美学动作营造氛围
- 2-3秒后镜头上移露出人物
- 适合决定/行动/情绪外化

**Prompt核心片段**：
```
第0-3秒：大特写，手部动作占据画面，{握笔在保单上签字/翻开保单第一页/手指捏紧拳头/手指微微颤抖}
动作过程清晰可见，不是只展示结果，手部皮肤纹理自然
第3-5秒：运镜：镜头上移，从手部特写移至人物面部近景
第5秒起：人物面朝镜头/画外说话，嘴唇随台词张合，表情{坚定/凝重/愤怒}
```

**适用**：决定/行动/情绪外化/全险种
**避坑**：AI生成手部容易手指异常（六指/弯曲畸形），必须加强"手指数量正常/结构正常"约束

---

### 5.5 道具大特写开场

**画面描述**：大特写，道具占满画面（保单/药品盒/账单/病历夹）。

**写法要点**：
- 第0秒是道具大特写，细节清晰（质感/纹理/公章）
- 不生成可辨认文字，用图形化/色块/线条代替
- 手进入画面拿起/翻开道具，随后后拉露出人物
- 适合产品/证据/冲击感

**Prompt核心片段**：
```
第0-2秒：大特写，{保单/药品盒/账单}占据画面，细节清晰（保单公章质感/药品盒包装纹理/账单纸张纹理），表面用色块和横线图形化表示（不生成可辨认文字）
第2-4秒：一只手进入画面，拿起/翻开道具
第4-6秒：运镜：镜头后拉，从道具特写拉至中景，露出手持道具的口播者
第6秒起：口播者面朝镜头说话，嘴唇随台词张合
```

**适用**：产品/证据/冲击感/全险种
**避坑**：道具文字必然乱码，必须用图形化/色块代替；手进入画面时注意手指结构正常

## 六、剧情/叙事类

> 剧情/叙事类11种开场方式保留原有写法，详见 `prompt_craft_guide.md` 速查表。本库仅补充保险场景化的具体应用提示。

### 6.1 高空远景/城市航拍
**保险场景应用**：从城市航拍降至医院/社保局/银行，建立地域和场景感。适合惠民保/城市定制险。

### 6.2 建筑空镜立人设
**保险场景应用**：医院大门/社保局/银行大厅/高端社区，用建筑暗示人物身份和经济状况。

### 6.3 脚部入场特写
**保险场景应用**：皮鞋走进银行/运动鞋跑进医院/拖鞋走出病房，用鞋子暗示人物状态。

### 6.4 车内第一视角
**保险场景应用**：开车赶往医院/坐在车内看保单/接保险公司电话，封闭空间制造紧迫感。

### 6.5 关键冲突直入
**保险场景应用**：夫妻因保费争吵/家属在医院走廊争执/患者与缴费窗口冲突，零铺垫直进矛盾。

### 6.6 延时定场
**保险场景应用**：医院日夜交替/社保大厅人流变化/四季变化暗示时间流逝，适合长期保障/年金险。

### 6.7 穿越机入局
**保险场景应用**：穿越机飞入医院大厅/穿过社保窗口/飞入家庭客厅，空间感强，适合3D动画风格。

### 6.8 手部特写起步
**保险场景应用**：手握笔签字/手翻病历/手数钱/手捏紧保单，手部承载决定/焦虑/希望等情绪。

### 6.9 画外音+空镜
**保险场景应用**：医院走廊空镜+旁白"那年我爸住院"/缴费窗口空镜+旁白"账单出来的那一刻"，旁白定调后人物出场。

### 6.10 镜面/水面倒影
**保险场景应用**：医院玻璃门倒影/病房窗户倒影/水杯水面倒影，模糊变形的虚影暗示焦虑/不确定。

## 七、事件/事故直入类

### 7.1 意外事故直入

**画面描述**：中景，意外事故发生瞬间（摔倒/碰撞/突发疾病倒地）。

**写法要点**：
- 第0秒就是事故发生瞬间，动作有过程（脚下一滑→摔倒/两车相撞→人后退）
- 周围人反应（惊呼/上前查看）
- **不表现血腥/断肢/内脏/血迹**，用动作和表情传递意外
- 适合意外险/医疗险开场

**Prompt核心片段**：
```
第0秒即刻进入事故场景，中景，{老人在浴室脚下一滑摔倒在地/电动车与自行车相撞，骑车人摔倒在地/中年人突然捂住胸口倒地}
动作过程清晰可见（不是只展示结果），周围人惊呼并上前查看
画面不出现血腥/断肢/血迹，人物表情痛苦但不夸张
运镜：固定机位或手持轻微晃动，真实感
第5秒起：画面切到/推到家属或当事人表情特写
```

**适用产品**：意外险/医疗险/重疾险
**避坑**：**绝对禁止血腥/断肢/内脏/大量血迹**（合规+AI生成能力限制）；建议事故动作有过程增强真实感，也可根据风格只展示结果或用音效暗示

---

### 7.2 急诊抢救场景

**画面描述**：中景，救护车/急诊室/担架推入，医护人员推车奔跑。

**写法要点**：
- 背景是急诊室/救护车，担架上盖白布（不露脸）
- 医护人员推车奔跑表情紧张（**医护只做抢救动作，绝不提保险/推荐保险**）
- 家属在旁边焦急跟随
- 适合医疗险/重疾险/意外险

**Prompt核心片段**：
```
中景，急诊室走廊，医护人员推着担架车快速奔跑，担架上盖着白色床单（不露脸/不露出身体）
医护人员穿白大褂，表情紧张专注，只做推车/抢救动作，绝不说话提保险
家属在旁边焦急跟随，表情凝重，眼眶泛红
<急诊室环境音：脚步声/监护仪滴答声/远处呼喊>
运镜：跟随拍摄，带轻微晃动，紧迫感
```

**适用产品**：医疗险/重疾险/意外险
**避坑**：**医护人员绝对不能提保险/推荐保险**（医疗题材红线）；担架不露脸/不露出身体（避免AI生成异常）

---

### 7.3 缴费窗口冲击

**画面描述**：中近景，医院缴费窗口，人物拿着账单表情震惊。

**写法要点**：
- 缴费窗口背景，人物手持账单/发票
- 表情从平静到震惊/无奈/凝重
- 账单金额用【】标注特写（不生成可辨认数字，用图形化数字/色块代替）
- 适合医疗险/惠民保痛点引入

**Prompt核心片段**：
```
中近景，医院缴费窗口前，人物手持账单/发票，面朝窗口方向
背景：缴费窗口，窗口内有工作人员（虚化），窗口玻璃上有图形化标识
人物先看账单，表情从平静逐渐变为震惊/无奈，眉头紧皱，嘴唇微张
镜头推近至账单特写，账单上金额区域用【】标注（图形化大数字，不生成可辨认文字）
运镜：固定机位→缓推至账单特写
```

**适用产品**：医疗险/惠民保/重疾险
**避坑**：账单数字必然乱码，必须用图形化/【】标注代替；窗口工作人员不说话/虚化

---

### 7.4 体检报告打开瞬间

**画面描述**：特写，手翻开体检报告，手指指向异常指标区域。

**写法要点**：
- 第0秒是手翻开体检报告的动作
- 报告上异常指标用红色箭头/↑↓图形标注（不写具体病名/数字）
- 手指指向异常项，随后上移露出人物凝重表情
- 适合重疾险/医疗险/健康险

**Prompt核心片段**：
```
第0-3秒：特写，手翻开体检报告，报告页面上有红色箭头和↑↓图形标注（表示异常指标，不写具体病名/数字）
手指指向异常指标区域，手指停顿
第3-5秒：运镜：镜头上移，从报告特写移至人物面部近景
第5秒起：人物表情凝重，眉头微皱，看着报告，然后抬头面朝镜头说话
```

**适用产品**：重疾险/医疗险/健康险/防癌险
**避坑**：报告指标必然乱码，必须用红色箭头/↑↓图形代替；不写具体病名（合规+避免误导）

---

### 7.5 救护车远景驶入

**画面描述**：远景，救护车闪着灯驶入画面，伴随警笛声。

**写法要点**：
- 第0秒是街道远景，救护车从远处驶来
- 红蓝警灯闪烁，<救护车警笛声>由远及近
- 随后切到近景/人物反应（家属焦急/路人围观）
- 适合意外险/医疗险/重疾险

**Prompt核心片段**：
```
第0-4秒：远景，城市街道，救护车从远处驶入画面，红蓝警灯闪烁
<救护车警笛声>由远及近，逐渐变大
第4-6秒：硬切，近景，家属在医院门口焦急等待，看到救护车后表情紧张，上前迎接
第6秒起：画面切到急诊室/家属对话场景
运镜：远景固定机位→硬切近景
```

**适用产品**：意外险/医疗险/重疾险
**避坑**：警笛声不能过长（不超过4秒）；救护车不出现真实医院名称/logo

### 7.6 紧急拨打电话

**画面描述**：中近景，人物焦急地拿着手机贴耳（不展示屏幕），表情慌张。

**写法要点**：
- 第0秒是人物焦急表情，背景是事故/突发场景
- 人物拿起手机贴耳（屏幕朝向脸部不可见），<拨号音>后急促说话
- 适合"打120""打保险公司电话"等紧急场景
- 适合意外险/医疗险/重疾险

**Prompt核心片段**：
```
中近景，人物表情焦急慌张，背景是{事故现场/医院走廊/家中}
人物拿起手机贴耳（屏幕朝向脸部，不展示屏幕内容），<拨号音>响起
第3秒起，人物急促说话，嘴唇随台词张合：{"喂120吗"/"喂保险公司吗，我要报案"/"医生你快看看"}，语气急切
人物另一只手扶住{伤者/额头/桌子}，身体微微颤抖
运镜：手持拍摄，带轻微晃动，紧迫感
```

**适用产品**：意外险/医疗险/重疾险
**避坑**：**绝对禁止展示手机屏幕内容**；建议拨号音控制在2秒内；建议人物说话清晰可辨，也可根据风格用急促呼吸/环境音代替

## 八、产品/营销类

> 产品/营销类3种开场方式保留原有写法，详见 `prompt_craft_guide.md` 速查表。

### 9.1 延迟全貌法
**保险场景应用**：先展示保单公章特写→保额数字特写→人物签字特写→后拉露出完整投保场景。每个局部特写都承当一次"重要性证明"。

### 9.2 问题场景直入
**保险场景应用**：直接展示痛点场景（排队缴费/翻遍存折/家人争吵），用画面行为呈现痛点，不用文字说明，然后产品出场解决。

### 9.3 仪式降临
**保险场景应用**：80%黑场只勾勒保单/保障伞轮廓→光影突变揭示产品全貌，揭示瞬间环境音全部静默2-3秒，适合高端产品/新品发布。
