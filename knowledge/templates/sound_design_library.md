# 声音设计素材库

> 可复用的声音 motif / 介质声 / 场景物件音效。写 Prompt 的「本镜声音」时从这里选,不再凭空想。
> **规则**:全片只写一段声音通则,每镜音效写在分镜条目里;台词短促可互相打断;结尾固定"不叠加任何背景音乐"(除明确要 BGM 的风格)。

## 一、环境垫底声 motif(按场景选 1-2,持续垫底)

| 场景 | 垫底声 |
|---|---|
| **海边/码头** | 海风、浪的闷响、退潮的沙沙声 |
| **城市/街头** | 远处车流、电动车驶过、环境人声底噪 |
| **室内/家** | 冰箱嗡鸣、楼道人声、风扇摇头声 |
| **山林/公园** | 风穿树冠、蝉鸣、脚踩落叶 |
| **夜间** | 虫鸣、远处犬吠、路灯镇流器电流声 |

## 二、介质声(按拍摄设备选,决定声音"年代感/质感")

| 介质 | 声音特征 |
|---|---|
| **Super 8 胶片** | 跑片机械嗡鸣(很轻,人说话就被盖住) |
| **手机** | 麦克风风爆(噗噗声)、数码底噪 |
| **DV 录像** | 带仓机械声、变焦马达声、磁带底噪 |

> 介质声要和画面的"成像设备"配对(手机画面→手机声),与 `visual_style_system` 的成像基底一致。

## 三、场景物件音效池(每镜 2-3 个,须与画面动作对应)

| 场景 | 音效池 |
|---|---|
| **码头/渔港** | 缆绳摩擦桩的吱呀、浮球碰撞空响、渔船马达、赤脚踩湿水泥的啪嗒 |
| **小店/冰室** | 冰柜压缩机嗡鸣、柜盖掀开合上的闷响、冰棍纸撕开的刺啦、玻璃瓶碰响 |
| **林间/公园** | 风穿树冠沙沙、踩松针的窸窣、树枝勾住又弹回 |
| **医院** | 走廊回声、推车轮子、远处叫号(禁监护仪/仪器特写声) |
| **家庭** | 关门声、碗筷碰撞、钥匙放桌面、拖鞋走动 |
| **街道** | 鸣笛、小贩叫卖、自行车铃、脚步声 |

## 四、台词节奏(beat-chain)

- 每镜 **1-3 句**(缓镜 2-4 句),夹在动作里,不整段对话。
- 人物之间**互相说,不面向镜头**(除非互动型镜头)。
- 短句、口语、**允许互相打断**;听不清也没关系,不为说清楚而放慢。
- 每镜人声只保留 1 个爆点(谁在这镜说关键句),其余是环境音效。
