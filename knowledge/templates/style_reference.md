## 风格锁定规则

- 确定风格后，将完整的风格关键词记录到创意文档的整体风格字段
- 所有镜头的prompt末尾必须重复完整的风格关键词，禁止跨镜头改写
- 禁止中途切换风格，如需更换需重新生成所有参考素材

## 预置锚定图 — 平台适配

> 平台原生 `video_creation` 技能内置了20种经过验证的风格概览图，存放于 `/workspace/.skills/video_creation/refs/creative/anchors/`。保险视频项目可直接引用这些预置锚定图，跳过风格概览图生成步骤。

### 使用方法

1. 在上方速查表中找到匹配的风格行
2. 对应的预置锚定图路径非"—"时，用以下命令复制到项目目录：
```bash
cp /workspace/.skills/video_creation/refs/creative/anchors/{文件名} assets/{project}/style_anchor.png
```
3. 复制后跳过风格概览图生成，直接进入角色/场景参考图生成阶段

### 穿搭描述四维模型

角色锁定卡中「默认服装」字段按以下四维度展开，避免笼统描述：

```
[色彩搭配] 主色+辅色+点睛色，色温倾向，饱和度水平
[单品层次] 外层→内层→下装→鞋履，每层标注面料+颜色，叠穿露出位置
[配饰系统] 从头到脚列举，标注与服装的呼应关系
[氛围质感] 风格气质关键词+面料动态物理特征
```

### 配色三原则（保险视频角色穿搭适用）

1. **60-30-10比例**：60%基底低饱和色 + 30%辅助同色系 + 10%点睛高饱和色
2. **色温统一**：同一角色同一场景内色温一致，跨场景可切换
3. **明度层次**：上装/下装/配饰三者明度有差异，避免全身同明度扁平感
