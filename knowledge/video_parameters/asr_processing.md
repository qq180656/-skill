# ASR 逐字稿处理规范（asr_processing）

> 视频生成完成后，调火山 ASR 对音轨做语音识别，拿到逐字稿后进行标点恢复、同音纠错、文本对齐、差异分析，产出可用于字幕和校验的结构化文本。
> 保险口播视频竖屏 9:16 为主。与 `wf_verification.md` Step 1-3 对应（ASR_TRANS → TEXT_CLEAN → DIFF_ANALYSIS）。

## 依赖
- `knowledge/video_parameters/config_matrix.md` — 字幕字数（≤14字/行）、语速、SRT标准流程
- `knowledge/tts_optimization/pronunciation_rules.md` — 发音规避词表（同音纠错、CAR-T卡替、删除级息肉/超声）
- `atomic_scripts.json` — 原子脚本列表（**DIFF_ANALYSIS 唯一基准**）

## 第1章：火山 ASR 返回格式

### 1.1 结构
```json
{
  "result": {
    "text": "完整识别文本（含ASR自动标点）",
    "utterances": [
      {"text":"这是第一句，","start_time":0,"end_time":1705,"definite":true,
       "words":[{"text":"这","start_time":740,"end_time":860,"blank_duration":0}]}
    ]
  },
  "audio_info": {"duration":10000}
}
```
- `result.utterances[].words[]`：逐字 start/end（毫秒），字幕对齐核心；用秒÷1000保留3位；blank_duration 不用
- `definite` true=已确定分句 false=可能调整

### 1.2 关键特征
毫秒级时间戳；ASR按语音停顿分句（不一定符语义）；自带标点但位置可能不准；常见同音错误（好医保→好质保、符合条件→个头条件）。

## 第2章：处理流水线
```
火山ASR JSON
 → Step1 原始提取：WordTime[]逐字时间戳 + 全文文本(保留纠错前原件)
 → Step1.5 逐字稿导出：WordTime[] 直出 → {名称}_逐字稿.srt + {名称}_words.json（存 字幕/，不经LLM，见第10.5章）
 → Step2 标点恢复：LLM按语义重新断句加标点(每段≤14字)
 → Step3 同音纠错：ASR同音错字纠正到原子脚本对应词(只改文字/不动时间戳)
 → Step4 占位符保护：产品名/数字/百分比→占位符(对齐后还原)
 → Step5 文本对齐：ASR原文(纠错前) vs 原子脚本 逐字diff(Levenshtein适配)
 → Step6 差异分类：replace/insert/delete分流
 → Step7 SRT生成：逐字稿词时间戳 + 标点恢复断句 → 口播字幕SRT（**逐字稿的派生产物**）
```
**关键**：DIFF 用 Step1 纠错前原始文本（Step3 纠错会抹平发音错误）；SRT 用 Step2 标点恢复文本。
**源头唯一**：Step1.5 的逐字稿（SRT+JSON）是字幕链路唯一源头，Step7 口播字幕SRT 由它派生；两者共用同一份 ASR words，**不得各自独立再跑一次 ASR**。

## 第3章：Step1 原始提取
- 拍平 utterances→words 为一维 WordTime(text/start/end)，毫秒→秒÷1000保留3位，忽略 blank_duration
- 保留 result.text 纠错前原始版（Step3 基线）
异常：utterances空→ASR失败进WAITING_USER；words空但text有→按字切分时间均分；部分字缺时间戳→前后字均值；全文置信度<0.95→标"低置信度"DIFF降阈值。

## 第4章：Step2 标点恢复
ASR标点基于停顿非语义，用 **LLM（Doubao-Seed-2.0-mini，高并发稳；Evolving长文本超时）** 对去标点纯文字重新断句：
- 每段≤14中文字；语义完整处（逗号/句号/问号）断；产品名/数字(15.08元/100%/400万)/核心术语(免赔额/报销比例)不拆
- 结果**仅用于字幕显示**，不用于DIFF；**禁止本地机械切字**，LLM 429/超时只能重试/换key
- 断句后去标点字数须与原文守恒，不守恒重试

## 第5章：Step3 同音纠错
- 原则：**纠错回原子脚本对应词，不替换同义词**（"个头条件"→"符合条件"，非"满足条件"）
- 从 atomic 取期望文本逐段比对，同音差异替换为期望词；**只改文字不改时间戳**；同句内不跨段
- 常见词表（持续积累）：好质保/好植保→好医保（产品名位）、个头条件→符合条件、百分百→100%（比例语境）、超生→超声（医疗语境）
- 禁区：纠错后文本**不用于DIFF**；不改字数；不跨段

## 第6章：Step4 占位符保护
DIFF前替换（映射存 `_session/alignment_map.json`，原子与ASR两侧都替换，diff后还原）：
| 原文 | 占位符 |
|------|--------|
| 好医保·中老年长期医疗 | [PROD_01] |
| 好医保·少儿长期医疗 | [PROD_02] |
| 15.08元 | [NUM_01] |
| 100% | [PCT_01] |
| 400万 | [NUM_02] |
| 70岁 | [NUM_03] |
- 间隔号"·"不念、ASR不识别，整产品名占位不比"·"；**字幕显示补回"·"**（产品名完整）

## 第7章：Step5 文本对齐
以原子脚本为 target、ASR纠错前原文为 source，Levenshtein 逐字（中文单字/英文单词/数字完整）：
match相同 / replace同位置不同 / insert原子有ASR无(漏念) / delete ASR有原子无(多念)。

## 第8章：Step6 差异分类与分流
| 类型 | 定义 | 去向 | 严重度 |
|------|------|------|--------|
| replace | 同位置文字不同=发音错 | wf_correction（TTS克隆音频替换 AUDIO_REPAIR） | 中 |
| insert | 漏念 | 1-2字先AUDIO_REPAIR；3-5字/整句>5字 VIDEO_REDO | 高 |
| delete | 多念 | 1-2字先音频切割；整句>5字必须VIDEO_REDO | 高 |

**过滤规则**：置信度<0.5跳过；**单字同音过滤（拼音+声调，见8.3）**；纯数字格式差异跳过（读法错不豁免）；replace>10字跳过（疑对齐错位）；仅标点差异跳过。
### 8.3 同音声调判定（pypinyin，无库默认不跳过=宁多报）
- 单字差异+拼音全同+声调同 → ASR同音误差，跳过
- 拼音同+声调不同 → 声调错误，进replace
- 拼音不同 → 真实发音错，进replace
### 差异报告
含：视频信息/置信度、match·replace·insert·delete·过滤跳过计数、逐项（时间位置、原子、ASR、拼音对比、判定、去向）、过滤项。

## 第9章：Step7 SRT生成
- **前提**：先按第10.5章导出逐字稿（`_逐字稿.srt` + `_words.json`）；本章的口播字幕SRT 是**逐字稿的派生产物**（LLM 断句给分行、时间戳仍取逐字稿词时间戳），不是与逐字稿并列的第二份 ASR 输出
- 用 WordTime逐字时间戳 + Step2标点恢复断句；每段首字start、末字end+0.1s
- **SRT格式**：序号递增；`HH:MM:SS,mmm --> HH:MM:SS,mmm`（逗号毫秒）；每条≤2行每行≤14中文字；换行LF；UTF-8 **without BOM**；产品名独立成段
- 产品名段时间=各字WordTime范围；字幕补回"·"
- **警示语SRT**：独立文件，时间轴对齐触发句 start→end，最多4行每行≤20字，与口播SRT分别编号
- 口播与警示语可重叠（警示语下方小字）；同屏最多口播+警示语+压底三层

## 第10章：审核文档
`{项目}/{日期}/审核文档/{序号}_{名称}.md`，含：视频信息/置信度、ASR逐字稿（原始/纠错后/标点恢复后字幕用）、差异报告、触发句↔警示语对应表（触发句/警示语/时间轴）、校验结论（发音replace、漏念、多念、警示语挂载x/x、字幕清单）。

> 审核文档内嵌的是**加标点的可读文本版**逐字稿（给人核对用）；机器可读的逐字稿文件（`_逐字稿.srt` + `_words.json`）存 `{项目}/{日期}/字幕/`，见第10.5章——两者同源，不要各写一份。

## 第10.5章：逐字稿导出规范（v4.0 新增，v4.1 统一为 SRT+JSON）

ASR 验证完成后，**必须导出逐字稿**（之前只导出断句 SRT 和审核文档，缺逐字级数据——口播字幕的断句对齐、字幕烧录的时间轴对齐都依赖逐字稿，不能只有断句 SRT）。

**逐字稿是字幕链路的唯一源头**：`逐字稿（ASR words 直出）→ LLM 语义断句 → 口播字幕SRT`。口播字幕不是"另一份 ASR 输出"，禁止两者各自独立生成（会时间轴/文字不一致且无法追溯）。

### 格式（两份，缺一不可）

| 文件 | 格式 | 用途 |
|------|------|------|
| `{名称}_逐字稿.srt` | SRT，每条只有 1 个字（ASR 返回的最小单元），时间戳精确到毫秒 | 人看 / 播放器可直接加载 / 剪辑软件可导入 |
| `{名称}_words.json` | JSON 数组 `[{"text":"字","start":0.32,"end":0.36}, ...]`（单位秒，3 位小数） | 程序读取（口播字幕断句对齐、烧录时间轴、DIFF） |

- 路径：**`{项目}/{日期}/字幕/`**（与口播字幕SRT同目录，**不另建 `逐字稿/` 子目录**）
- 交付目录中带序号前缀，即 `{序号}_{名称}_逐字稿.srt` / `{序号}_{名称}_words.json`（见 `outputs/delivery_standard.md`）
- 编码：UTF-8 **without BOM**；换行 LF；SRT 序号从 1 递增不跳号；时间轴 `HH:MM:SS,mmm --> HH:MM:SS,mmm`（逗号毫秒）
- ⚠️ 旧版 TAB 分隔的 TXT 逐字稿（`起始秒<TAB>结束秒<TAB>字`）与 `{项目}/{日期}/逐字稿/` 子目录**已废弃**，不再产出

### 示例

`{名称}_逐字稿.srt`：

```
1
00:00:00,840 --> 00:00:01,040
咱

2
00:00:01,040 --> 00:00:01,160
爸
```

`{名称}_words.json`：

```json
[{"text": "咱", "start": 0.840, "end": 1.040},
 {"text": "爸", "start": 1.040, "end": 1.160}]
```

### 来源
- 从火山ASR的 `words` 词级数据**直接导出**（`w.text` + `w.start_sec` + `w.end_sec`，毫秒÷1000 保留 3 位）
- **不经 LLM，不做任何断句/合并/纠错/加标点**：逐字稿必须保持 ASR 原始粒度与原始识别文字（含错字）。错字由 Step3 同音纠错在下游处理，**不回写逐字稿**
- ASR 有缓存时从缓存读取（不重新调 API）
- **数字/英文多字 token 不在此步展开**（保持ASR原始粒度）；展开在字幕烧录 Step 2 做（见 subtitle_burnin.md）
- 参考实现：`scripts/skill_config.py` 的 `words_to_transcript_srt()` / `words_to_json()`

### 产物清单（每条视频完成后必须有这4个文件）

| 文件 | 路径 | 说明 |
|------|------|------|
| `{名称}_逐字稿.srt` | `{项目}/{日期}/字幕/` | 逐字级 ASR 原始数据（人看/播放器加载），**唯一源头** |
| `{名称}_words.json` | `{项目}/{日期}/字幕/` | 同上，程序读取用 |
| `{名称}_口播字幕.srt` | `{项目}/{日期}/字幕/` | **由逐字稿派生**：LLM 语义断句 + 逐字稿词时间戳锚定（≤13字/行，见 wf_verification Step 5b） |
| `{序号}_{名称}.md`（审核文档） | `{项目}/{日期}/审核文档/` | DIFF报告 + 逐字稿文本版 + 触发句↔警示语对应表 |

按需产出（仅硬字幕烧录需求时）：

| 文件 | 路径 | 说明 |
|------|------|------|
| `{名称}_原文字幕.srt` | `{项目}/{日期}/字幕/` | 烧录用（客户原稿文字 + 逐字稿时间轴对齐，见 subtitle_burnin.md） |
| `{名称}_对齐报告.json` | `{项目}/{日期}/字幕/` | 烧录对齐率 + 错配明细 |

## 第11章：常见问题
- **ASR一段话分两段**：正常，DIFF全文逐字不受影响，字幕以标点恢复为准
- **语气词（啊/嗯/那个）**：1-2字标delete先AUDIO_REPAIR；句末<0.3s疑呼吸声误识别→跳过
- **时间戳偏移**：<0.3s接受；0.3-0.5s整体平移；>0.5s不可靠标异常建议重生
- **产品名错**：缺"·"占位符已处理；多/少字正常报diff；完全错（好质保）同音纠错后仍报replace
- **数字读法**：占位符替换后值相同（15.08元=十五点零八元）match；值不同（15.8）报replace

## 第12章：红线
1. DIFF基准必须是 atomic_scripts.json 期望文本，**禁止用原始脚本**（含括号警示语/删除级词等不该念内容）
2. 同音纠错后文本不能用于DIFF（抹平发音错），DIFF必须用纠错前ASR原文
3. 占位符必须DIFF前替换、DIFF后还原；映射存_session
4. ASR原始与纠错后文本同时保存（审核文档展示两版）
5. 字幕用标点恢复文本，不用ASR自带标点；**禁止本地机械切字**
6. 单字差异声调判定不能跳过（声调错是真错）
7. 警示语SRT时间轴必须与触发句对齐不错位
8. 逐字稿必须是 ASR words 直出的 SRT+JSON 两份（`{名称}_逐字稿.srt` + `{名称}_words.json`），存 `{项目}/{日期}/字幕/`（**禁止另建 `逐字稿/` 目录、禁止 TAB 分隔 TXT 格式、禁止经 LLM 断句/纠错后再写逐字稿**）
9. 口播字幕SRT 只能**从逐字稿派生**（逐字稿→LLM断句→口播字幕），禁止与逐字稿各自独立跑一次 ASR 生成两份
