# 视频生成双线路径定义

> 本文件定义保险视频生产的两条核心生成路径。PLANNING 阶段完成后，根据角色一致性需求和视频时长结构判定走哪条路径。

---

## 路径一：文生视频 + 视频延长

### 适用场景
- 单角色或无跨镜身份诉求的口播/旁白类视频
- 脚本预估时长超过单次生成上限（30s），需要分段延续
- 用户未提供角色照片，且无多角色跨镜一致性需求

### 执行链路

```
Step 1: text_to_video（文生视频）
  ├─ 输入：Prompt（含台词/动作/场景描述/通用约束）
  ├─ TaskType：普通生成（不填）
  ├─ ImageList：无（或仅传场景参考图/首帧图）
  ├─ VideoList：无
  └─ 产物：shot_01.mp4（第一段视频，作为后续延长的源片）

Step 2: reference2video / extend（视频延长）
  ├─ 输入：shot_01.mp4 的末帧截图 + 次段 Prompt
  ├─ TaskType：extend
  ├─ VideoList：[shot_01.mp4]（以第一段视频为源片，延续动作与内容）
  ├─ ImageList：无（或仅传场景参考图）
  └─ 产物：shot_02.mp4（延续片段）

Step N: 多段extend（>60s 时）
  ├─ 按上述模式逐段延续，每段以上一段末帧为参考
  ├─ 各段 task_id 记为数组，最终统一 ffmpeg 拼接
  └─ 产物：shot_NN.mp4 序列 → 拼接为 output.mp4
```

### 关键规则
- **首段为源片**：第一段 text_to_video 的产物是整条视频的内容基准，后续所有段从它延续
- **末帧承接**：每段生成完成后截取末帧（`shot_NN_endframe.png`），作为下一段 reference2video 的输入；末帧在拼接完成前不可删除
- **台词边界保护**：分段点必须落在句读边界（。！？）之后，禁止切半句；30s 落点在句中则前推到最近句末
- **时长判定**：
  - 修正后总时长 ≤ 30s → 单段 text_to_video，不走 extend
  - 30s < 总时长 ≤ 60s → 首段 text_to_video + 次段 extend
  - 总时长 > 60s → 多段 extend，按30s分段
- **Prompt 构造**：台词逐字取自 `atomic_scripts.json`，遵循四层分层结构（素材绑定→概述→画面阶段→通用约束）
- **无角色锁定**：不生成四视图，不传角色参考图；角色形象由 Prompt 文字描述控制，跨段一致性靠末帧承接

### 与路径二的核心区别
| 维度 | 路径一（文生+延长） | 路径二（角色锁定+生成） |
|------|---------------------|------------------------|
| 一致性保障 | 末帧承接（动作/场景延续） | ImageList 角色参考图（身份锁定） |
| 生成模式 | text_to_video → extend | 普通生成（每镜独立调用） |
| 参考素材 | VideoList（前段视频） | ImageList（角色图+场景图） |
| 适用场景 | 单角色口播/旁白/无跨镜身份诉求 | 多角色/跨镜需识别为同一人 |
| 前置准备 | 无（直接进生成） | 需先走角色资产产线出四视图 |

## 路径二：角色锁定 + 视频生成

### 适用场景
- 脚本包含2个及以上角色，需要跨镜头识别为同一人
- 用户对角色形象有明确要求（指定外貌/服装/年龄等）
- 多镜头叙事，角色在不同场景中出现

### 执行链路

```
前置：角色资产产线（character_asset_pipeline.md）
  ├─ S1: 单张大头（验脸闸门，像才往下走）
  ├─ S2: 面部四视图（3:4，锁脸型/五官/发型）
  └─ S3: 全身四视图（9:16，锁身高/服装/体态）
  → 产物：character_{role}_sheet.png

前置：场景参考图（image_generation.md §五）
  → 产物：scene_{name}.png

前置：风格锚（image_generation.md §四，按需）
  → 产物：style_anchor.png

Step 1~N: 逐镜头视频生成
  ├─ 输入：各镜头 Prompt（含角色引用/台词/动作/场景描述）
  ├─ TaskType：普通生成（不填）
  ├─ ImageList：[character_A_sheet.png, character_B_sheet.png, scene_xxx.png]
  │   └─ 每个镜头都必须重复传入该镜所有出场角色的参考图（工具无状态）
  ├─ VideoList：无
  └─ 产物：shot_NN.mp4（各镜头独立生成）

> **路径二时长判定（与路径一对称，优先于上方逐镜头拆解）**：
> - 修正后总时长 **≤ 30s** → **一次 reference2video 调用**，ImageList 传全部参考图（角色+场景），分镜中的多个镜头**合并为段内切镜点**（Prompt 里按时间轴分段描述不同景别/机位/说话者，而非拆成独立调用）。duration 按修正后总时长取档（精细预算含停顿/角色切换/段末缓冲，计算方法见 `segmentation_packaging.md` Step 6；取 5s 步进：10/15/20/25/30）。多角色正反打在 Prompt 时间轴内用"第X-Y秒：近景A说话→第Y-Z秒：近景B回答"描述，不拆独立调用。
> - 修正后总时长 **> 30s** → 按上方 Step 1~N 逐段拆（首段 reference2video + 后续段 extend），每段内仍可包含多个切镜点（上限9个对白镜头，见 segmentation_packaging）。

合并：render_video
  ├─ video_paths: [shot_01.mp4, shot_02.mp4, ...]
  └─ 产物：output.mp4
```

### 关键规则
- **逐镜头传参**：每个镜头的 ImageList 都必须传入该镜所有出场角色的参考图，工具无状态不记忆历史
- **角色引用语法**：Prompt 中用 `参考@图片N的形象作为{角色名}` 显式绑定，禁止模糊描述如"两个人在说话"
- **四视图格式**：正面头肩特写 + 正面/侧面/背面三个完整全身视图横排，纯白背景，均匀平光
- **视觉锁定由参考图承担**：已传参考图的角色 Prompt 只写"参考@图片N的形象作为{角色名}"，禁止复写图上可见的静态外观
- **单图不超4人**：每张参考图中人物不超过4个，超过时分批
- **音色锚定**：成片且2个及以上角色时触发 AUDIO_ANCHOR，为每个角色生成 voice_{role}.mp3
- **多角色布局**：2-3人镜头用角色解耦引用法（策略A），复杂布局/多人用空间占位锚定法（策略B），详见 `multi_character_layout_spec.md`

### 与路径一的核心区别
- 路径二每个镜头是**独立生成**，不依赖前一段视频的末帧
- 角色一致性完全由 ImageList 参考图驱动，不靠内容延续
- 前置准备更重（需出角色图+场景图），但跨镜一致性更稳定

## 路径判定规则

```
判定入口：PLANNING 阶段完成后

1. 用户已上传角色照片？
   └─ 是 → 直接用作参考图，走路径二（跳过四视图生成）

2. 脚本包含2个及以上有台词角色？
   └─ 是 → 走路径二（需角色锁定）

3. 需要跨镜头识别为同一人？
   └─ 是 → 走路径二（需角色锁定）

4. 以上都不满足（单角色/无跨镜诉求）？
   └─ 走路径一（文生视频，超时则延长）

5. 路径一中单段时长 ≤ 30s？
   └─ 是 → 纯 text_to_video，不走 extend
   └─ 否 → text_to_video + extend 延长
```

### 混合场景
- **多角色 + 长视频**：走路径二生成各镜头，但单个镜头内部超30s时，该镜头内部可用 extend 模式延续（以该镜头首段为源片）
- **单角色 + 多场景**：走路径一，但每个场景切换处可生成场景参考图辅助（ImageList 传场景图，不传角色图）
