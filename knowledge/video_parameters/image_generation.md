# 参考图生成（Seedream 生图规范）

> 补齐"参考图从哪来"这一环。character_lock_protocol 规定**用什么参考图、怎么逐镜传**，本文规定**怎么把图生成出来**。
> 执行接口：BlueAI 网关 `POST /api/doubao/text2image_v*` / `image2image_v*`（Seedream，豆包/火山方舟）。
> Prompt 工程的完整范式（四视图/骨相/物理白描/风格锚）参考小云雀项目的 ref-image-design 手册（外部资源，非本规范库文件），本文沉淀其要点并接执行参数。

## 一、什么时候需要生图（按需，不是每镜都生）

默认 **reuse / skip**，只在图片能实质稳定"脆弱身份"时才生成：
- **角色四视图**：主角/重要配角、需跨多镜识别为同一人、且用户**没有提供照片** → 生成 `character_xxx_sheet.png`
- **场景空镜**：主场景反复出现、需要跨机位一致 → 生成场景底板
- **首帧/关键帧**：image2video 图生视频需要一张定构图的首帧
- **风格锚 style_anchor.png**：多角色/多段、需要统一画风时，全链路第一张生成

不生的情况：
- **用户已上传该角色清晰照片** → 直接用作参考图，**跳过四视图生成**（风格差异不是弃用用户素材的理由）
- 单段短视频、无跨镜身份诉求、群像/类型角色（用群像图即可）
- 次要一次性道具/环境，交给视频模型即时生成

人物素材图默认比例 **3:4**（竖屏角色）；场景/首帧跟随视频最终比例（竖屏 9:16）。小云雀四视图横排设定稿用 16:9。

## 二、模型选型（Seedream）

| model_id | 能力 | 适用 |
|----------|------|------|
| `doubao-seedream-5-0-260128`（5.0-lite） | **组图**（sequential_image_generation=auto，最多15张）、2K/3K/4K、联网搜图 | 四视图、多角色批量、组图一致性 |
| `doubao-seedream-5-0-pro-260628`（5.0-pro） | 单图质量高、**图层分解**、最高仅2K、不支持组图 | 高精度单张首帧/海报、图层拆分 |
| Seedream 4.0/4.5（text2image_v4_x） | 兜底 | 5.0不可用时降级 |

- 端点：`POST /doubao/text2image_v5_0`（文生图）、`POST /doubao/image2image_v5_0`（图生图：换装/换景/基于风格锚派生）
- `size`：档位 `2K`/`3K`/`4K`（pro仅1K/2K）或像素宽高；竖屏角色用 3:4 比例像素，场景 9:16
- `watermark=false`（参考素材不打"AI生成"角标）、`output_format=jpeg`（透明图层用png）
- 组图：`sequential_image_generation="auto"` + 必传 `max_images`
- 异步轮询同视频：提交拿 task_id，`/doubao/task_status` 轮询到成功取图 URL，下载存项目 `assets/` 或 `upload/`

## 三、角色四视图（身份锁定核心）

一张图横排：**正面头肩特写 + 正面/侧面/背面三个完整全身视图**，一次生成保证同一人：
- 三全身视图**从头顶完整到脚尖，严禁裁切下半身**；特写只画头肩
- 纯白背景、均匀平光无明显阴影、自然站立平视、中性表情
- 服装/发型/五官四视图完全一致
- Prompt 末尾必写"禁止生成任何背景、文本、标注、字幕"
- **反同质化**：禁写"锥子脸/网红脸"，用骨相组合差异化（面部折叠度+颅骨比例+下颌角+皮肉包裹）
- 出厂默认态：健康肤色/整洁发型/中性表情，**剧情状态**（黑眼圈/伤痕/凌乱/哭）不进设定图，留给视频prompt

### 角色辨识度指南(让角色有"特色"而不是"AI标准脸")

> 好的角色参考图,观众一眼能读出**年龄/身份/性格**,而不是"又一个30岁AI美女"。关键不是骨相术语,是**具象的生活化细节**。

**辨识度四维模型**(角色白描时逐维检查,缺维=缺记忆点):

| 维度 | 说明 | ❌ 没辨识度 | ✅ 有辨识度 |
|------|------|-----------|-----------|
| **年龄真实感** | 年龄写具体数字+**年龄该有的痕迹** | "中年男性" | "55岁,额头三道横纹,鬓角花白,眼角细纹明显" |
| **不完美特征** | 一个小缺陷比十个优点更有记忆点 | "五官端正" | "微秃——头顶稀疏能看到头皮,两侧头发梳向中间遮盖" |
| **身份道具** | 一件物品就能定位社会角色 | "戴眼镜" | "金边细框老花镜,鼻梁上滑到中段,总是从镜框上方看人" |
| **服装阶层感** | 衣服暗示收入/职业/生活状态 | "穿衬衫" | "洗到发黄的白色短袖衬衫,领口微卷,胸口口袋插着两支笔" |

**写法对比(保险视频常见角色)**:

```
❌ 没特色的写法(会出AI标准脸):
50岁中国男性,圆脸,短发,戴眼镜,穿白色衬衫。

✅ 有特色的写法(出来有辨识度):
55岁中国男性,方脸偏宽颧骨突出,前额发际线后退明显——头顶头发稀疏能隐约看到头皮,
两鬓花白剃短,眉毛浓密微连但修过。金边细框椭圆老花镜架在鼻梁中段。
下巴圆钝有双下巴,脖子偏短。洗到微微发黄的白色短袖衬衫,领口第一颗扣子没扣,
深灰色西裤微皱,棕色皮带旧了发白,黑色布鞋。
整体气质:退休干部/中学老师——不讲究但干净,有点固执的体面。
```

```
❌ 没特色的写法:
25岁中国女性,长发,大眼睛,穿红色T恤。

✅ 有特色的写法:
24岁中国女性,偏圆的鹅蛋脸——苹果肌饱满,下巴短圆不尖。
眼睛偏大且圆(不是杏仁眼),双眼皮宽但不深,瞳仁棕色偏浅像茶色。
金棕色过肩长发自然微卷,刘海中分八字帘遮住太阳穴。眉毛细淡、弯弧度大。
鼻子小巧微翘,嘴唇薄上厚下、唇色自然粉。耳朵小、贴头。
红色圆领短袖T恤(棉质微宽松),黑色细肩带内搭从领口露一截。
整体气质:大学刚毕业的邻家女孩——不是明星脸,是你会在奶茶店遇到的那种。
```

**关键原则**:
1. **"整体气质"用一句生活化类比收尾**(退休干部/邻家女孩/菜市场大妈)——这比骨相术语更能帮模型理解你要什么
2. **年龄必须写具体数字+对应痕迹**(不是"中年",是"55岁+额纹+花白")——AI 默认把所有角色往 25-30 岁靠
3. **至少一个"不完美"**(微秃/双下巴/鼻子偏大/法令纹深)——完美的脸没有记忆点
4. **服装写到旧新程度**(洗到发黄/微皱/旧了发白)——新衣服没有生活感
5. **一个身份道具**(老花镜/围裙/工牌/菜篮子)——一件物品定位整个人

### 画面叙事道具技巧(视频 Prompt 用,不止设定图)

> 以下技巧用于**视频生成的 Prompt**,让画面自己讲故事,不靠台词解释。

**原则:配饰/道具/动作比脸重要**——观众记住角色靠的不是五官,是那个小熊发夹、那副黑框眼镜、那个低头看手机的姿态。

#### ① 一件配饰定身份(角色设定图 + 视频 Prompt 都用)

| 配饰 | 暗示的身份 | Prompt 怎么写 |
|------|-----------|-------------|
| 小熊/卡通发夹 | 学生气/可爱系/年轻 | "金棕色丸子头,头顶别一个白色小熊毛绒发夹" |
| 黑框方形眼镜+耳钉 | 文艺/潮流/有审美 | "黑色粗框方形眼镜,左耳一颗银色十字耳钉" |
| 珍珠耳坠+工牌挂绳 | 有品味的职场人 | "耳垂一对珍珠串耳坠,脖子上挂黑色工牌挂绳" |
| 老花镜+胸口插笔 | 退休干部/老教师 | "金边细框老花镜滑到鼻梁中段,衬衫胸口袋插两支笔" |
| 围裙+沾面粉的手 | 家庭主妇/会做饭的人 | "浅蓝色棉布围裙,双手指尖沾着面粉" |

#### ② 道具当悬念(不给内容,只给动作)

**核心**:拍"人在看/用某个东西"的**姿态**,故意不给东西的具体内容——观众自己脑补。

| 场景 | ❌ 写内容(信息过载) | ✅ 只写动作(制造悬念) |
|------|-------------------|---------------------|
| 看手机 | "手机屏幕显示支付宝App好医保页面" | "低头看手机,手机屏幕的光映在脸上,表情从疑惑变成放松" |
| 看文件 | "手里拿着一份写着'诊断报告'的A4纸" | "手里攥着一张纸,眼睛扫过后眉头微皱" |
| 看电脑 | "电脑屏幕显示保险购买页面" | "坐在电脑前,一手撑下巴盯着屏幕,另一手犹豫地悬在键盘上" |

> **为什么不给内容**:①模型生成的文字/UI 经常崩(乱码/错位);②画面留白让观众代入自己的理解,比塞信息更有效;③保险合规上,屏幕内容可能涉及"虚假页面展示",不如不给

#### ③ 服装组合叙事(不是单件,是搭配关系讲故事)

| 搭配 | 讲了什么故事 | Prompt 怎么写 |
|------|------------|-------------|
| 斜肩上衣+珍珠耳坠+工牌 | "有品味但在上班" | "黑色斜肩针织衫露出一侧锁骨,耳垂珍珠耳坠,脖子上黑色工牌挂绳" |
| 宽松卫衣+狗狗图案+半扎发 | "休闲在家/下班后的放松状态" | "藏蓝色宽松卫衣胸前印白色狗狗图案,金棕长发用酒红色发绳半扎高" |
| 红色领子制服+背带 | "餐厅/店铺员工" | "淡黄色短袖衬衫配红色大翻领,胸前交叉红色背带,像快餐店制服" |

#### ④ 同一角色不同景别讲不同信息

同一个镜头里不要塞太多信息——**中景交代环境+人物关系,近景聚焦表情+动作细节**。

| 景别 | 讲什么 | 保险场景示例 |
|------|-------|-----------|
| 中景(腰以上+环境) | 人在哪、跟谁在一起、在做什么 | "办公室工位前,女孩坐在电脑前低头看手机" |
| 近景(胸以上) | 表情、情绪、配饰细节 | "女孩低头看手机,眉头微蹙,手机的光映在脸上" |
| 特写(脸/手/物) | 一个关键细节 | "手指滑动手机屏幕,指甲上有浅粉色甲油" |

### 写实四视图 Prompt 骨架
```
{由头到脚物理白描：空间姿态→骨相→妆造→发型→手饰→上衣→下装鞋履}的四视图角色设定稿，
同一角色的正面头肩特写、正面、侧面、背面三个完整全身视图横向排列，
特写只显示头肩，三个全身视图从头顶完整到脚尖，双足平踏、平视镜头、自然站立，
四视图五官服装发型完全一致。纯白色背景，均匀平光、无明显阴影。
正面侧面背面全身严禁裁切下半身，特写禁止画成全身，禁止任何背景/文字/标注/字幕。
比例:16:9
```

> Prompt 必须**物理白描**（可见材质/颜色/结构），禁技术黑话（8k/photorealistic/电影感光影/次表面散射）和抽象气质词（高级感/唯美）。抽象词先降维：`[部件]+[材质]+[固有色]`。

## 四、风格锚（多角色统一画风）

- 全链路**第一张**生成 `style_anchor.png`，只定义"世界长什么样"
- 写实模式：**纯场景元素**（材质/光影/配色），不放人物面部（会泄漏污染下游角色图）
- 角色/场景图 image2image 派生时 ImageList 带 @style_anchor，prompt 必写引用语：
  - 场景："仅参考@图片N的画面风格、色彩与材质质感，不参考构图与人物"
  - 写实人物：同上（锚点无人脸）；风格化人物须加"严禁参考五官体型构图"

## 五、场景空镜

纯空镜底板，**无人物/无人影/无剪影**（否则视频误当角色参考）；默认约45°高角度俯拍暴露空间布局；物体稳定常态（不画进行中的瞬时动作）；交互小道具留白不画；比例跟视频。

## 六、生成后校验（关键素材需用户确认）

- 角色图：四视图是否同一人、三全身有无裁切、面部有无崩坏/脏污
- 场景图：是否混入人物/人影
- 多角色并排核对五官是否雷同（雷同→强化骨相差异重生成该张）
- 关键参考素材（主角/主场景/首帧）出图后简要展示给用户确认，通过才进视频生成；次要素材可径直用
- 审核拦截（security_filter / copyright code=12002）：**不重试不改词**，告知用户由其决定（小云雀红线，同版权处理）

## 七、产物落位与下游引用

```
{项目}/
├── assets/ 或 upload/
│   ├── style_anchor.png
│   ├── character_{role}_sheet.png   # 四视图
│   ├── character_{role}_group.png   # 群像
│   ├── scene_{name}.png             # 场景空镜
│   └── keyframe_{NN}.png            # 首帧/关键帧
```
- 生成后登记到 `_session/` 的素材绑定关系表（角色↔参考图文件）
- 视频生成时**每个镜头/每段的 ImageList 都重复传入**该镜出场角色参考图（工具无状态，见 character_lock_protocol）
- 首帧图用于 image2video / firstlast2video；多参考用 reference2video
- 给只认厂商资产ID的渠道（PixVerse/Gaga/volcengine_visual/byteplus），先走 `asset_management.md` 转 `vendor_asset_id`
