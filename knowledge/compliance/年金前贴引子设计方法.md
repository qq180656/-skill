# 年金前贴引子设计方法（NEW SOLO）

> 前贴只引产品名、零利益点。难点：合规封死了"利益/钱"类引子，
> 破局关键是走「聊生活小事 → 自然带出产品名」的**好奇路径**，而非从利益切入。

## 一、核心公式

```
生活场景句 → 过渡句 → 产品名 → 收尾句
```

- **生活场景句**：消费/生活场景的日常对话（逛街、咖啡、追剧、健身、通勤…）
- **过渡句**：用好奇/推荐/参照等引子自然转折（不说利益、不说存钱理财）
- **产品名**："长钱保·五年领年金"（念准，不念"长钱宝"）
- **收尾句**："回头发你看看/改天细说/回家聊聊"——**到"回头聊"为止，不展开功能**

## 二、六大可用引子方向

| 类型 | 引子逻辑 | 示例 |
|------|---------|------|
| 数字触发型 | "五年"作为**生活数字**出现（非利益表述） | "五年没见的朋友""坚持五年健身""五年计划" |
| 手机刷到型 | 刷手机看到/刷到，不出现屏幕 | "昨天刷到一个挺有意思的""老给我推一个东西" |
| 朋友推荐型 | 朋友/同事/闺蜜提到 | "我闺蜜/同事提过一个""有人跟我推荐过" |
| 名字好奇型 | 觉得名字特别、好奇 | "名字挺有意思的，叫长钱保" |
| 同龄参照型 | 同龄人/同学都在弄 | "我同学他们都了解过了""同龄的朋友提过" |
| 礼物/仪式感型 | 当礼物/给自己一个安排 | "想给自己安排一个""当送给未来的自己" |

## 三、三红线（必须遵守）

1. **"五年"是生活数字，不是利益表述**：可说"五年计划/五年没见"，不可说"交五年/五年后领多少钱/第五年开始领"
2. **用"了解/留意到"，不用"推荐/买/投"**："我了解了一个长钱保"，不催单、不说"你应该买"
3. **引子到"回头聊"为止，不展开功能**：前贴不说产品做什么、不提利益、不提钱、不提领取，只留好奇心钩子

## 四、八条合规红线（前贴台词）

前贴台词必须全部规避：
1. 金融混同：存钱/攒钱/小金库/定投/基金/利息/理财/本金/存款/储备类禁词（"储备"也慎用，统一走好奇路径）
2. 利益点：交五年往后领/一直领/收益/回本/翻倍/复利
3. 不当类比：银行/理财/通胀/利率/股票/黄金对比
4. 经济焦虑：裁员/被优化/失业/行业差
5. 群体贴签：月光族/花光/乱花/存不下/大手大脚
6. 万能化：有它就够/真正的安全感
7. 产品错字：长钱宝/常钱保
8. 医护药名：医生/护士/药品/住院（年金前贴不涉及）

## 五、过渡句模板库（安全）

- "我前阵子留意到一个东西"
- "最近老刷到，名字还挺特别的"
- "我同事/闺蜜他们都在聊这个"
- "说来你可能不信，有个叫长钱保·五年领年金的"
- "我最近了解到一个，回头跟你细说"
- "我同学都了解过了，就叫长钱保·五年领年金"
- "想给自己安排个东西，长钱保·五年领年金"

## 六、收尾句模板库（安全）

- "回家细聊 / 回头我跟你说说 / 改天喝咖啡讲 / 发你看看 / 回去我找找资料 / 坐下慢慢说"
