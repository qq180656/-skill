# 脚本撰写 - 通用规则

## 适用范围
所有项目（好医保·中老年/好医保·门诊险/长钱保等），在脚本撰写阶段必须遵守。

## 脚本格式
- 每条用 `===` 分隔
- 括号内容为 disclaimer 警示语（TTS 不读，后续做字幕下方提示）
- 标题行格式：`序号-场景-类型-描述`

## 脚本结构（每条）

```
序号-场景-类型-描述
口播正文（已TTS优化）+（警示语1）（警示语2）...
===
序号-场景-类型-描述
口播正文（已TTS优化）+（警示语1）（警示语2）...
===
```

## 口播文字断句规则（TTS友好）

### 核心原则：每 5-8 个中文字加逗号断开

```
❌ 像我妈这种有高血压糖尿病结节这些的符合条件可以投保
✅ 像我妈这种，有高血压，糖尿病，结节这些的， 符合条件 可以投保
```

### 不可拆分的元素

| 类型 | 说明 | 示例 |
|------|------|------|
| 产品名 | 已拆分加逗号，拆分后各段不再二次拆 | 好医保，中老年长期医疗 |
| 数字+单位 | 保持完整在一个短句内 | 15.08元起、5.21%、100%、400万 |
| 核心术语 | 不可拆分 | 免赔额、报销、投保、续保 |

### 产品名拆分（用逗号断开）

| 原产品名 | TTS友好写法 |
|----------|------------|
| 好医保·中老年长期医疗 | 好医保，中老年长期医疗 |
| 好医保·门诊险 | 好医保，门诊险 |
| 长钱保·五年领年金 | 长钱保，五年领年金 |

### 数字保护（不拆）

- `15.08元起` → 保持完整在一个短句内
- `5.21%` → 不拆
- `100%` → 不拆
- `400万` → 不拆

## 合规输入：三层叠加规则

每个项目脚本撰写前必须读取三层合规规则，按层级叠加：

| 层级 | 来源 | 适用范围 | 叠加逻辑 |
|------|------|---------|---------|
| 第一层 | `通用合规/保险投放素材通用规则（全险种适用）.md` | 所有险种 | 全局生效，不可覆盖 |
| 第二层 | `险种专项/{险种}-合规要求.md` | 该险种全部产品 | 在第一层基础上叠加 |
| 第三层 | `产品专属/{产品名}-投放注意事项.md` | 仅该产品 | 在前两层基础上叠加，最高优先级 |

### 合规读取流程
1. 读取第一层通用规则 → 建立"全局禁用词清单"
2. 读取第二层险种规则 → 补充"险种专属禁用词/表述规范"
3. 读取第三层产品规则 → 补充"产品专属触发句→警示语映射表"
4. 合并三层规则 → 生成当前项目的"完整合规检查清单"

### 关键合规红线
- 保险期间1年的产品，不得说成长期险（不说"保xx年/保至xx岁"）
- "0免赔"必须写全"0免赔额"
- "100%报销"必须写"100%比例报销"
- 保证续保须区分一般医疗与特定疾病责任，不可笼统说"终身续保"
- 不得宣传"带病可投"，须写"符合条件可投保"
- 不使用医生/护士形象推荐保险产品
- 不以新闻主持人形象做产品宣传
- 禁止焦虑卖惨/恐吓营销

## 警示语处理规则

### 正文已含"责任内"时的去重
- 正文口播说了"责任内" → 警示语中不再重复加"（责任内）"
- 正文口播没说"责任内" → 警示语需要加"（责任内）"前缀

### 涉及0免赔额/1元/100%的强制警示语
凡是口播正文涉及以下关键词，警示语必须包含：
> （一般医疗2万免赔额,重度恶性肿瘤治疗/先进医药责任/7大新发结节等手术治疗/指定术后复筛查责任0免赔额,责任内最高100%比例报销）（符合条款约定可赔付）

触发关键词：0免赔额、一元起赔、一元也能申请理赔、100%比例报销、100%比例赔付

### 必加提示（视频末尾字幕）
以下提示必须在视频中体现（压底或末尾字幕）：
1. 等待期内发生保险事故，可能无法赔付，具体以条款为准
2. 投保时必须如实进行健康告知
3. 带病投保不代表所有相关疾病均可赔付
4. 部分结节可能存在特定疾病责任除外
5. 新发部位保障需满足疾病定义、治疗方式和医院范围等要求
6. 复筛查责任仅限符合条件的指定手术后复筛查，不等同于普通体检报销
7. 最低保费不代表所有年龄和人群均按该价格投保
