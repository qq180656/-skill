# TTS降级与回退策略

本文档定义TTS处理失败或质量不达标时的降级方案。
工作流在 REPAIRING 阶段或异常处理时按此文件执行降级。

## 1. TTS克隆失败降级链

| 优先级 | 策略 | 说明 |
|--------|------|------|
| 1(首选) | TTS克隆重读 | 使用参考音克隆,音色一致 |
| 2 | 标准TTS重读 | 放弃克隆,使用标准音色,接受音色差异 |
| 3 | 整段视频重新生成 | 音频修复无效,换参数重新生成该镜头 |
| 4 | 修改脚本绕过（**需用户确认**） | 生成同义替换候选 → 用户确认（不自动改，避免违反 pronunciation_rules"不换词"铁律）→ 替换后**重跑 COMPLIANCE_CHECK + 警示语匹配**（防新词命中禁用词/触发句脱落）→ 重新生成 |
| 5(FATAL) | 通知用户 | 所有策略均失败,暂停等待用户决策 |

## 2. 发音错误降级决策树

检测到发音差异时:
1. 差异类型 = REPLACE -> 尝试TTS克隆修复(策略1)
2. 差异类型 = INSERT/DELETE -> 无法局部修复,重新生成该镜头(策略3)
3. 同一镜头修复失败3次 -> 换脚本表达(策略4)
4. 换脚本后仍失败 -> 通知用户(策略5)

## 3. 语速不达标降级

> 基准语速从 config_matrix.md 取：好医保系列(中老年/门诊险/少儿)=7字/秒，长钱保=6字/秒。正常范围=基准语速±0.5字/秒。

| 问题 | 策略 |
|------|------|
| 语速 > 基准语速+0.5字/秒 | 增加断句密度或插入停顿 |
| 语速 < 基准语速-0.5字/秒 | 检查是否过度断句,合并短句 |
| 语速波动大 | 重新切分原子句,平衡各句字数 |

## 4. 音频接口与音色锚定异常处理

区分两种异常场景，处理策略不同：

### 4.1 BMC音频接口调用失败（500错误/超时/网络错误）
- 自动重试，最多3次
- 重试间隔：第1次立即，第2次等10s，第3次等30s
- 3次均失败：降级为标准TTS(策略2)，不阻断视频生成，记录警告

### 4.2 音色锚定效果不达标（克隆音色不像/有杂音/参考音质量差）
- 不重试接口（接口没坏）
- 记录警告，不阻断视频生成
- 后期修复时回退到从原视频提取参考音（wf_repair.md Step 1）
- 对应异常码：E012（音色锚定失败）
