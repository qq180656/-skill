# TTS 发音规避表

## 适用范围
所有项目（好医保·中老年/好医保·门诊险/长钱保等），在脚本撰写阶段必须遵守。

## 问题词分级总览

TTS发音问题词只有两种处理方式，不存在改词/换同音词：

| 分级 | 处理方式 | 适用词 | 说明 |
|------|---------|--------|------|
| **删除级** | 口播整词删除 + prompt显式禁止补词 | 息肉、超声 | generate_audio怎么都念不对，空格/逐字约束均无效，只能删除 |
| **空格级** | 保留原词 + 前后加空格 + prompt逐字约束 | 其他所有问题词 | 加空格切断TTS错误连读，发音错了就标记，不删词不改词 |

> 统一原则：**不换词、不删词（删除级除外）、不加逗号、不改同音词**。空格级词发音错了就标记到《音频发音问题清单》，由用户决定是否重生。

## 规避方法优先级

统一方案：**前后加空格**（空格级词）。所有空格级问题词一律用空格隔断，不换词、不删词、不加逗号。

| 方法 | 说明 | 示例 |
|------|------|------|
| **前后加空格**（空格级唯一方案） | 在问题词前后各加一个空格，切断TTS错误连读 | ` 意外 `、` 符合条件 `、` 免赔额 ` |
| **整词删除**（删除级唯一方案） | 口播正文整词删除，警示语括号里保留原文 | 息肉、超声 |

**验证流程**：
1. 加空格后跑视频
2. ASR提取逐字稿
3. ASR识别结果与原词一致 → 标记 ✅ 已验证
4. ASR识别仍有误 → **不改词、不删词、不换同音词**，直接标记到《音频发音问题清单》，由用户决定是否重生

## 口播 vs 警示语的差异化处理

| 位置 | 处理规则 | 说明 |
|------|---------|------|
| **口播正文** | 空格级：原词保留 + 问题词前后加空格；删除级：整词删除 | TTS会朗读这部分内容，**不删词（删除级除外）、不替换词**，发音错了就标记 |
| **警示语（括号内）** | 不需要加空格，保持合规原文 | TTS不读警示语，警示语只做字幕展示，必须与合规规则文档完全一致 |

示例：
```
口播正文： 符合条件 可以投保        ← 原词保留，"符合条件"前后加空格辅助念准
警示语：（符合条件可投保）          ← 保持原文，不改
```

```
口播正文：CT、胃肠镜等指定项目   ← 删除级词"超声"口播删除
警示语：（复筛查责任仅限...超声...）     ← 警示语保留"超声"原文
```

```
口播正文：新发结节、良性肿瘤       ← 删除级词"息肉"口播删除
警示语：（7大新发部位保障需...息肉...）   ← 警示语保留"息肉"原文
```

## generate_audio 专业词逐字念约束（视频生成 prompt 必加）

**处理原则分两类：**

### A. 口播直接删除词（删除级：实测generate_audio怎么都念不对，整词删除）
这两个词在口播正文里**直接删除**（不替换、不改音），警示语括号里保留原文：

| 删除词 | 念错（无解） | 口播处理 | 警示语 |
|--------|-------------|---------|--------|
| **息肉** | 皮肉/批肉/皮韧/点皮 | 口播整词删除（如"结节、息肉、良性肿瘤"→"结节、良性肿瘤"） | 保留"息肉"原文 |
| **超声** | 超伤/超空/抽生/空锐 | 口播整词删除（如"CT、超声、胃肠镜"→"CT、胃肠镜"） | 保留"超声"原文 |

> ⚠️ **关键：光删除不够，必须在prompt显式禁止generate_audio补词。**
> 实测即使脚本删除了息肉/超声，generate_audio 会"脑补"：看到"结节、良性肿瘤"自行插入"皮肉"，看到"CT、胃肠镜"自行插入"超伤"。
> 因此 prompt 的逐字约束里必须加：
> `【严格禁止】绝不允许念出"息肉"和"超声"两个词，台词中没有这两个字，不得自行添加；"结节、良性肿瘤"中间、"CT、胃肠镜"中间都不要加任何字。`

> 删除后句子仍通顺即可。这两个词是 generate_audio 的顽固念错词，空格/逐字约束均无效，只能删除+显式禁止。

### B. 其他问题词（空格级：保留原词 + 空格注入 + prompt逐字约束）
除息肉/超声外，其余问题词口播照念、不删，SCRIPT_ATOMIZE 在词前后加空格辅助断句：

1. **问题词前后加空格**：` 免赔额 ` ` 胃肠镜 ` ` 保证续保 ` ` 符合条件 ` 等
2. **prompt 末尾加逐字硬约束**：
   `旁白逐字朗读台词，专业术语咬字清晰：免赔额、胃肠镜、甲状腺、结节、保证续保、恶性肿瘤、符合条件，不得吞字、改读、自由发挥。`
3. **禁止自由演绎**：旁白/对白文本必须逐字要念，不写"大概意思是…"
4. **发音错了就标记**：ASR 检测，念错记入《音频发音问题清单》，是否重生生用户决定。

### 产品名完整念出（关键）

generate_audio 常会省略/简化长产品名，必须在 prompt 显式约束：
- 产品名**台词里出现几次就完整念几次**，不许省略、不许简化成"好医保""这个保险""长钱保"
- 全名一字不漏：
  - 医疗险：**好医保中老年长期医疗**（好-医-保-中-老-年-长-期-医-疗）
  - 年金险：**长钱保·五年领年金**（长钱保，不念成"长钱宝"）

### 两种视频形态

| 形态 | 内容 | 画面 | 声音 |
|------|------|------|------|
| **口播（营销号）** | 单人口播一整段（故事钩子→产品讲解→情绪落点） | 真人面对镜头讲述 + 生活场景 | 单人画外/出镜口播，全程连续 |
| **剧情（达人）** | 多人对话，带【人设卡】（角色·年龄·关系·场景） | 人物对手戏表演 | 角色台词，男女声区分 |

两种形态都适用：动态时长(字数/语速+动作停顿，好医保7字/秒、长钱保6字/秒，详见 segmentation_packaging)、extend多段拼接、全程不空窗、产品名完整、息肉超声删除。

## 新增规避词流程

当视频生成后ASR检测到新的发音错误时：

1. **记录问题**：记下原文词、ASR实际念成什么
2. **判定分级**：先尝试加空格（空格级），跑视频验证；加空格仍念错 → 升级为删除级
3. **验证通过**：重新生成视频，ASR确认发音正确
4. **更新本表**：在表格中新增一行，填写规避方案和分级，标记验证状态
5. **同步更新脚本**：将已验证的规避方案应用到后续所有脚本撰写中
6. **同步更新strip_disclaimers函数**：确保程序处理逻辑与表格一致

## 数字 / 符号读法规则（防"纯数字跳过"漏检）

TTS 对数字/小数/百分号/大额金额常念错，SCRIPT_ATOMIZE 阶段须标注正确读法，且 VERIFYING 的 DIFF **不得因"纯数字跳过"而豁免数字念错**（"纯数字跳过"仅指纯数字时间戳对齐噪声，不豁免读法错误）：

| 类型 | 示例 | 正确念法 | 常见念错 |
|------|------|---------|---------|
| 小数（价格） | 15.08元 | 十五点零八元 | 十五点儿零8 / 十五零八 |
| 百分比 | 5.21% | 百分之五点二一 | 五点二一 / 百分之五二一 |
| 大额金额 | 400万 | 四百万 | 四零零万 |
| 保额区间 | 100万/150万 | 一百万、一百五十万 | 一零零万 |
| 年份（括号内） | （2026版）/ 旗舰版2026 | **不念**（括号内容不念；"旗舰版2026"的"2026"读"二零二六"，非"两千零二十六"，若在产品名括号外须念） | 二零二六 漏读/错读 |

> 旗舰版2026（52975）的"2026"不在括号内，若口播出现须按"二零二六"念；其余产品（45750/43117/39894）无特殊数字读法，按上表通用规则。

## 英文缩写 / 外来词读法

| 词 | 正确念法 | 禁止念法 | 原子化处理 |
|----|---------|---------|-----------|
| **CAR-T**（抗癌针/细胞疗法） | **整体读"卡替"（kǎ tì），像一个词**，也可读英文整体发音 | ❌ 逐个字母 C、A、R、T 念 | atomize 里 `CAR-T→卡替`、`CART→卡替`；prompt显式约束"CAR-T读卡替，不逐字母" |
| ICU | 逐字母 I、C、U（三个字母） | ❌ 不要读成一个音节 | 前后加空格 |
| CT（CT检查） | 逐字母 C、T | ❌ 不读成单词 | 前后加空格 |

> 原则：缩写是"已经中文化的药名/疗法名"（如CAR-T卡替）按中文谐音整体读；纯机构/检查缩写（ICU/CT）才逐字母。判断不了时在prompt显式写明读音，不要让模型自行逐字母拼读。

## 方言处理规则

脚本可能指定角色说方言（川渝/东北/粤语等，SCRIPT_PARSE 会识别"方言"元信息）：
- **口播文本仍用规范普通话书写**（不写方言用字/谐音字），方言口音通过视频生成 prompt 的"音色/说话风格"描述实现（如"川渝口音的中年女性"），**不改动原子脚本文本**（保持 DIFF 基准干净）。
- **发音规避照常适用**：方言口音下专业术语（免赔额/保证续保等）同样可能念错，空格级/删除级规避规则不变。
- **DIFF 校验**：方言口音的 ASR 识别偏差更大、误报率高，需人工复核；但**不因方言放宽合规术语的准确性要求**。
- 若脚本无明确方言要求 → 默认标准普通话。
