# 创意设计工作流

## 适用场景
用户输入只有模糊意图或仅有产品Brief时在脚本撰写前先进行创意设计

## 依赖知识库
- `knowledge/templates/creative_design_template.md` — 创意文档模板
- `knowledge/templates/style_reference.md` — 风格速查表（选定风格关键词）
- `knowledge/templates/narrative_arc.md` — 故事弧线与节奏模板
- `knowledge/templates/opening_hooks_library.md` — 开场方式库（40+种开场方式完整说明）
- `knowledge/templates/broll_skills/` — 场景空镜 skill（开场/场景涉及地标·著名景点/医院/家庭日常/通用空镜时按需加载）
- `knowledge/templates/character_lock_protocol.md` — 角色锁定协议（多角色时）
- `knowledge/compliance/` — 三层合规规则（禁用词+产品约束）

## 执行步骤

### Step 1: 意图解析与上下文构建
- 识别意图层: 题材 目的 面向人群
- **意图分层提取规则**：
  - 题材 ← 从产品名映射（好医保·中老年 → 健康险/中老年医疗险；长钱保·五年领年金 → 年金险/储蓄型）
  - 目的 ← 从类型词（前贴 → 引流认知；成片 → 转化购买）
  - 面向人群 ← 产品名含受众词直接取（"中老年" → 45-65岁本人及子女）；不含受众词 → 标"待确认"，随 Step 3 一并询问
- 检索知识库: 从 knowledge/compliance/ 检索相关产品合规要求（三层全读）
- 建立约束: 确定风格限制 禁用词 必加警示语
- 参考 `narrative_arc.md` 确定叙事结构（起承转合/钩子类型）
- **叙事结构时长匹配**：
  - 15-20s 前贴 → 钩子型：3s 引入 + 8s 铺垫 + 4s 产品名 + 2s 收尾
  - 30s 成片 → 起承型：5s 痛点 + 12s 利益点 + 8s 信任 + 5s CTA
  - 60s 成片 → 起承转合型：8s 建立 + 20s 问题方案 + 20s 利益 + 12s CTA收尾
  - 弹性时长 → 先按 字数 ÷ 语速（好医保系列 7字/秒、长钱保 6字/秒）得时长，再选最接近的时长弧线
- **开场方式选型指引**（参考 `opening_hooks_library.md` 完整库，含每种方式的画面描述+写法要点+Prompt示例+避坑提示）：
  > 以下为**推荐方向，非强制**。库中方式可自由组合、变体和创新，也可自行设计库中未列出的开场方式。
  - 按产品类型推荐（常见匹配，非唯一选择）：
    - 医疗险/重疾险 → 医院场景口播 / 缴费窗口冲击 / 体检报告打开 / 急诊抢救场景
    - 意外险 → 意外事故直入 / 救护车远景驶入 / 紧急拨打电话 / 街头随机采访
    - 惠民保/社保 → 社保局口播 / 画外音+空镜 / 场景化口播 / 手持道具
    - 年金险/储蓄险 → 银行场景口播 / 手持保单合同 / 延时定场 / 仪式降临
    - 少儿险/家庭险 → 家庭场景口播 / 画外音+空镜 / 多人接力采访
  - 按时长推荐：
    - 前贴15-20s → 直面镜头Hook / 面部大特写直入 / 手持道具口播 / 手机提示音触发 / 问答互动
    - 成片30s → 场景化口播 / 采访类 / 物件特写拉开 / 问题场景直入 / 缴费窗口冲击
    - 成片60s → 剧情叙事类 / 事件事故直入 / 延时定场 / 画外音+空镜 / 建筑空镜立人设
  - 按风格推荐：
    - 真人实拍 → 场景化口播全类 / 采访全类 / 事件事故全类 / 手持道具全类 / 大特写全类
    - 3D动画 → 剧情叙事全类 / 产品营销全类 / 大特写全类 / 画外音+空镜 / 延时定场
  - **通用约束**：所有开场方式涉及手机时**禁止展示手机屏幕内容**（AI生成文字乱码+与产品不一致），手机仅作为手持道具或声音触发；涉及医院/医护/药品时遵守医疗题材两条模式
- 参考 `style_reference.md` 选定视觉风格和情绪参数

### Step 2: 创意方案撰写
- 使用 `creative_design_template.md` 模板进行撰写
- 核心要素:
  1. 核心主题 Theme
  2. 视觉调性 Visual Style（从风格速查表选取，记录完整关键词）
  3. 叙事结构 Narrative Arc（从弧线模板选取，匹配时长）
  4. 开场方式 Opening Hook（从开场方式库选取，记录方式名称+适用理由）
  5. 角色设定 Character Setting（多角色时遵循角色锁定协议）
  6. 合规约束（从三层规则提取禁用词+必加项）
- **角色数量上限**：
  - 15-20s 前贴 ≤ 2 角色；30s 成片 ≤ 3 角色；60s 成片 ≤ 4 角色
  - 含医生/护士角色 → 必须过形象合规（默认禁医生推荐保险；医生剧情向可白大褂出镜但只诊断病情、绝不提保险），且不能担任产品推荐人
- 输出 creative_design.md
- **创意方案合规自检**（输出前逐项必查）：
  - 医生推荐产品场景 → 改为用户视角叙述
  - 焦虑恐吓式引入（住院后悔/患病恐慌）→ 改为日常场景引入
  - 承保主体错误（如把平台名当承保方）→ 修正为保司全称
  - 开场方式涉及手机屏幕展示 → 改为手持道具不展示屏幕或声音触发
  - 自检结果附在 creative_design.md 末尾："合规自检：通过 / 已修正N项"
  - **轻量合规预检**（可选，当创意方案含口播草稿时）：对草稿口播文本跑 `scripts/pre_compliance_check.py --json`，将返回的禁用词/格式问题在自检中一并标注。此阶段只做检测不做修复（脚本尚未原子化，修复在 PLANNING → Step 3.5 执行）

### Step 3: 用户确认
- 展示创意文档给用户
- **确认展示分层**：
  - 一级（必确认）：核心主题一句话 / 角色设定 / 叙事结构选型 / 开场方式选型
  - 二级（建议确认）：视觉调性关键词 / 情绪参数
  - 三级（附带展示）：禁用词清单 / 必加警示语清单
  - 用户确认一、二级即视为通过；三级无异议默认接受
- 用户确认后回到入口工作流继续后续步骤：
  - 路径B（entry_brief_only.md）：进入 Step 3 脚本撰写
  - 路径A（entry_direct_script.md）：不经过本工作流，直接从脚本解析开始
- 用户要求修改则回到 Step 2

## 多脚本共用创意
一次创意出 N 条脚本（N≥2）时：
- 共用不变项：核心主题 / 视觉调性 / 合规约束（禁用词 + 必加警示语）
- 叙事结构：可用同一弧线，各条写不同变体（A/B/C，换开场钩子或场景载体）
- 开场方式：各条可选用不同开场方式做A/B测试（如条1用大特写直入、条2用场景代入、条3用问答互动），对比完播率
- 角色：同一 campaign 内固定（遵循角色锁定协议），但各条可切换主视角（如条1母亲视角、条2子女视角）
- creative_design.md 中用表格列出各条差异项：

| 脚本 | 弧线变体 | 开场方式 | 主视角角色 | 开场场景 |
|------|---------|---------|-----------|---------|
| 条1 | A | 大特写直入 | … | … |
| 条2 | B | 场景代入 | … | … |

## 创意版本管理
- 每次用户要求修改 → 新版存为 creative_design_v2.md / v3.md，不覆盖旧版
- 修改展示时给出与上一版的 diff（变更字段 + 变更原因）
- 用户最终确认后 → 最终版改名为 creative_design.md，删除中间版本 v2/v3

## 风格-弧线-开场搭配建议（参考，非绝对互斥）

Step 1/2 选定视觉风格、叙事弧线与开场方式后，可参考以下常见搭配：
- 温馨家庭 / 生活纪实 → 场景引入、情感共鸣类弧线 + 家庭场景口播/画外音+空镜
- 专业严谨 / 数据对比 → 问题-方案、对比说服类弧线 + 银行场景口播/投影屏讲解/手持保单
- 活泼搞笑 → 反转钩子类弧线 + 街头采访/多人接力/手机提示音触发
- 严肃医疗 → 情绪共鸣/问题-方案类弧线 + 医院场景口播/缴费窗口冲击/体检报告打开
- 搭配不符（如温馨家庭 + 意外事故直入）→ 可输出提醒，让用户确认是否为刻意创意，不擅自决定修改；特殊创意可突破常规搭配
