## 本次已确立的标准（必须与之一致，不要改回旧值）
- 语速：好医保系列（中老年52973/门诊险36866/少儿53408）统一 **7字/秒**；长钱保 **6字/秒**；通用默认7。旧文档里"好医保8字/秒"是过时值，遇到改为7。
- 分段算法：句子流均匀打包，目标190字/段、硬上限205字（7字/秒×~29s），在句读边界（。！？）切；duration 取 10/15/20/25/30（5s步进，短段给10s不硬撑）。详见 knowledge/video_parameters/segmentation_packaging.md。
- 时长预算：停顿类型化——逗号0.3s、句末0.6-0.8s、角色切换1.0-1.3s；动作与台词共享时间轴不叠加（只有纯动作无台词镜头才单独给：establishing 2-3s、反应1.5-2s、转场1.5-3s）；段末1.5-2s余韵、段首不留；首段第0秒即刻开口。
- 台词：声画一体接口（generate_audio=True）台词随镜头写，用 @VOX_角色 锚定六维音色卡、{}包裹；不做独立AUDIO区块（那是音频先行6阶段才用）。
- 角色参考图：工具无状态，每个镜头/每段 ImageList 都重复传入，不能只在首镜传。
- 防模型自由发挥：角色只念{}台词、逐字念；VERIFYING 用 ASR总字数对照期望，显著多=插入/重复需重做。
- Extend 承接：同角色承接 vs 换角色承接（"B听完A最后一句立刻回应"）两种。
- 版权 `copyright restrictions` = Seedance 随机撞库误判，非内容问题，换key/种子原样重试。
- 方言：同一脚本多版本（3普通话+四川话+东北话），台词相同只改@VOX口音维度。
- 发音：CAR-T 读"卡替"不逐字母；ICU/CT 逐字母。
- 暗水印：低码率AI片源(<3Mbps)固定CBR 4M+window50；抽全帧子进程隔离防C层崩溃。
- **逐字稿（字幕链路唯一源头，v4.1 统一）**：格式 = **SRT + JSON 两份**（SRT 每字一行，人看/播放器可加载；JSON = `[{"text":"字","start":0.32,"end":0.36}, ...]`，程序读取）；路径 = **`{项目}/{日期}/字幕/`**（与口播字幕SRT同目录，**不另建 `逐字稿/` 子目录**）；命名 = **`{名称}_逐字稿.srt` + `{名称}_words.json`**（交付目录带序号前缀 `{序号}_{名称}_...`）；来源 = **ASR words 直出，不经 LLM、不做任何断句/合并/纠错/加标点**。口播字幕SRT 是**派生产物**：`逐字稿 → LLM断句 → 口播字幕`，禁止两者各自独立跑一次 ASR。旧 TAB 分隔 TXT 逐字稿（`起始秒\t结束秒\t字`）**已废弃**，全库不得再出现。格式权威 = `knowledge/video_parameters/asr_processing.md` 第10.5章。
- 医疗题材两模式：默认禁医生推荐保险；医生剧情向（客户指定）医生白大褂可出镜但只诊断病情、绝不提保险。血氧=指夹探头+SpO₂波形（非心电图ECG）。
