# 统一异常处理框架 (Error Handler)

## 1. 异常分级

| 等级 | 名称 | 含义 | 处理方式 |
|------|------|------|----------|
| FATAL | 致命异常 | 无法自动恢复,必须终止当前任务 | 终止 -> 保存上下文 -> 通知用户 -> WAITING_USER |
| RECOVERABLE | 可恢复异常 | 有明确的自动修复路径 | 自动执行修复 -> 回到来源状态重试 |
| USER_INPUT_NEEDED | 需用户决策 | 暂停问用户 | 暂停 -> 展示选项 -> WAITING_USER -> 用户响应后继续 |
| SKIP | 跳过异常 | 当前任务无意义/用户要求跳过 | 跳过当前任务 -> 进入下一任务 |

## 2. 异常清单

| 异常ID | 场景 | 等级 | 修复策略 |
|--------|------|------|----------|
| E001 | 视频生成超时/单段时长超限 | RECOVERABLE | 首次超时→切换extend模式（前半段text2video + 后半段reference2video + ffmpeg拼接）；extend仍失败→按退避策略延迟重试（立即/10s/30s）；累计3次后升级FATAL |
| E002 | 视频生成接口报错（非超时/非审核） | RECOVERABLE | 换模型/降分辨率/缩短时长后重试；累计3次后升级FATAL |
| E003 | 内容审核不通过 | FATAL | 终止并通知用户，展示审核不通过的具体原因 |
| E004 | ASR识别失败 | RECOVERABLE | 退避重试（10s/30s）；累计2次后升级FATAL |
| E005 | 音频修复-TTS克隆失败 | RECOVERABLE | 更换参考音片段/降采样率后重试；累计3次后升级为VIDEO_REDO（重新生成该镜头） |
| E006 | ffmpeg处理失败（音频替换/视频拼接/格式转换） | RECOVERABLE | 检查输入文件完整性和编码格式后重试；累计2次后升级FATAL |
| E007 | 警示语缺失/触发句无对应警示语 | USER_INPUT_NEEDED | 展示缺失项，询问补挂方案或确认跳过 |
| E008 | 合规扫描命中禁用词且无法自动修正 | USER_INPUT_NEEDED | 展示命中项和建议替换方案，请用户决策 |
| E009 | 镜头拼接失败（SHOT_MERGE） | RECOVERABLE | 检查各镜头编码/分辨率/帧率一致性后重试；累计2次后升级FATAL |
| E010 | 归档失败（文件移动/存储写入） | RECOVERABLE | 检查磁盘空间/目录权限后重试；累计2次后升级USER_INPUT_NEEDED |
| E011 | 脚本解析失败（格式无法识别/内容为空/编码错误） | USER_INPUT_NEEDED | 请用户重新提供脚本或确认文件格式 |
| E012 | 音色锚定/TTS接口异常（分两种场景） | RECOVERABLE | ①接口调用失败（500/超时）：重试3次（立即/10s/30s），仍失败则降级标准TTS，不阻断；②音色锚定效果不达标：不重试接口，记录警告，后期修复时回退到从原视频提取参考音 |
| E013 | 时长超限（脚本预估时长超出模型能力且无法extend） | USER_INPUT_NEEDED | 询问缩短脚本或拆分为多条视频 |
| E014 | API Key额度超限 | RECOVERABLE | 自动切换下一把Key（3把轮转）；全部超限→USER_INPUT_NEEDED，通知用户等待次月重置或手动提供新Key |
| E015 | 分镜规划失败（无法合理拆解镜头/Prompt构造失败/时长预估不合理） | USER_INPUT_NEEDED | 展示分镜问题，请用户调整脚本或确认分镜方案 |
